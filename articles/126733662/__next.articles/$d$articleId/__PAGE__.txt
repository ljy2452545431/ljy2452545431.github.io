<h2><a id="_4"></a>插槽是什么</h2> 
<p>vue中的插槽指的是子组件提供给父组件使用的一个占位符用标签表示，父组件可以在这个占位符中填充任何模板代码比如html、组件等，填充的内容会替换掉子组件的标签（替换占位符）<br> 大致来说插槽的作用是：父组件提供内容，在子组件中展示。也有相反的作用域插槽</p> 
<h2><a id="_7"></a>有哪些插槽</h2> 
<p><strong>1.默认插槽</strong></p> 
<pre><code>&lt;slot&gt;&lt;/slot&gt;
</code></pre> 
<p><strong>2.具名插槽</strong><br> 具名插槽可以在一个组件中出现N次，出现在不同的位置。<br> 再2.6.0使用v-slot:插槽名 语法糖:#插槽名</p> 
<pre><code>//子组件中
 &lt;slot name=&quot;名称&quot;&gt;&lt;/slot&gt;
//父组件中
&lt;template v-slot:名称&gt;内容&lt;/template&gt;
</code></pre> 
<p><strong>3.作用域插槽</strong><br> 作用域插槽就是带参数（数据）的插槽，强调的则是数据作用的范围<br> 在子组件的插槽中带入参数（数据）提供给父组件使用，该参数（数据）仅在插槽内有效，父组件可以根据子组件中传过来的插槽参数（数据）对展示内容进行定制</p> 
<p>也就是：子组件提供内容（数据），在父组件中展示。</p> 
<p>如何使用：</p> 
<ol><li>在子组件中设置:slot：自定义name=data中的属性或对象</li></ol> 
<pre><code>//默认作用域插槽情况下
&lt;!-- slot标签中属性名跟变量名必须一至 --&gt;
&lt;slot :msg=&quot;msg&quot;&gt;&lt;/slot&gt;  //具名作用域插槽情况下：绑定个name
&lt;slot :msg=&quot;msg&quot; name=&quot;s3&quot;&gt;&lt;/slot&gt;  </code></pre> 
<p>在父组件中设置：slot-scope=“自定义命名”</p> 
<pre><code>//默认作用域插槽情况下
&lt;box1&gt;  &lt;template slot-scope=&quot;box1scope&quot;&gt;  &lt;h1&gt;{{box1scope.msg.name}}&lt;/h1&gt;  &lt;/template&gt;  &lt;/box1&gt;
//具名作用域插槽情况下：绑定个v-slot:名称=&quot;作用域名称&quot;
&lt;box1 v-slot:s3=&quot;box1scope&quot;&gt;  &lt;h1&gt;{{box1scope.msg.name}}&lt;/h1&gt;
&lt;/box1&gt;
</code></pre> 
<p><strong>案例：</strong></p> 
<pre><code>//父组件App.vue中
&lt;template&gt;  &lt;div v-cloak class=&quot;App&quot;&gt;  &lt;!-- 默认插槽传值 --&gt;  &lt;box1&gt;  &lt;!-- 将box2组件传入到box1默认插槽中 --&gt;  &lt;box2&gt;&lt;/box2&gt;  &lt;/box1&gt;  &lt;!-- 具名插槽传值 --&gt;  &lt;box1&gt;  &lt;template v-slot=s2&gt;  &lt;h2&gt;  {{msg}}  &lt;/h2&gt;  &lt;/template&gt;  &lt;/box1&gt;  &lt;!-- 作用域插槽传值 --&gt;  &lt;box1 v-slot:s3=&quot;box1scope&quot;&gt;  &lt;h1&gt;{{box1scope.msg.name}}&lt;/h1&gt;  &lt;/box1&gt;  &lt;/div&gt;
&lt;/template&gt;

&lt;script&gt;
import box1 from &quot;@/components/box1.vue&quot;
import box2 from &quot;@/components/box2.vue&quot;
export default {  data() {  return {  msg: &quot;父组件App&quot;,  name:&quot;这是父组件App.vue传的值&quot;  }  },  components:{  box1,  box2  },  methods: {  fn(){  console.log(box.msg.name)  }  },
}
&lt;/script&gt;
</code></pre> 
<pre><code>//子组件box1中
&lt;template&gt;  &lt;div&gt;  &lt;!-- 默认插槽 --&gt;  &lt;slot&gt;&lt;/slot&gt;  &lt;!-- 具名插槽 --&gt;  &lt;slot name=&quot;s2&quot;&gt;&lt;/slot&gt;  &lt;!-- 作用域插槽 --&gt;  &lt;!-- slot标签中属性名跟变量名必须一至 --&gt;  &lt;slot :msg=&quot;msg&quot; name=&quot;s3&quot;&gt;&lt;/slot&gt;  &lt;/div&gt;
&lt;/template&gt;
&lt;script&gt;  export default {  data() {  return {  box1name:&quot;box1插槽中&quot;,  msg: {name:&quot;ljy&quot;,age:21}  }  },  }
&lt;/script&gt;
</code></pre> 
<pre><code>//子组件box2中
&lt;template&gt;
&lt;h1&gt;{{msg}}&lt;/h1&gt;
&lt;/template&gt;
&lt;script&gt;
export default {  data() {  return {  msg:&quot;box2组件&quot;  }  },
}
&lt;/script&gt;
</code></pre>

<p><strong>注意点：</strong></p>
