<h2><a id="_5"></a>代理配置</h2> 
<p>在Vue框架中，我们使用相对网络路径去请求我们后端服务器时，会存在跨域，<br> 因为打包时自动给我们生成了服务器，去请求我们自己的后端服务器时，会导致端口不对从而跨域。<br> <strong>如何解决呢?</strong><br> 方法一：后端egg中配置跨域服务。具体参考<a href="https://blog.csdn.net/qq_56973906/article/details/126112902" target="_blank" rel="noreferrer noopener">跨域解决方案</a><br> 方法二：代理配置</p> 
<pre><code>//vue.config.js文件中配置
 devServer: {  port: 8080, //默认vue脚手架配置就8080  //代理配置  proxy: {  &#x27;/server&#x27;: {  target: &#x27;http://localhost:7001&#x27;,  secure: true, //如果代理的target是https接口,需要配置它  pathRewrite: {  &#x27;^/server&#x27;: &#x27;/&#x27;  },  //请求时重写pathname:  //项目组件中请求的是http://localhost:8080/server/ajax1  //8080服务器就会帮我们代理请求 http://localhost:7001/ajax1  //如果项目组件中请求的是http://localhost:8080/app/ajax1 那么proxy就检测不到 就不会做代理  },  },
 }
</code></pre> 
<p>配置好了我们就可以跨域请求我们的后端服务器了</p> 
<pre><code>//父组件App.vue文件中
&lt;template&gt;  &lt;div v-cloak class=&quot;App&quot;&gt;  &lt;button @click=&quot;fn&quot;&gt;点击请求后端ajax1&lt;/button&gt;  &lt;h1&gt;{{data.name}}{{data.age}}&lt;/h1&gt;  &lt;/div&gt;
&lt;/template&gt;
&lt;script&gt;
import axios from &quot;axios&quot;
export default {  data() {  return {  data:{}  }  },  methods: {  async fn(){  let shuju=await axios(&#x27;/server/ajax1&#x27;)  this.data=shuju.data  console.log(this.data)  }  },
}
&lt;/script&gt;
</code></pre>

<h2><a id="axios_63"></a>axios二次封装</h2> 
<p>为了省略每次请求时都需要添加代理配置的api 例如axios(‘/server/ajax1’)<br> 此时需要对axios进行二次封装<br> 要使每个子组件都能使用axios,需要在组件的原型链上配置axios工具,并配置公共网址</p> 
<pre><code>main.js文件中:
 import axios from &quot;axios&quot;
 Vue.prototype.$axios=axios
 Vue.prototype.$axios.defaults.baseURL=&quot;http://ip:8080/api&quot; 
</code></pre> 
<p>组件中使用this.$axios进行请求</p> 
<pre><code>let shuju=await this.$axios(&#x27;/ajax1&#x27;)
</code></pre>
