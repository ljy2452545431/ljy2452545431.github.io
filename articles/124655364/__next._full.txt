<h2><a id="_7"></a>前言</h2> 
<p>JS中new关键字是什么?<br> 它有哪些作用?</p> 
<h2><a id="new_11"></a>一、new关键字的定义</h2> 
<p>new fn() new关键字后面跟函数 是一个表达式(运算符) 创建对象的运算 整个表达式一定会得到一个对象并且给它添加一个属性 <strong>proto</strong> 这个属性引用fn.prototype</p> 
<h2><a id="new_14"></a>二、new关键字的作用</h2> 
<ol><li>创建一个空对象 ，给它添加一个属性 <strong>proto</strong> 这个属性引用fn.prototype</li><li>运行构造函数,让内部的this指向创建的对象(用创建的空对象去调用构造函数)</li><li>整个表达式的结果看函数的返回值:<br> 3.1返回值是引用数据 那么就是返回值<br> 3.2返回值不是引用数据 那么就是这个运行完毕之后的创建的那个对象</li></ol> 
<h2><a id="_20"></a>三、实例</h2> 
<p>实例1</p> 
<pre><code>function fm(name) {  this.name = name  return fm  }  var re=new fm(&quot;ljy&quot;)  console.log(re)  //打印什么?
</code></pre> 
<p><strong>分析：</strong> 首先判断返回值是引用数据,所以结果返回的是fm函数之后；打印的就是这个函数<br> ƒ fm(name) {<br> this.name = name<br> return fm<br> }</p> 
<p>实例2</p> 
<pre><code>function fn() {  var obj={say:function(){  return obj  }}  return obj  }  var re=new fn()  var re2=fn().say  var re3=new re2()  console.log(re)  console.log(re2)  console.log(re3)  //分别打印什么
</code></pre> 
<p><strong>分析：</strong> 首先判断返回值是引用数据，所以结果返回obj<br> 所以console.log(re)打印的内容为</p> 
<pre><code>{say:function(){
return obj
}}
</code></pre> 
<p>var re2=fn().say 意思是调用这个fn函数然后得到结果的say属性值赋给re2<br> fn()调用得到返回值obj对象，obj.say得到function(){return obj}值<br> 所以console.log(re2)打印内容为</p> 
<pre><code>function(){  return obj
}
</code></pre>

<pre><code>function Parent() {  this.a = 1;  this.b = [1, 2, this.a];  this.c = {  demo: 5  };  this.show = function() {  console.log(this.a, this.b, this.c.demo);  }  this.change = function() {  this.a = this.b.length;  this.c.demo = this.a++;  }  }  var parent = new Parent();  parent.change();  parent.show();
</code></pre>

parent.a=3;parent.c.demo=3 因为a++是先取值后自增,所以a自加1 a=4<br> <strong>注意：</strong> parent.b = [1, 2, this.a] 这里的this.a是先存值所以得出parent.b = [1, 2, 1]<br> 最后parent.show();调用show函数打印出结果为: <strong>4,[1, 2, 1]
