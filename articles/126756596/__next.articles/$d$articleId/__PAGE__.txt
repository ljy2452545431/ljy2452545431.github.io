<h2><a id="_4"></a>两种的实现原理</h2> 
<p><strong>两种传值都是通过属性和自定义事件来封装的</strong><br> 比如：当我们子组件实现购物车增减，父组件中的总价也随之改变<br> 使用属性和自定义事件来双向绑定</p> 
<pre><code>//App.vue父组件中
&lt;template&gt;  &lt;div v-cloak class=&quot;App&quot;&gt;  &lt;!-- 向子组件传递数据,并给子组件绑定自定义事件，等待子组件触发--&gt;  &lt;box1  @myadd=&quot;add&quot; @myreduce=&quot;reduce&quot; v-for=&quot;(item, i) in goods&quot; :key=&quot;item.id&quot; :pro=&quot;item&quot; :index=&quot;i&quot;&gt;&lt;/box1&gt;  &lt;p&gt;共计{{goods|fn}}元&lt;/p&gt;  &lt;/div&gt;
&lt;/template&gt;
&lt;script&gt;  import box1 from &quot;./components/box1.vue&quot;
export default {  data() {  return {  goods:[{id:1,title:&#x27;鱼香肉丝&#x27;,price:21,count:1}, { id: 2, title: &#x27;回锅肉&#x27;, price: 28 , count: 2}, { id: 3, title: &#x27;酸菜鱼&#x27;, price: 30, count: 3}],  }  },  methods: {  &lt;!-- 自定义事件处理函数--&gt;  add(index){  this.goods[index].count++  },  reduce(index){  if (this.goods[index].count&gt;0){  this.goods[index].count--  }  },  },  //使用过滤器来计算总价  filters:{  fn(arr){  let count=null  arr.forEach(el =&gt; {  count+=el.price*el.count  });  return count  }  },  components:{  box1,  }
}
&lt;/script&gt;
</code></pre> 
<pre><code>//子组件box1.vue中
&lt;template&gt;  &lt;!-- 接受父组件的数据，并给每个商品绑定加减按钮--&gt;  &lt;p&gt;&lt;span&gt;{{pro.title}}----{{pro.price}}&lt;/span&gt;&lt;button @click=&quot;reduce&quot;&gt;-&lt;/button&gt;&lt;span&gt;{{pro.count}}&lt;/span&gt;&lt;button @click=&quot;add()&quot;&gt;+&lt;/button&gt;&lt;/p&gt;
&lt;/template&gt;
&lt;script&gt;  export default {  props:[&#x27;pro&#x27;,&#x27;index&#x27;],  methods: {  &lt;!-- 点击按钮触发自定义事件--&gt;  add(){  this.$emit(&quot;myadd&quot;, this.index)  },  reduce(){  this.$emit(&quot;myreduce&quot;,this.index)  }  },  }
&lt;/script&gt;
</code></pre> 
<h2><a id="sync_73"></a>sync实现双向绑定</h2> 
<p>对于 @myadd=“add” @myreduce=“reduce” vue 提供了一个语法糖，将其替换成 :mydata.sysnc=“item.count”;而且也不用再父组件中再去写触发函数了，这样是不是看起来简洁多了。</p> 
<p>那么就变成了：</p> 
<p>// 父组件</p> 
<pre><code>//App.vue父组件中  &lt;div v-cloak class=&quot;App&quot;&gt;  &lt;box1  :mydata.sync=&quot;item.count&quot; v-for=&quot;(item, i) in goods&quot; :key=&quot;item.id&quot; :pro=&quot;item&quot; :index=&quot;i&quot;&gt;&lt;/box1&gt;  &lt;p&gt;共计{{goods|fn}}元&lt;/p&gt;  &lt;/div&gt;
&lt;/template&gt;
&lt;script&gt;  import box1 from &quot;./components/box1.vue&quot;
export default {  data() {  return {  goods:[{id:1,title:&#x27;鱼香肉丝&#x27;,price:21,count:1}, { id: 2, title: &#x27;回锅肉&#x27;, price: 28 , count: 2}, { id: 3, title: &#x27;酸菜鱼&#x27;, price: 30, count: 3}],  }  },  //使用过滤器来计算总价  filters:{  fn(arr){  let count=null  arr.forEach(el =&gt; {  count+=el.price*el.count  });  return count  }  },  components:{  box1,  }
}
&lt;/script&gt;
</code></pre> 
<pre><code>//子组件box1.vue中
&lt;template&gt;  &lt;p&gt;&lt;span&gt;{{pro.title}}----{{pro.price}}&lt;/span&gt;&lt;button @click=&quot;reduce&quot;&gt;-&lt;/button&gt;&lt;span&gt;{{pro.count}}&lt;/span&gt;&lt;button @click=&quot;add()&quot;&gt;+&lt;/button&gt;&lt;/p&gt;
&lt;/template&gt;
&lt;script&gt;  export default {  props:[&#x27;pro&#x27;,&#x27;index&#x27;],  methods: {  add(){  this.$emit(&quot;update:mydata&quot;, this.pro.count+1)  },  reduce(){  if (this.pro.count &gt; 0){  this.$emit(&quot;update:mydata&quot;, this.pro.count-1)  }  }  },  }
&lt;/script&gt;
