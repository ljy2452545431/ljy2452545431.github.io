<h2><a id="mime_4"></a>一、mime模块是什么</h2> 
<p>mime是一个互联网标准，通过设定它就可以设定文件在浏览器的打开方式。<br> 它是第三方模块，需要手动下载。</p> 
<h2><a id="mime_7"></a>二、如何安装mime模块</h2> 
<p>使用npm安装模块<br> npm -i mime //下载到全局则要加-g<br> <img src="/images/articles/126089202/1560c38f6a885923831c75388bbc50c9.png" alt="在这里插入图片描述" loading="lazy" decoding="async"><br> <img src="/images/articles/126089202/852940d81e25f54ab6b75304e082ae4e.png" alt="在这里插入图片描述" loading="lazy" decoding="async"><br> 安装完后项目中会出现node_modules和json文件说明安装成功；接下来就可以使用require来引入它了</p> 
<h2><a id="mime_13"></a>三、mime模块方法</h2> 
<h3><a id="1mimegetTypeurl_14"></a>1.mime.getType(url)</h3> 
<p>可以通过路径返回资源类型<br> 可以给网站请求的资源（html、css等）添加一个content-type<br> 没有添加content-type使用高级浏览器不会出错，但低级浏览器可能会出错</p> 
<pre><code>var http = require(&#x27;http&#x27;)
var url = require(&#x27;url&#x27;)
var mime = require(&#x27;mime&#x27;)
var fs = require(&#x27;fs&#x27;)
http.createServer((req, res) =&gt; {
	let pathname = url.parse(req.url).pathname
	let type = mime.getType(req.url)
	console.log(type)
	fs.readFile(__dirname + pathname, (err, data) =&gt; {  if (!err) {  res.setHeader(&quot;content-Type&quot;, type)  res.end(data)  }
	})

}).listen(8081)
</code></pre>

<h3><a id="2mimegetExtensiontype_38"></a>2.mime.getExtension(type)</h3> 
<p>查询文件护展名可配合getType使用，传入的是MIME类型</p> 
<pre><code>var mime = require(&#x27;mime&#x27;)
var type=mime.getType(&quot;./img/test.txt&quot;)
let type2=mime.getExtension(type)
console.log(type,type2)
</code></pre>

<h3><a id="3mimedefine_47"></a>3.mime.define</h3> 
<p>mime自定义类型，当mime模块自带的mime-db库不存在或不能满足我们所需的MIME类型时，还可以自定义MIME类型</p> 
<pre><code>var mime = require(&#x27;mime&#x27;)
mime.define({  &#x27;text/mytext&#x27;: [&#x27;t-txt&#x27;, &#x27;t-ext&#x27;, &#x27;t-xt&#x27;],
});
type=mime.getExtension(&#x27;text/mytext&#x27;)
console.log(type)
</code></pre>
