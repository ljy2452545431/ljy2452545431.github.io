<h2><a id="_7"></a>前言</h2> 
<p>CSS用于控制网页的样式和布局, 修饰页面效果，可以配合脚本语言动态的对网页各元素进行格式化，提升用户体验性，接下来让我们详细看看CSS是如何将网页美容的。</p> 
<h2><a id="CSS_10"></a>一、CSS样式规则</h2> 
<p>CSS规则主要由两个主要部分构成：<strong>选择器</strong>，以及<strong>一条或多条声明</strong>。</p> 
<ol><li>选择器用于指定css样式作用的HTML对象，花括号内是对该对象设置的具体样式。</li><li>属性和属性值之间以“键值对”的形式出现。</li><li>属性是对指定的对象设置的样式属性，例如字体大小、文本颜色等。</li><li>属性和属性值之间用英文“：”连接。</li><li>多个键值对之间使用英文“；”区分。</li></ol> 
<pre><code>p {  /*选择器*/  color: red;	/*声明*/  font-size: 14px;  /*声明*/
}
</code></pre> 
<h2><a id="CSS_23"></a>二、CSS引入方式</h2> 
<h3><a id="1__24"></a>1.行内样式表 (不建议使用)</h3> 
<p>直接在标签的属性中使用style声明，在style属性中添加css声明即可。</p> 
<pre><code>&lt;!--在标签内部再嵌套一个内嵌标签来设置样式--&gt;
&lt;p&gt;这是一个&lt;span style=&quot;color: red;&quot;&gt;行内样式表&lt;/span&gt;的css&lt;/p&gt;
</code></pre> 
<h3><a id="2_30"></a>2.内部样式表（内联样式）</h3> 
<p>定义在head或body标签中,使用style标签</p> 
<pre><code>&lt;style type=&quot;text/css&quot;&gt;
	p {  background-color: blue;  color: red;
	}
&lt;/style&gt;
</code></pre> 
<h3><a id="3_40"></a>3.外部样式表</h3> 
<p>定义在外部的css文件中，需要在head中引入相应的css文件<br> (1）<strong>html文件中：使用link来导入css文件</strong></p> 
<pre><code>&lt;html&gt;
&lt;head&gt;
&lt;title&gt;CSS外部样式引入&lt;/title&gt;
/*关联外部的css样式文件*/
&lt;link type=&quot;text/css&quot; rel=&quot;stylesheet&quot; href=&quot;../css/text.css&quot; /&gt;
&lt;/head&gt;
&lt;body&gt;
&lt;/body&gt;
&lt;/html&gt;
/*type:定义链接文档的类型，在这里需要指定为&quot;text/css&quot;,表示链接的外部文件为css样式表。
rel：定义当前文档与被链接文档之间的关系，在这里需要指定为&quot;stylesheet&quot;，表示被链接的文档是一个样式表文件。
href：定义所链接外部样式表文件的url，可以是相对路径，也可以是绝对路径。*/
</code></pre> 
<p>(2）<strong>css文件中：定义CSS样式</strong></p> 
<pre><code>p {  background-color: blue;  color: red;  }
</code></pre> 
<h3><a id="4_64"></a>4.三种样式表总结</h3> 
<p><img src="/images/articles/124527516/eac3b0fb795f8deae3432dbb4690d989.png" alt="在这里插入图片描述" loading="lazy" decoding="async"><br> 3种样式表的优先级：</p> 
<p>1、行内样式表 &gt; 内部样式表 = 外部样式表</p> 
<p>2、当内部样式表和外部样式表同时存在时，采用 <strong>就近原则</strong> 来使用样式</p> 
<h2><a id="CSS_72"></a>三、CSS字体属性</h2> 
<table><thead><tr><th>字体属性</th><th>描述</th></tr></thead><tbody><tr><td>font-size：字号大小</td><td>用于设置字号</td></tr><tr><td>font-family：字体</td><td>用于设置字体</td></tr><tr><td>font-weight：字体粗细</td><td>用于设置字体粗细</td></tr><tr><td>font-style：字体风格</td><td>用于定义字体风格如设置斜体、倾斜或正常字体</td></tr><tr><td>font-variant</td><td>规定字体异体</td></tr></tbody></table>
<p>font-style 可用属性值如下：</p> 
<ul><li><strong>normal</strong>：默认值，浏览器会显示标准的字体样式。</li><li><strong>italic</strong>：浏览器会显示斜体的字体样式。</li><li><strong>oblique</strong>：浏览器会显示倾斜的字体样式。</li></ul> 
<p>font-variant 可用属性值如下：</p> 
<ul><li><strong>normal</strong>：默认值。浏览器会显示一个标准的字体。</li><li><strong>small-caps</strong>： 浏览器会显示小型大写字母的字体。</li><li><strong>inherit</strong>： 规定应该从父元素继承 font-variant 属性的值。</li></ul>

<table><thead><tr><th>文本属性</th><th>描述</th></tr></thead><tbody><tr><td>color</td><td>用于指定文本的颜色</td></tr><tr><td>text-align</td><td>指定元素文本的水平对齐方式</td></tr><tr><td>text-decoration</td><td>用于对文本添加修饰，如下划线、删除线等</td></tr><tr><td>text-transform</td><td>用于转换文本的大小写</td></tr><tr><td>text-indent</td><td>规定文本块(块级中的文本)中首行文本的缩进</td></tr><tr><td>text-shadow</td><td>用于设置文本的阴影效果</td></tr><tr><td>direction</td><td>用于指定文本的方向</td></tr><tr><td>letter-spacing</td><td>用于增加或减少字符间的空白（字符间距）主要用于汉字</td></tr><tr><td>word-spacing</td><td>用于增加或减少单词与单词之间的空白 主要用于英文段落</td></tr><tr><td>line-height</td><td>用于设置文字行与文字行之间的距离</td></tr><tr><td>word-break</td><td>规定自动换行的处理方法</td></tr></tbody></table>
<h3><a id="41_color__107"></a>4.1 color 文本颜色</h3> 
<p>color属性有3种表现形式：</p> 
<ul><li>color-name：使用颜色名称，如：red, transparent</li><li>hex-number：使用十六进制数表示，取值是0~f，每个颜色使用两位表示，如：#ff0000表示红色 0-9 a:10 b:11 c:12 d:13 e:14 f:15</li><li>rgb-number：使用rgb颜色值表示，取值0~255，如rgb(255,0,0)，rgba(100%, 0%, 0%, .5)</li><li>rgba：在rgb上多了一给a，表示透明度，取值0~1完全透明完全不透明</li></ul> 
<pre><code>&lt;style type=&quot;text/css&quot;&gt;
	h1 {  color: red;
	}
	h2 {  color: #00ff00;
	}
	h3 {  color: rgb(0, 0, 255);
	}  h4 {  color: ; rgba(100%, 0%, 0%, .5)
	}
&lt;/style&gt;

&lt;h1&gt;标题1&lt;/h1&gt;
&lt;h2&gt;标题2&lt;/h2&gt;
&lt;h3&gt;标题3&lt;/h3&gt;
&lt;h4&gt;标题3&lt;/h4&gt;
</code></pre> 
<h3><a id="42_textalign__135"></a>4.2 text-align 文本对齐方式</h3> 
<p>text-align用于指定元素文本的水平对齐方式，取值有left、right、center、justify（两端对齐文本）</p> 
<pre><code>&lt;head&gt;
&lt;style type=&quot;text/css&quot;&gt;
	h1 {  text-align: left;	/*左对齐*/
	}
	h2 {  text-align: center;	/*居中对齐*/
	}
	h3 {  text-align: right; /*右对齐*/
	}
	p {  text-align: justify; /*分散对齐，主要针对英文段落中出现空格时，由于两边对齐，空格的大小会有变化*/
	}
&lt;/style&gt;
&lt;/head&gt;
&lt;body&gt;
&lt;h1&gt;标题1&lt;/h1&gt;
&lt;h2&gt;标题2&lt;/h2&gt;
&lt;h3&gt;标题3&lt;/h3&gt;

&lt;p&gt;这是一个段落这是一个段落这是一个段落这是一个段落这是一个段落这是一个段落&lt;/p&gt;
&lt;/body&gt;
</code></pre> 
<h3><a id="43_textdecoration__162"></a>4.3 text-decoration 文本修饰</h3> 
<p>text-decoration用于对文本添加修饰，如下划线、删除线等。有如下取值：</p> 
<ul><li>none：默认，定义标准的文本，没有任何修饰。</li><li>underline：定义在文本下方的一条线</li><li>overline：定义在文本上方的一条线</li><li>line-through：定义穿过文本的一条线</li></ul> 
<pre><code>&lt;style type=&quot;text/css&quot;&gt;
	h1 {  text-decoration: none;
	}
	h2 {  text-decoration: overline;
	}  h3 {  text-decoration: line-through;
	}  h4 {  text-decoration: underline;
	}
	h5 {  /* 文字闪烁，只在火狐中支持 */  text-decoration: blink;
	}
&lt;/style&gt;
</code></pre> 
<h3><a id="44_texttransform__188"></a>4.4 text-transform 文本转换</h3> 
<p>text-transform用于转换文本的大小写（主要用于英文），其取值有：</p> 
<ul><li>none：默认</li><li>capitalize：文本中每个单词以大写字母开头</li><li>uppercase：所有单词字母都大写</li><li>lowercase：所有单词字母都小写</li></ul> 
<h3><a id="45_textindent__196"></a>4.5 text-indent 文本缩进</h3> 
<p>text-indent 属性规定文本块(块级中的文本)中首行文本的缩进。取值有：</p> 
<ul><li>数值：表示像素值</li><li>百分比：基于父元素宽度的百分比的缩进。</li></ul> 
<p><strong>注意：</strong> 负值是允许的。如果值是负数，将第一行左缩进。<br> 小技巧： 首行缩进2字符使用 2em</p> 
<h3><a id="46__textshadow__204"></a>4.6 text-shadow 文本阴影</h3> 
<p>text-shadow用于设置文本的阴影效果。语法格式是</p> 
<pre><code>text-shadow: h-shadow v-shadow blur color;
</code></pre> 
<p>text-shadow: h-shadow v-shadow blur color;</p> 
<pre><code>h-shadow：必需。水平阴影的位置。允许负值。horizontal， X轴往右是正值
v-shadow：必需。垂直阴影的位置。允许负值。 vertical，Y轴向下是正值
blur：可选。模糊的距离。
color：可选。阴影的颜色。
</code></pre> 
<h3><a id="47_direction__216"></a>4.7 direction 文本方向</h3> 
<p>CSS中<strong>direction</strong>属性决定了<strong>HTML</strong>文字渲染方向</p> 
<p>direction 用于指定文本的方向。取值如下：</p> 
<ul><li> <p>ltr：默认的，文本方向从左到右 left to right</p> </li><li> <p>rtl：文本方向从右到左。right to left</p> </li></ul> 
<h3><a id="48_letterspacing__224"></a>4.8 letter-spacing 字符间距</h3> 
<p>letter-spacing 属性增加或减少字符间的空白（字符间距），使用数值表示，可以是负数。主要用于汉字</p> 
<p>如果用于英文段落 增加/减少字母之间的空白</p> 
<h3><a id="49_wordspacing__228"></a>4.9 word-spacing 字间距</h3> 
<p>word-spacing属性增加或减少单词与单词之间的空白，允许使用负值。主要用于英文段落<br> 如果作用于中文，挨在一起的中文会被识别为一个单词</p> 
<h3><a id="410_lineheight__231"></a>4.10 line-height 行高</h3> 
<p>line-height 用于设置文字行与文字行之间的距离。取值如下：</p> 
<ul><li> <p>number：设置数字，此数字会与当前的字体尺寸相乘来设置行间距。</p> </li><li> <p>length：设置固定的行间距 px em 。</p> </li><li> <p>%：基于当前字体尺寸的百分比行间距。</p> </li></ul> 
<p><strong>使用技巧</strong>：在一行的盒子内，我们设定行高等于盒子的高度，就可以是文字垂直居中。<strong>只适用于单行文本</strong></p> 
<h3><a id="411_wordbreak_241"></a>4.11 word-break</h3> 
<p>规定自动换行的处理方法。通过使用 word-break 属性，可以让浏览器实现在任意位置的换行。</p> 
<table><thead><tr><th>属性值</th><th>描述</th></tr></thead><tbody><tr><td>normal</td><td>使用浏览器默认的换行规则。</td></tr><tr><td>break-all</td><td>允许在单词内换行(主要用于英语)</td></tr><tr><td>keep-all</td><td>保持同行显示，不是中文日语韩语(CJK)其实和normal一样(主要用于CJK)</td></tr></tbody></table>
<p>keep-all: <strong>所有“单词”一律不拆分换行</strong>可以理解为<strong>只有空格等可以触发自动换行</strong><br> break-all：<strong>所有单词碰到边界一律拆分换行</strong></p> 
<h3><a id="412_whitespace_252"></a>4.12 white-space</h3> 
<p>设置元素对内容中的空格的处理方式</p> 
<table><thead><tr><th>值</th><th>描述</th></tr></thead><tbody><tr><td>normal</td><td>默认。文本空白 换行会被浏览器忽略。</td></tr><tr><td>pre</td><td>保留文本原样式 比如空格或换行</td></tr><tr><td>nowrap</td><td>文本不会换行，文本会在在同一行上继续，直到遇到br标签为止。</td></tr><tr><td>pre-wrap</td><td>保留空白符序列，保留换行符。如果文本超出容器宽度处没有换行符自动换行</td></tr><tr><td>pre-line</td><td>合并空白符序列，保留换行符。如果文本超出容器宽度处没有换行符自动换行</td></tr><tr><td>inherit</td><td>规定应该从父元素继承 white-space 属性的值。</td></tr></tbody></table>
<h3><a id="412_overflow_262"></a>4.12 overflow</h3> 
<table><thead><tr><th>值</th><th>描述</th></tr></thead><tbody><tr><td>visible</td><td>默认值。内容不会被修剪，会呈现在元素框之外。</td></tr><tr><td>hidden</td><td>内容会被修剪，并且其余内容是不可见的。</td></tr><tr><td>scroll</td><td>内容会被修剪，浏览器会显示滚动条以便查看其余的内容。</td></tr><tr><td>auto</td><td>如果内容被修剪，浏览器会显示滚动条以便查看其余的内容。</td></tr><tr><td>inherit</td><td>规定应该从父元素继承 overflow 属性的值。</td></tr></tbody></table>
<p>如果父元素宽高能够包含子元素 auto就不会出现滚动条 scroll 就会出现滚动条</p> 
<h3><a id="413_textoverflow_272"></a>4.13 text-overflow</h3> 
<p>用来控制超长溢出的文字内容的显示方式</p> 
<table><thead><tr><th>值</th><th>描述</th></tr></thead><tbody><tr><td>clip</td><td>修剪文本。</td></tr><tr><td>ellipsis</td><td>显示省略符号来代表被修剪的文本。</td></tr></tbody></table>
<p>单行文本溢出</p> 
<pre><code>  div{  width: 100px;  height: 100px;  border: 1px solid black;  /* 强制一行显示*/  white-space: nowrap;  /* 超出部分隐藏 */  overflow: hidden;  /* 超出部分省略号 */  text-overflow: ellipsis;  }

<p>多行文本溢出显示省略号，有较大的兼容性，适合用于webkit浏览器或移动端（移动端内核大部分是webkit内核）</p>

<h2><a id="_315"></a>六、基础选择器</h2> 
<h3><a id="61__316"></a>6.1 标签选择器（元素选择器）</h3> 
<p>标签选择器是指用HTML<strong>标签名作为选择器</strong>，按标签名称分类，为页面中某一类标签指定统一的CSS样式。<br> 基本语法格式:</p> 
<pre><code>  标签名{属性1：属性值1; 属性2：属性值2; ...}
</code></pre> 
<p>优点：能快速为页面中<strong>同类型的标签</strong>统一样式<br> 缺点：不能设计差异化样式。</p> 
<pre><code>span {  color: red;
}

div {  background-color: red;
}
</code></pre> 
<h3><a id="62_id_333"></a>6.2 id选择器</h3> 
<p>id选择器使用“<strong>#</strong>”进行标识，后面紧跟id名。</p> 
<pre><code>#id名{属性1：属性值1; 属性2：属性值2; ...}
&lt;标签名 id=&quot;id值&quot;&gt;&lt;/标签名&gt;
</code></pre> 
<p>注意：元素的id值是唯一的，只能对应于文档中某一个具体的元素。</p> 
<h3><a id="63__341"></a>6.3 类选择器</h3> 
<p>类选择器使用“<strong>.</strong>”（英文点）进行标识，后面紧跟类名。</p> 
<pre><code>.类名{属性1：属性值1; 属性2：属性值2; ...}

&lt;标签名 class=&quot;类名&quot;&gt;&lt;/标签名&gt;
</code></pre> 
<p>相对于ID选择器，类选择器的类名可以是多个，并且一个类名可以对应多个元素，可以为元素对象定义单独或相同的样式。</p> 
<h3><a id="64__350"></a>6.4 多类名选择器</h3> 
<p>可以给标签指定多个类名，类名之间用空格隔开。</p> 
<pre><code>&lt;style&gt;
	.red {  color: red;  }
	.weight {  font-weight: bold;  }
&lt;/style&gt;
</code></pre> 
<pre><code>&lt;div class=&quot;red&quot;&gt;红色&lt;/div&gt;
&lt;div class=&quot;red weigth&quot;&gt;红色加粗&lt;/div&gt;
</code></pre> 
<h3><a id="65__366"></a>6.5 通配符选择器</h3> 
<p>通配符选择器用“*”号表示，它是所有选择器中作用范围最广的，能<strong>匹配页面中所有的元素</strong>。<br> 基本语法格式:</p> 
<pre><code>* {属性1：属性值1; 属性2：属性值2; ...}
</code></pre> 
<p>通常使用它来清楚HTML元素的默认边距。</p> 
<pre><code>* {  margin: 0;	/*定义外边距*/  padding: 0;	/*定义内边距*/
}
</code></pre> 
<h3><a id="66__379"></a>6.6 伪类选择器</h3> 
<p>伪类选择器用于向某些选择器添加特殊的效果。<br> 伪类选择器使用“<strong>:</strong>”冒号来表示</p> 
<h4><a id="1__382"></a>(1) 链接伪类选择器</h4> 
<p>链接伪类选择器主要针对于a标签</p> 
<pre><code>a:link		/*未访问的链接*/
a:visited	/*已访问的链接*/
a:hover		/*鼠标移动到链接上*/
a:active	/*选定的链接*/
</code></pre> 
<p>注意：</p> 
<blockquote>  <ol><li>a:hover 必须在 a:link 和 a:visited 之后。</li><li>a:active 必须在 a:hover 之后，需要严格按顺序才能看到效果。</li><li>visited只能修改颜色，在未访问状态下设置了背景颜色的条件下 可以设置背景颜色 其他不能做改变</li></ol> 
</blockquote> 
<p>记忆方法：<strong>l</strong> o <strong>v</strong> e <strong>h</strong> <strong>a</strong> t e</p> 
<h4><a id="2__CSS3_398"></a>(2) 结构伪类选择器（CSS3）</h4> 
<ul><li> <p><strong>:first-child</strong> 获取第一个子元素</p> <p>​ 在 HTML 中，文本本身是 HTML 元素的父节点，HEAD 和 BODY 是 HTML 元素的子节点。</p> </li><li> <p><strong>:last-child</strong> 获取最后一个子元素。注意：IE8不支持X:last-child。</p> </li><li> <p><strong>:nth-child(n)</strong> 选取某个元素的一个或者多个特定的子元素。可以使用<strong>数字</strong>（n从1开始）、<strong>关键字</strong>（<strong>even偶数</strong>、<strong>odd奇数</strong>）或<strong>公式</strong>&lt;2n-1&gt;（n从0开始，当表达式的值小于等于0时，将不选择任何子元素）。</p> </li><li> <p><strong>:nth-last-child(n)</strong> 选择某个元素的一个或多个特定的子元素，从这个元素的最后一个子元素开始获取。可以使用数字（n从1开始）、关键字（even偶数、odd奇数）或公式（n从0开始）。</p> </li><li> <p><strong>:first-of-type</strong> 选择特定元素的第一个子元素</p> </li><li> <p><strong>:last-of-type</strong> 选择特定元素的最后一个子元素</p> </li><li> <p><strong>:nth-of-type(n)</strong> 只计算父元素中指定的某种类型的子元素</p> </li><li> <p><strong>:nth-last-of-type(n)</strong> 只计算父元素中指定的某种类型的子元素，从这个元素的最后一个元素开始获取</p> </li><li> <p><strong>:only-child</strong> 匹配没有任何兄弟元素的元素</p> </li><li> <p><strong>:only-of-type</strong> 匹配所有元素 这个元素没有其他相同类型的兄弟元素</p> </li><li> <p><strong>:empty</strong> 选择的元素里面没有任何的内容或子节点</p> </li><li> <p><strong>:root</strong> 匹配文档的根节点 html</p> </li></ul> 
<h4><a id="3__420"></a>(3) 目标伪类选择器</h4> 
<p><code>:target</code>选择器用于选取页面中的某个<code>target</code>元素。该元素的<code>id</code>被当做页面的超链接来使用。</p> 
<h2><a id="CSS_422"></a>七、CSS复合选择器</h2> 
<p>复合选择器是由两个或多个基础选择器，通过不同的方式组合而成的。</p> 
<h3><a id="71__424"></a>7.1 交集选择器</h3> 
<p>交集选择器由两个选择器构成，其中第一个为标签选择器，第二个为class选择器或者id选择器，两个选择器之间不能有空格。</p> 
<pre><code>&lt;p class=&quot;blue&quot;&gt;这是一个段落&lt;/p&gt;
</code></pre> 
<pre><code>p.blue {  color: blue;
}
</code></pre> 
<h3><a id="72__434"></a>7.2 并集选择器</h3> 
<p>并集选择器是各个选择器通过<strong>逗号连接</strong>而成的，任何形式的选择器，都可以作为并集选择器的一部分，其中用并集选择器设置的样式是所有选择器会执行的样式</p> 
<pre><code>&lt;p class=&quot;p1&quot;&gt;这是一个段落&lt;/p&gt;
&lt;p class=&quot;p2&gt;这是一个段落&lt;/p&gt;
&lt;p class=&quot;p3&quot;&gt;这是一个段落&lt;/p&gt;
</code></pre> 
<pre><code>.p1,.p2,.p3{  color: blue;
}
</code></pre> 
<h3><a id="73__446"></a>7.3 兄弟选择器</h3> 
<p>兄弟选择器是CSS3.0新增的一个选择器，语法格式： **A~B **或者 <strong>A+B</strong></p> 
<ul><li><strong>‘+’选择器则表示某元素后相邻的兄弟元素，也就是紧挨着的，是单个的。</strong></li><li><strong>‘~’选择器则表示某元素后所有同级的指定元素，强调所有的。</strong></li></ul> 
<pre><code>&lt;div&gt;  &lt;p&gt;这是一个段落&lt;/p&gt;
&lt;/div&gt;
&lt;p&gt;我是相邻的兄弟元素&lt;/p&gt;
&lt;p&gt;这是一个段落&lt;/p&gt;
</code></pre> 
<pre><code>&lt;style&gt;  div+p {  color: red;  }  div~p {  background-color: blue;  }  &lt;/style&gt;
</code></pre> 
<h3><a id="74__467"></a>7.4 后代选择器</h3> 
<p>后代选择器又称为包含选择器，用来选择元素或元素组的后代。其写法就是把外层标签写在前面，中间用<strong>空格</strong>分隔。当标签发生嵌套时，内层标签就成为外层标签的后代。</p> 
<pre><code>&lt;div class=&quot;red&quot;&gt;  &lt;p&gt;red&lt;/p&gt;
&lt;/div&gt;
&lt;p&gt;这是一个段落&lt;/p&gt;
&lt;p&gt;这是一个段落&lt;/p&gt;
</code></pre> 
<pre><code>&lt;style&gt;  .red p {  color: red;  }
&lt;/style&gt;
</code></pre> 
<h3><a id="75__483"></a>7.5 子元素选择器</h3> 
<p>子元素选择器只能选择作为其元素子元素的元素。其写法就是父亲标签写在前面，子级标签写在后面，中间跟一个“<strong>&gt;</strong>”进行连接。<br> 注意：这里的子元素表示<strong>亲儿子</strong>，不包含孙子、重孙子之类。</p> 
<pre><code>&lt;ul class=&quot;header&quot;&gt;
	&lt;li&gt;一级菜单  &lt;ul&gt;  &lt;li&gt;  &lt;ul&gt;  &lt;li&gt;三级菜单&lt;/li&gt;  &lt;/ul&gt;  &lt;/li&gt;  &lt;li&gt;二级菜单&lt;/li&gt;  &lt;li&gt;二级菜单&lt;/li&gt;  &lt;/ul&gt;
	&lt;/li&gt;
&lt;/ul&gt;
</code></pre> 
<pre><code>&lt;style&gt;  .header li { /*后代选择器*/  color: red;
	}  .header &gt; li { /*子元素选择器*/  color: blue;
	}
&lt;/style&gt;
</code></pre> 
<h3><a id="76__511"></a>7.6 属性选择器</h3> 
<table><thead><tr><th>选择器</th><th>含义</th></tr></thead><tbody><tr><td><strong>[attr]</strong></td><td>存在attr属性即可</td></tr><tr><td><strong>[attr=val]</strong></td><td>属性值完全等于val</td></tr><tr><td><strong>[attr*=val]</strong></td><td>属性值里包含val字符并且在“任意”位置</td></tr><tr><td><strong>[attr^=val]</strong></td><td>属性值里包含val字符并且在“开始”位置</td></tr><tr><td><strong>[attr$=val]</strong></td><td>属性值里包含val字符并且在“结束”位置</td></tr></tbody></table>
<h3><a id="77_CSS3_520"></a>7.7 伪元素选择器（CSS3）</h3> 
<ol><li><strong>E::first-letter</strong> 块级文本的第一个单词或字</li><li><strong>E::first-line</strong> 块级文本的第一行</li><li><strong>E::selection</strong> 可改变选中文本的样式</li><li><strong>E::before和E::after</strong> 在E元素内部的开始位置和结束位置创建一个元素，该元素为行内元素，且必须结合content属性使用。</li></ol> 
<p>注意：before与after表示在<strong>盒子内部</strong>的前端和后端插入内容。<br> <strong>::-webkit-input-placeholder</strong>表示选择到input中的placeholder，为其设置样式</p> 
<h2><a id="CSS_529"></a>八、CSS三大特性</h2> 
<h3><a id="1CSS_530"></a>（1）CSS层叠性</h3> 
<p>是浏览器处理冲突的一个能力。如果一个css属性通过两个选择器设置到同一个元素上，那么这个时候一个属性就会将另一个属性层叠掉</p> 
<h3><a id="2CSS_532"></a>（2）CSS继承性</h3> 
<p>含义：指我们设置上级(父级)的CSS样式，上级（父级）及以下的子级（下级）都具有此属性。<br> 特殊性：</p> 
<ul><li> <p>并不是所有的属性都可以继承, 只有以color/font-/text-/line-开头的属性才可以继承。</p> </li><li> <p>在CSS的继承中不仅仅是儿子可以继承, 只要是后代都可以继承 。</p> </li><li> <p>a标签的颜色和下划线的设置不能继承，必须对a标签本身进行设置。</p> </li><li> <p>h标签的字体大小/加粗效果不能修改，必须对h标签本身进行修改。(字体放大两倍)</p> </li></ul> 
<h3><a id="3CSS_543"></a>（3）CSS优先级</h3> 
<p>含义：优先级表示当多个选择器选中同一个标签, 并且给同一个标签设置相同的属性时, 如何层叠就由优先级来确定</p> 
<p><strong>优先级权重</strong><br> 1.同类型选择器：就近原则<br> 2.不同类型选择器：按照：<strong>!important &gt;</strong> <strong>行内样式&gt;ID选择器 &gt; 类选择器 &gt; 标签 &gt; 通配符 &gt; 继承 &gt; 浏览器默认属性</strong><br> 3.多个选择器混合时：通过计算权重判断<br> <strong>权重计算规则</strong><br> （1）<strong>内联样式，如: style=””，权值为1，0，0，0。</strong></p> 
<p>（2）<strong>ID选择器，如：#content，权值为0，1，0，0。</strong></p> 
<p>（3）<strong>类，伪类和属性选择器，如.content E:link E[attr]，权值为0，0，1，0。</strong></p> 
<p>（4）<strong>元素选择器和伪元素选择器，如div p ::before，权值为0，0，0，1。</strong></p> 
<p>（5）<strong>通配符、子选择器、兄弟选择器等的。如*、&gt;、+,权值为0，0，0，0。</strong></p> 
<p>（6）<strong>继承的样式没有权值。!important的权重最高</strong></p> 
<p><strong>注意：单独使用一个选择器的时候，不能跨等级使css规则生效，也就是权重是在双方处于同一等级的情况下，才开始对比。</strong></p> 
<h2><a id="_565"></a>九、标签显示模式</h2> 
<p>HTML标签一般分为块标签和行内标签两种类型</p> 
<h3><a id="1blocklevel_567"></a>（1）块级元素（block-level）</h3> 
<p>每个块元素通常都会独自占据一整行或多整行，可以对其设置高度、宽度、对齐等属性。常见块元素有&lt;h1&gt;~&lt;h6&gt;、&lt;p&gt;、&lt;div&gt;、&lt;ul&gt;、&lt;ol&gt;、&lt;form &lt;li&gt;等。</p> 
<p>特点：</p> 
<ul><li> <p>总是从新行开始 — 换行</p> </li><li> <p>宽度、高度、外边距以及内边距都可以控制</p> </li><li> <p>宽度默认是容器的100%</p> </li><li> <p>可以容纳—嵌套 内联元素和其他块元素</p> </li></ul> 
<h3><a id="2inlinelevel_580"></a>（2）行内元素（inline-level）</h3> 
<p>行内元素（内联元素）不占有独立的区域，仅仅靠自身的字体大小和图像尺寸来支撑结构，一般不可以设置宽度、高度、对齐等属性。<br> 常见的行内元素有：&lt;a&gt;、&lt;strong&gt;、&lt;b&gt;、&lt;em&gt;、&lt;i&gt;、&lt;del&gt;、&lt;s&gt;、&lt;ins&gt;、&lt;u&gt;、&lt;span&gt;等。</p> 
<p>特点：</p> 
<ul><li>和相邻行内元素在一行上。</li><li>宽、高无效，但水平方向的padding和margin可以设置 ，垂直方向padding有效 但是margin不可以。</li><li>默认宽度就是它本身内容的宽度。</li><li>行内元素只能容纳文本或其他行内元素（a特殊）。</li></ul> 
<p>注意：</p> 
<ol><li>只有文字才能组成段落，因此p标签中不能放块级元素。</li><li>链接里面不能在放链接。</li></ol> 
<h3><a id="3inlineblock_597"></a>（3）行内块元素（inline-block）</h3> 
<p>在行内元素中有几个特殊的标签&lt;img /&gt;、&lt;input /&gt;，可以对它们设置宽高和对齐属性，称为行内块元素。</p> 
<p>特点：<br> （1）和相邻行内元素（行内块）在一行上，但是之间会有空白间隙。<br> （2）默认宽度就是它本身内容的宽度。<br> （3）宽高、内外边距都可以控制。</p> 
<h3><a id="4_display_605"></a>（4）标签显示模式转换 display</h3> 
<p>块转行内：display:inline;<br> 行内转块：display:block;<br> 块、行内元素转换为行内块：display:inline-block;</p>

<h3><a id="101_backgroundcolor_619"></a>10.1 背景颜色（background-color）</h3> 
<p>background-color属性设置一个元素的背景颜色。元素的背景是元素的总大小，包括填充和边界（但不包括边距）。<br> 指定背景颜色透明时可使用transparent作为属性值。</p> 
<pre><code>background-color: blue;
background-color: transparent;	/* 透明 */
</code></pre> 
<h3><a id="102_backgroundimage_626"></a>10.2 背景图片（background-image）</h3> 
<p>background-image属性设置一个元素的背景图像。元素的背景是元素的总大小，包括填充和边界（但不包括边距）。默认情况下，background-image放置在元素的左上角，并重复垂直和水平方向。</p> 
<p>语法格式：</p> 
<pre><code>background-image: url(&#x27;图片路径&#x27;);	/*设置图片显示*/
</code></pre> 
<h3><a id="103_backgroundrepeat_633"></a>10.3 背景平铺（background-repeat）</h3> 
<p>设置如何平铺对象的 background-image 属性。默认情况下，重复background-image的垂直和水平方向。</p> 
<p>语法格式：</p> 
<pre><code>background-repeat: repeat-x;  //表示向水平方向平铺
</code></pre> 
<table><thead><tr><th>值</th><th>描述</th></tr></thead><tbody><tr><td>repeat</td><td>背景图像将向垂直和水平方向重复 | 默认值</td></tr><tr><td>repeat-x</td><td>只有在水平方向会重复背景图像</td></tr><tr><td>repeat-y</td><td>只有在垂直方向会重复背景图像</td></tr><tr><td>no-repeat</td><td>不会重复</td></tr></tbody></table>
<h3><a id="104_backgroundposition_647"></a>10.4 背景位置（background-position）</h3> 
<p>background-position属性设置背景图像的起始位置<br> 第一个值表示水平方向，值增大时，意味着背景图片向右移动 减小 往左<br> 第二个值垂直方向，值增大时，背景图片向下移动，减小往上移动</p> 
<p>语法：</p> 
<pre><code>/*取值有left、right、top、bottom、center，如果仅指定一个关键字，其他值将会是&quot;center&quot;*/
/* 水平有left center right, 出垂直有top center bottom */
background-position: center; 关键词
background-position: 30% 20%; 百分比
background-position: 50px 100px; 固定值

(容器的宽度-图片的宽度)*百分比 = 图片最左边到容器左边的距离
(容器的高度-图片的高度)*百分比 = 图片最上边到容器上边的距离 
</code></pre> 
<h3><a id="105_backgroundattachment_663"></a>10.5 背景附着（background-attachment）</h3> 
<p>background-attachment设置背景图像是否固定或者随着页面的其余部分滚动。</p> 
<p>语法：</p> 
<pre><code>background-attachment:fixed; //表示视口固定，不会随着元素的内容滚动。
</code></pre> 
<table><thead><tr><th>值</th><th>说明</th></tr></thead><tbody><tr><td>scroll</td><td>背景相对于元素本身固定， 而不是随着它的内容滚动（对元素边框是有效的）| 默认值</td></tr><tr><td>fixed</td><td>背景相对于视口固定，不会随着元素的内容滚动。</td></tr></tbody></table>

<p>background: 背景颜色 背景图片地址 背景平铺 背景滚动 背景位置</p> 
<h3><a id="107_CSS3_678"></a>10.7 背景颜色透明（CSS3）</h3> 
<p>CSS3支持背景半透明的语法格式：</p> 
<pre><code>background: rgba(0, 0, 0, 0.5);
</code></pre> 
<p>alpha的取值范围在0~1之间<br> 同样可以给文字和边框透明，都是使用rgba的格式来写</p> 
<pre><code>color: rgba(255, 0, 0, 0.5);
border: 1px solid rgba(255, 0, 0, 0.5);
</code></pre> 
<h3><a id="108_CSS3_689"></a>10.8 背景缩放（CSS3）</h3> 
<p>通过background-size设置背景图片的尺寸<br> 1.可以设置长度单位（px）或百分比（设置百分比时，参照盒子的宽高）。<br> 当设置一个值时，第二个值为auto，横向展示为设置的值 ， 或者设置的百分比 * 盒子的宽度，纵向会按照原图宽高度等比缩放。</p> 
<p>2.设置为cover时，会自动调整缩放比例，保证图片始终填充满背景区域，如有溢出部分则会被隐藏。<br> 特点：会充满整个盒子，但是图片不一定能够显示完整</p> 
<p>3.设置为contain时，会自动调整缩放比例，保证图片始终完整显示在背景区域。<br> 特点：图片一定能显示完整，但是可能就不能充满盒子</p> 
<h3><a id="109_CSS3_699"></a>10.9 多背景（CSS3）</h3> 
<p>以逗号分隔可以设置多背景，可用于自适应布局。<br> 不同的背景图像用逗号隔开，并且图像会彼此堆叠，其中的第一幅图像最靠近观看者。前面的会堆叠在后面的上面</p> 
<h3><a id="1010_CSS3_702"></a>10.10 背景颜色渐变（CSS3）</h3> 
<p>CSS3 渐变（gradients）可以让你在两个或多个指定的颜色之间显示平稳的过渡。<br> CSS3 定义了两种类型的渐变（gradients）：</p> 
<ul><li>线性渐变（Linear Gradients）- 向下/向上/向左/向右/对角方向</li><li>径向渐变（Radial Gradients）- 由它们的中心定义</li></ul> 
<p>从上到下的线性渐变</p> 
<pre><code>background: linear-gradient(red, yellow);
</code></pre> 
<p>从左到右的线性渐变</p> 
<pre><code>background: linear-gradient(to right, blue, green); 
// 或者
background: linear-gradient(to left, blue, green); 
</code></pre> 
<p>对角方向的线性渐变</p> 
<pre><code>background: linear-gradient(to bottom right, blue, green);
</code></pre> 
<p>颜色结点均匀分布的径向渐变</p> 
<pre><code>background: radial-gradient(red, green, yellow);
</code></pre> 
<p>颜色结点不均匀分布的径向渐变</p> 
<pre><code>background: radial-gradient(red 20%, green 30%, yellow 50%);
</code></pre> 
<p>形状为圆形的径向渐变</p> 
<pre><code>background: radial-gradient(circle, red, green, yellow);
</code></pre>

<h2><a id="_CSS_784"></a>十一 盒子模型（CSS重点）</h2> 
<h3><a id="111__785"></a>11.1 盒子模型简介</h3> 
<p>盒子模型就是把HTML页面中的元素看作是一个矩形的盒子，也就是一个装内容的容器。每个矩形都由元素的内容、内边距（padding）、边框（border）和外边距（margin）组成</p> 
<h3><a id="112_Box_Model_787"></a>11.2 盒子模型（Box Model）</h3>

<h4><a id="4_border_797"></a>(4) 盒子边框（border）</h4> 
<p>边框就是元素最外层的包装。CSS边框属性允许你指定一个元素边框的样式和颜色。<br> 语法：</p> 
<pre><code>border： border-width  border-style  border-color
</code></pre>

<p><strong>圆角边框（CSS3）</strong><br> 使用 CSS3 border-radius 属性，你可以给任何元素制作 “圆角”。radius 半径（距离）</p> 
<h4><a id="5_padding_811"></a>(5) 内边距（padding）</h4> 
<p>padding属性用于设置内边距。是指边框与内容之间的距离。<br> <strong>padding</strong> <strong>:</strong> 上右下左内边距</p> 
<table><thead><tr><th>值的个数</th><th>表达意思</th></tr></thead><tbody><tr><td>1个值</td><td>padding: 四周内边距</td></tr><tr><td>2个值</td><td>padding: 上下、左右内边距</td></tr><tr><td>3个值</td><td>padding: 上、左右、下内边距</td></tr><tr><td>4个值</td><td>padding: 上、下、左、右内边距</td></tr></tbody></table>
<h4><a id="6_margin_822"></a>(6) 外边距（margin）</h4> 
<p>margin属性用于设置外边距。设置外边距会在元素之间创建“空白”，这段空白通常不能放置其他内容。<br> <strong>margin</strong> <strong>:</strong> 上右下左<br> <strong>注意</strong>：行内元素可以设置水平方向的内外边距，但不能设置垂直方向的内外边距。<br> <strong>外边距实现盒子居中方法：</strong><br> margin: 0 auto</p> 
<h4><a id="7__828"></a>(7) 外边距合并</h4> 
<p><strong>相邻块元素垂直外边距的合并</strong><br> 就是说垂直距离不是margin-bottom与margin-top之和，而是<strong>取两者中的较大者</strong><br> 解决方案：</p> 
<ol><li>想办法只给一个盒子加外边距</li><li>BFC规范</li></ol> 
<p><strong>嵌套块元素垂直外边距的合并</strong><br> 当两个块级元素嵌套时，如果内部的块设置有margin-top属性，而且父元素没有下边解决方法所述的特征，那么内部块的margin-top属性会绑架父元素，使其作用给父元素。<br> <strong>解决方案</strong>：</p> 
<ol><li>设置父元素或者自身的display:inline-block; （BFC规范）</li><li>设置父元素的border:1px solid #fff;(&gt;0) ；或者border-top(一定要包含border-top方向) 此方法如果不想影响元素高度 加上box-sizing:border-box;</li><li>设置父元素的padding:1px;(&gt;0); 或者padding-top(一定要包含padding-top方向) 此方法如果不想影响元素高度 加上box-sizeing:border-box;</li><li>给父元素设置overflow:hidden; （BFC规范）</li><li>给父元素或者自身设置position:absolute;（BFC规范）</li><li>设置父元素非空，填充一定的内容。（在父元素与当前子元素之间 加点具有高度的元素或内容分开父元素与当前子元素）</li></ol> 
<h4><a id="8__847"></a>(8) 盒子阴影</h4> 
<p>语法格式：</p> 
<pre><code>box-shadow: 水平位置  垂直位置  模糊距离  阴影尺寸扩大/缩小阴影  阴影颜色  内/外阴影;
</code></pre>

<h2><a id="_Float_861"></a>十二 浮动（Float）</h2> 
<h3><a id="121__862"></a>12.1 什么是文档流？</h3> 
<p>文档流处在网页的最底层，它表示的是一个页面中的位置，我们所创建的元素默认都处在文档流中</p> 
<h3><a id="122__864"></a>12.2 什么是浮动？</h3> 
<p>元素的浮动是指设置了浮动属性的元素会<strong>脱离标准普通流</strong>的控制，浮动的框可以向左或向右移动，但是会影响到正常文档流中的文字排版。<br> 本语法如下</p> 
<pre><code>选择器 {  float: 属性值;
}
</code></pre> 
<table><thead><tr><th>属性值</th><th>描述</th></tr></thead><tbody><tr><td>left</td><td>元素向左浮动</td></tr><tr><td>right</td><td>元素向右浮动</td></tr><tr><td>none</td><td>元素不浮动（默认值）</td></tr></tbody></table>
<h3><a id="123__877"></a>12.3 清除浮动</h3> 
<p><strong>清除浮动</strong>clear属性</p> 
<p>这个属性主要有三个值:</p> 
<ul><li> <p><code>left</code> 清除前面的左浮动元素带给我的影响</p> </li><li> <p><code>right</code>清除前面的右浮动元素带给我的影响</p> </li><li> <p><code>both</code> 同时清除前面的左右浮动元素带给我的影响. 一般情况下选择这个值比较方便.<br> 给父元素设置after伪类清除：设置父元素中的最后一个子元素 （推荐）</p> <pre><code>.clear:after{  display: block;  content: &quot;&quot;;  clear: both;
}
</code></pre> </li></ul> 
<h2><a id="__895"></a>十三 定位</h2> 
<h3><a id="131__896"></a>13.1 元素的定位属性</h3> 
<p>元素的定位属性主要包括<strong>定位模式</strong>和<strong>边偏移</strong>两部分</p> 
<p><strong>边偏移</strong></p> 
<table><thead><tr><th>边偏移属性</th><th>描述</th></tr></thead><tbody><tr><td>bottom</td><td>底部偏移量，定义元素相对于其父元素下边线的距离</td></tr><tr><td>top</td><td>顶端偏移量，定义元素相对于其父元素上边线的距离</td></tr><tr><td>left</td><td>左侧偏移量，定义元素相对于其父元素左边线的距离</td></tr><tr><td>right</td><td>右侧偏移量，定义元素相对于其父元素右边线的距离</td></tr></tbody></table>

<h3><a id="132_zindex_918"></a>13.2 叠放次序（z-index）</h3> 
<p>当多个元素同时设置定位时，定位元素之间有可能发生重叠。</p> 
<p>要想调整重叠定位元素的堆叠顺序，可以<strong>对定位元素</strong>使用z-index层叠等级属性，其取值可为正整数、负整数、0.。</p> 
<p>同级:</p> 
<p>​ 1 不加z-index 后来者居上<br> ​ 2 加z-index 值越大越在上面 如果值相等 还是后来者居上</p> 
<p>嵌套:</p> 
<p>​ 1 不加z-index 默认子元素在上<br> 2 只给子元素加z-index值&lt;0 可实现父元素为上<br> 3 如果给父元素也添加z-index 父元素无论怎样 子元素都将在父元素上</p> 
<p>嵌套+同层级：<br> 1 如果父元素有其他兄弟元素 如果两者都没加z-index 后来者居上<br> 2 两者父元素都没加z-index 若某一子元素z-index值大 那么该子元素将显示在上方 如果值相同 则后来者居上<br> 3 如果父级都加了z-index 那么在进行比较时 只比较父元素z-index值 值越大则父元素连同里面的子元素越靠上 如果值相等 后来者居上</p> 
<p>注意：</p> 
<p>数字后面不能加单位。</p> 
<p>只有相对定位、绝对定位、固定定位有此属性，其余标准流、浮动、静态定位都无此属性。</p> 
<p>flex盒子的子元素也可以设置z-index属性</p>

<h2><a id="_CSS3_animation_1059"></a>十七 CSS3动画 animation</h2> 
<p>动画是使元素从一种样式逐渐变化为另一种样式的效果， 可以改变任意多的样式任意多的次数。请用百分比来规定变化发生的时间，或用关键词 “from” 和 “to”，等同于 0% 和 100%。0% 是动画的开始，100% 是动画的完成。</p> 
<p>语法格式：<br> 设置在作用元素上 animation: 动画名字 动画时间 运动曲线 何时开始 循环次数 反向运动</p>

<p>animation-iteration-count 属性定义动画循环的次数。<br> 无限循环设置值为:infinite</p> 
<h3><a id="175_animationdirection_1095"></a>17.5 反向运动animation-direction</h3> 
<ul><li> <p><code>normal</code></p> <p>每个循环内动画向前循环，换言之，每个动画循环结束，动画重置到起点重新开始，这是默认属性，每次都是开始执行</p> </li><li> <p><code>reverse</code></p> <p>反向运行动画，每周期结束动画由尾到头运行。动画每次都是从尾部开始运行</p> </li><li> <p><code>alternate</code></p> <p>动画交替反向运行，反向运行时，动画按步后退，同时，带时间功能的函数也反向，比如，ease-in 在反向时成为ease-out。计数取决于开始时是奇数迭代还是偶数迭代，也就是第一次是正向的，第二次是反向的</p> </li><li> <p><code>alternate-reverse</code></p> <p>反向交替， 反向开始交替</p> <p>动画第一次运行时是反向的，然后下一次是正向，后面依次循环。决定奇数次或偶数次的计数从1开始。第一次是反向，后面是第二次是正向。</p> </li></ul>

<h2><a id="_CSS3_1117"></a>十八 CSS3多列显示</h2> 
<h3><a id="1columncountCSS3_1118"></a>（1）column-count（CSS3）</h3> 
<p>column-count用于指定某个元素应分为的列数。给多列容器指定列数后，在窗口尺寸发生变化时，浏览器会根据列数和容器宽度，自动计算出每列的宽度，以保证按照 3 列进行布局。</p> 
<p>取值如下：</p> 
<ul><li>数值：将元素的内容以指定的列数显示</li><li>auto：列数将取决于其他属性，例如：“column-width”</li></ul> 
<h3><a id="2columnwidthCSS3_1126"></a>（2）column-width（CSS3）</h3> 
<p>column-width指定列的宽度。取值如下：</p> 
<ul><li>length：指定列宽的长度</li><li>auto：浏览器将决定列的宽度</li></ul> 
<p>根据W3C标准，column-width属性值实际上是给浏览器建议的最佳宽度，实际的列宽可以根据容器空间的大小进行调整。调整规则如下：</p> 
<ol><li>当容器可用空间足够大时，实际的列宽可能大于所设置的列宽。</li><li>当容器的宽度小于设置的列宽时，将以容器的宽度作为列宽</li></ol> 
<h3><a id="3columnspanCSS3_1137"></a>（3）column-span(CSS3)</h3> 
<p>column-span属性指定某个元素应该跨越多少列(只有1和all)。column-span: 只能对块级（block）标签有效取值如下：</p> 
<ul><li>none：不跨列 默认，如果元素超过当前列宽度，文字将会向下列延伸</li><li>all：该元素应该跨越所有列</li></ul> 
<h3><a id="4columngapCSS3_1142"></a>（4）column-gap（CSS3）</h3> 
<p>column-gap的属性指定的列之间的间隙。取值如下：</p> 
<ul><li>length：一个指定的长度，将设置列之间的差距</li><li>normal：指定一个列之间的普通差距。 W3C建议1EM值</li></ul> 
<h3><a id="5columnruleCSS3_1147"></a>（5）column-rule（CSS3）</h3>

<h2><a id="_CSS3_Flex_Box_1204"></a>十九 CSS3 弹性盒子(Flex Box)</h2> 
<p>CSS3弹性盒子相对于普通盒子更为灵活性<br> <strong>容器项目</strong><br> <strong>容器：</strong> 设置了弹性盒子的这个盒子就叫容器<br> <strong>项目：</strong> 容器的子元素就称为项目<br> <strong>怎么设置弹性盒子呢？</strong> display: flex;<br> <strong>主轴与交叉轴</strong><br> <strong>主轴：</strong> 我们规定水平或者垂直方向是主轴方向 默认是水平方向 — 元素默认在主轴方向上排列<br> <strong>交叉轴：</strong> 与主轴垂直的方向 默认垂直反向</p> 
<p><strong>容器属性：</strong></p> 
<ul><li>flex-direction</li><li>flex-wrap</li><li>justify-content</li><li>align-items</li><li>align-content</li></ul> 
<p><strong>flex-direction属性</strong></p> 
<p>flex-direction属性决定主轴的方向（即项目的排列方向）：</p> 
<ul><li>row（默认值）：主轴为水平方向，起点在左端。</li><li>row-reverse：主轴为水平方向，起点在右端。</li><li>column：主轴为垂直方向，起点在上沿。</li><li>column-reverse：主轴为垂直方向，起点在下沿。</li></ul> 
<p><strong>flex-wrap属性</strong><br> 容器没有剩余空间时 项目是否换行</p> 
<ul><li>nowrap（默认）：不换行。</li><li>wrap：换行</li><li>wrap-reverse：换行，第一行在下方。</li></ul> 
<p><strong>justify-content</strong><br> 项目在主轴方向上的排列方式</p> 
<ul><li>flex-start 默认值 项目靠着起始位置</li><li>flex-end 项目靠着结束位置</li><li>center 项目居中</li><li>space-between 两端对齐 中间有空隙</li><li>space-around 项目左右两侧之间的间隙相等</li><li>space-evenly 项目左右两侧之间的间隙相等 也等于项目之间的间隙</li></ul> 
<p><strong>align-items</strong><br> 项目在交叉轴方向上的排列方式</p> 
<ul><li>flex-start 默认值 项目靠着上沿位置</li><li>flex-end 项目靠着下沿位置</li><li>center 项目居中</li><li>baseline 项目中第一行文字基线对齐</li><li>stretch<br> 如果项目有高度 效果与flex-start一样<br> 如果项目没有高度/auto 项目的高度将会拉甚至容器的高度</li></ul> 
<p><strong>align-content</strong><br> 定义多根轴线（比如换行）项目在交叉轴的排列方式</p> 
<ul><li>flex-start 靠着交叉轴的上沿位置</li><li>flex-end 靠着交叉轴的下沿位置</li><li>center 居中</li><li>space-between 两端对齐 中间有空隙</li><li>space-around 项目上下两侧之间的间隙相等</li><li>stretch 默认值<br> 项目没有高度/auto 拉甚至交叉轴垂直方向的高度 容器的高度一半<br> 项目有高度 容器折半的高度 上一行 靠着上边的高度上沿 下一行靠着下边的高度上</li></ul> 
<p><strong>项目属性：</strong></p> 
<p><strong>flex-grow</strong><br> 容器还有剩余空间 项目是否变大填充容器<br> &gt;=0<br> 比例<br> 0 默认值 不放大<br> 1 放大比例为1<br> 所有项目都为1 所有项目一起平分容器剩余空间<br> 某个项目为1 其余不设置默认为0 为1的项目分走容器剩余空间<br> 某两个项目分为1.5 0.5 比例为3：1 所以设置为1.5项目分走容器3/4剩余空间</p> 
<p><strong>flex-shrink</strong><br> 容器剩余空间不足 项目是否缩小<br> &gt;=0<br> 比例<br> 0 不缩小<br> 所有项目为1 默认值 所有项目一起缩小 缩小一样的值<br> 例子：假设所有项目宽之和为900 容器宽500 900-500 = 400</p> 
<pre><code>  三个项目设置flex-shrink 分别为：1.5 0.5 1  1.5：0.5：1  3:1:2  那么三个项目实际宽分别为 ： 3/6*400 1/6*400 2/6*400
</code></pre> 
<p><strong>align-self</strong><br> 项目自身在交叉轴上的排列方式 覆盖容器的属性</p> 
<ul><li>flex-start 项目靠着上沿位置</li><li>flex-end 项目靠着下沿位置</li><li>auto 默认值 按照容器的align-items属性值排列</li><li>baseline 文字基线</li><li>center 居中</li><li>stretch<br> 如果项目有高度 效果与flex-start一样<br> 如果项目没有高度/auto 项目的高度将会拉甚至容器的高度</li></ul> 
<p><strong>完美的居中</strong><br> 使用弹性盒子，居中变的很简单，只需要给子元素设置 <strong>margin: auto;</strong> (设置margin为auto，自动获取弹性容器中剩余空间)可以使得弹性子元素在两轴方向上完全居中。</p> 
<h2><a id="_CSS3_Media_Queries_1308"></a>二十 CSS3多媒体查询 Media Queries</h2> 
<p>@media可以针对不同的媒体类型(包括显示器、便携设备、电视机，等等)设置不同的样式规则，实现适应显示。媒体查询可用于检测很多事情，例如：</p> 
<ul><li>viewport(视窗) 的宽度与高度</li><li>设备的宽度与高度</li><li>朝向 (智能手机横屏，竖屏) 。</li><li>分辨率</li></ul> 
<p>目前很多针对苹果手机，Android 手机，平板等设备都会使用到多媒体查询。</p> 
<h3><a id="1_1319"></a>（1）多媒体查询语法</h3> 
<p>多媒体查询由多种媒体组成，可以包含一个或多个表达式，表达式根据条件是否成立返回 true 或 false。</p> 
<pre><code>@media not|only mediatype and (expressions) {  CSS 代码...;
}
@media only speech and (min-width: 500px){  CSS 代码...;
}
</code></pre> 
<ul><li> <p><strong>not:</strong> 用来排除掉特定的设备，比如 @media not print（非打印设备）。</p> </li><li> <p><strong>only:</strong> 用 来规定某种特别的媒体类型。 表示只有 仅仅，表示某一种的媒体类型设备。</p> </li><li> <p><strong>and</strong>: 表示并且，要求必须满足所有的表达式要求时，才能使用media定义样式</p> </li></ul> 
<h3><a id="2CSS3_1335"></a>（2）CSS3多媒体类型</h3> 
<table><thead><tr><th>值</th><th>描述</th></tr></thead><tbody><tr><td>all</td><td>用于所有多媒体类型设备</td></tr><tr><td>print</td><td>用于打印机</td></tr><tr><td>screen</td><td>用于电脑屏幕，平板，智能手机等。</td></tr><tr><td>speech</td><td>用于屏幕阅读器</td></tr></tbody></table>
<h3><a id="3_1343"></a>（3）常用的条件</h3> 
<p>max-width： 输出设备中页面最大可视区域宽度，小于这个width时，其中的css生效</p> 
<p>min-width： 输出设备中页面最小可视区域宽度，大于这个width时，其中的css生效</p> 
<p>max-height： 输出设备中页面最大可视区域高度</p> 
<p>min-height： 输出设备中页面最小可视区域高度</p> 
<h3><a id="4_1352"></a>（4）媒体查询两种方式</h3> 
<p>第一种：link的方式：</p> 
<pre><code>&lt;link rel=&quot;stylesheet&quot; media=&quot;screen and (min-width:600px) and (max-width:900px)&quot; href=&quot;./css/green.css&quot;&gt;
</code></pre> 
<p>第二种：css的方式：</p> 
<pre><code> /*使用关键词&quot;and&quot;将多个媒体特性结合在一起*/  @media screen and (min-width:600px) and (max-width:900px){  body {  background-color:blue;  }  }
</code></pre> 
<h2><a id="__1366"></a>二十一 移动端布局</h2> 
<h3><a id="1_1367"></a>（1）布局概念</h3> 
<p><strong>1. 静态布局</strong></p> 
<p>​ 直接使用px作为单位 不推荐 不会适应屏幕</p> 
<p>​ <strong>2. 流式布局</strong></p> 
<p>​ 宽度使用%百分比，高度使用px作为单位</p> 
<p>​ 通常还会加上最大值和最小值</p> 
<p>​ <strong>3. 自适应布局</strong></p> 
<p>​ 创建多个静态布局，每个静态布局对应一个屏幕分辨率范围。使用 @media媒体查询来切换多个布局</p> 
<p>​ <strong>4. 响应式布局</strong></p> 
<p>​ 通常是糅合了流式布局+弹性布局，再搭配媒体查询技术使用</p> 
<p>​ <strong>5. 弹性布局</strong></p> 
<p>​ rem或em布局。rem是相对于html元素的font-size大小而言的，</p> 
<p>​ em是相对于自身的font-size大小 1em = font-size的值</p> 
<p>​ 如果自己没有则相对自己最近的祖先font-size大小(其实也是相对于自己的font-size，因为font-size可以被继承)</p> 
<p>​ 如果所有的祖先都没有设置font-size属性，那么就会相对浏览器font-size的默认值大小，大部分浏览器默认都是16px</p> 
<h3><a id="2_1395"></a>（2）基本概念</h3> 
<h4><a id="1_1396"></a>1、物理像素</h4> 
<ul><li> <p>物理像素点指的是屏幕显示的最小颗粒，是物理真实存在的，这是厂商出厂时就设置好了，比如iPhone 678是750*1334，其实也就是我们通常所说的屏幕分辨率。</p> <p>也就是说在iPhone 678 一行可以放750个像素点，一列可以放1334个像素点</p> </li><li> <p>开发时1px不一定等于一个物理像素</p> </li><li> <p>PC端，1px等于一个物理像素，因为PC端屏幕宽度和分辨率一样，但移动端就不尽相同，比如iPhone8，分辨率为750，但屏宽却是375px</p> </li><li> <p>1px能显示的物理像素点的个数成为物理像素比或屏幕像素比</p> <p>比如iPhone8中 375px屏宽 意味着375px占满整屏，而横向分辨率却是750 所以1px = 2物理像素</p> </li></ul> 
<h4><a id="2device_pixel_ratio_1412"></a>2、设备像素比(device pixel ratio)</h4> 
<p>物理像素比 = 物理像素(屏幕分辨率) / 设备独立像素(屏幕尺寸或者开发尺寸)</p> 
<h4><a id="3Retina_1415"></a>3、视网膜屏幕Retina</h4> 
<p>Retina为高清设备屏幕，是一种显示技术，可以将更多的物理像素点压缩到一块屏幕里，从而提高屏幕设备屏幕分辨率，并提高屏幕显示的细腻程度。<br> 原理：原本图片1px = 1物理像素，但现在，我们只有1px这么宽却要显示2物理像素这么长，没有办法，只好把原像素撑大，相当于是图片放大，可以想象成我们的背景缩放</p> 
<p>这种对盒子或者是文字来说影响并不大</p> 
<p>一般的解决方案是提供<strong>2倍图</strong>，先准备一张宽100 高100 的图片 然后手动将图片的宽高设置为50*50，再放到手机里，会对当前图片放到50的2倍就是100，那么图片本身就是100宽高，这样的话图片就不会再模糊了。</p> 
<h4><a id="4_viewport_1423"></a>4、视口 viewport</h4> 
<p>视口就是浏览器显示页面内容的屏幕区域，视口可分为布局视口，视觉视口和理想视口。</p> 
<h5><a id="1layout_viewport_1425"></a>（1）布局视口layout viewport</h5> 
<p>一般移动设备的浏览器都默认设置了一个布局视口，用于解决早期的PC端页面在手机上显示的问题</p> 
<p>在PC端上，布局视口等于浏览器窗口的宽度。而在移动端上，由于要使为PC端浏览器设计的网站能够完全显示在移动端的小屏幕里，此时的布局视口会远大于移动设备的屏幕，980px远大于320px等移动设备屏幕，所以导致元素很小，如果想要看清只能缩放，但这样就会出现横线滚动条。</p> 
<h5><a id="2layout_viewport_1429"></a>（2）布局视口layout viewport</h5> 
<p>用户正在看到的网站区域</p> 
<p>视觉视口用户正在看到的网页的区域。用户可以通过缩放来查看网站的内容。如果用户缩小网站，我们看到的网站区域将变大，此时视觉视口也变大了，同理，用户放大网站，我们能看到的网站区域将缩小，此时视觉视口也变小了。不管用户如何缩放，都不会影响到布局视口的宽度。</p> 
<h5><a id="3ideal_viewport_1433"></a>（3）理想视口ideal viewport</h5> 
<p>在手机屏幕能显示完整的网页，并且不需要用户手动缩放调整页面大小，文字和网页元素宽高合适。</p> 
<p>布局视口的一个理想尺寸，只有当布局视口的尺寸等于设备屏幕的尺寸时，才是理想视口。</p> 
<h5><a id="4meta_1438"></a>（4）meta视口标签</h5> 
<p>在开发移动端页面，我们需要手动设置meta视口标签通知浏览器操作以达到使用理想视口的目的：</p> 
<p>布局视口的宽度应该与理想视口宽度一致，简单理解就是设备有多宽，布局视口就多宽</p> 
<pre><code>1、完整标准视口标签写法 width=device-width: 表示视口与设备宽度一致 就是理想视口-
&lt;meta name=&quot;viewport&quot; content=&quot;width=device-width, initial-scale=1.0, maximum-scale=1.0, minimum-scale=1.0,user-scalable=no&quot;&gt;
2、简单写法
&lt;meta name=&quot;viewport&quot; content=&quot;width=device-width, initial-scale=1.0&quot;&gt;
</code></pre> 
<table><thead><tr><th>属性</th><th>解释说明</th><th>标准viewport设置</th></tr></thead><tbody><tr><td>initial-scale</td><td>初始缩放比，大于0的数字 0-1视口缩小 &gt;1视口放大</td><td>视口缩放比例</td></tr><tr><td>width</td><td>宽度设置的是viewport宽度，可以设置device-width特殊值</td><td>视口宽度和设备保持一致</td></tr><tr><td>maximum-scale</td><td>最大缩放比，大于0的数字</td><td>最大允许的缩放比例1.0</td></tr><tr><td>minimum-scale</td><td>最小缩放比，大于0的数字</td><td>最小允许的缩放比例1.0</td></tr><tr><td>user-scalable</td><td>用户是否可以缩放，yes或no(1或0)</td><td>不允许用户自行缩放</td></tr></tbody></table>
<h4><a id="5rem_1457"></a>5、rem单位</h4> 
<ul><li> <p><strong>em</strong>：<strong>以父元素的</strong>font-size来计算，如父元素的font-size: 16px ; 1em = 16px</p> </li><li> <p><strong>rem</strong>：相对于<strong>根元素html</strong>标签的font-size来做计算，如html的font-size: 16px; 1rem = 16px</p> </li></ul> 
<p><strong>rem如何实现自适应设备</strong></p> 
<p><strong>实际的元素 / 设计的元素 == 实际的页面 / 设计的页面</strong><br> 所谓&quot;设计&quot;就是我们写代码期望网页呈现出来的样子，所有元素的大小和位置都和我们预想的一摸一样。通常在电脑端呈现出来的就是和设计的是一样的，但是移动端由于屏幕比电脑端小，呈现出来的样子就会不太一样，错位时有发生，所以才需要适配。</p> 
<p>​ 如果上面的等式恒成立，则说明适配成功。实际的元素 == 设计的元素 * （ 实际的页面 / 设计的页面），也就是是说需要知道（ 实际的页面 / 设计的页面）,设为k。试想，如果css中有一个属性能知道这个比例k,那么适配问题就已经完美解决了。可惜，并没有这个属性。但是,幸运的是，rem可以充当我们和这个比例之间的桥梁，rem可以看作一个单位，它可以和根元素的文字大小关联，也就是说把html的font-size设为k，比如设备屏幕尺寸是300px,设计稿宽度是600px,则html的字体大小就是320/640 = 0.5px，没错，这个值一般都很小，但是font-size的值一般在10px以上，虽然html里的font-size肯定会被下面设置的font-size所覆盖，但是出于习惯，还是会将这个k值乘上一个系数，一般是100。</p> 
<p>​ 这样，我们就找到了页面上不变的东西，就可以以不变应万变。至此，页面上所有元素的大小都可以用rem，或者说比例k来表示。</p> 
<p><strong>实际大小（rem） = 测量的大小（px）/ html的font-size大小（px）</strong></p> 
<p><strong>视窗单位</strong></p> 
<ul><li>vw : 1vw 等于视窗宽度的1%</li><li>vh : 1vh 等于视窗高度的1%</li><li>vmin : 选取 vw 和 vh 中最小的那个 700 * 900 100vmin</li><li>vmax : 选取 vw 和 vh 中最大的那个 1700 * 900 100vmax</li></ul>

</code></pre> 
<h3><a id="2CSScalc_1486"></a>（2）CSS很多长度都可以与calc()一起使用</h3>
