一、let

let跟var一样都是用来声明变量的，它跟var的区别在于作用域：
var的作用域被规定为一个函数作用域，而let则被规定为块作用域，块作用域要比函数作用域小一些，但是如果两者既没在函数中，也没在块作用域中定义，那么两者都属于全局作用域。

let与var区别如下：

在全局作用域下：

  var a='ljy'  let b='jjj'  console.log(window.a,window.b)


被let声明的变量不会作为全局对象window的属性，而被var声明的变量却可以

在函数作用域下：

  function fn(){  var a='ljy'  let b='jjj'  }

var 和 let 在函数作用域中声明一个变量，两个变量的意义是相同的。

在块作用域下
let只在块作用域内部可用，而 var则在块作用域外部也能用。
块作用域：大括号括起来的就表示一个块作用域，比如：if,for,或者直接写的大括号等等。

  {  var a='ljy'  let b='jjj'  console.log(a, b)  }  console.log(a,b)


for循环中

  for(var i=0;i<5;i++){  setTimeout(()=>{console.log(i)},1000)  }


Var的时候，Settimeout本身是同步的， 但它里面的函数是异步的， for每次循环的时候setTimeout也会执行 ，但是setTimeout里面的函数不会执行， 会被放入到异步队列中 ，等待主任务for循环结束后,再从异步队列打印出东西，此时循环完i的值变为了5，所以打印了5次5。

而使用let就实现了依次打印0到4

  for(let i=0;i<5;i++){  setTimeout(console.log(i),1000)  }

使用 let 声明迭代变量时，JavaScript 引擎在后台会为每个迭代循环声明一个新的迭代变量。每个 setTimeout 引用的都是不同的变量。所以打印的是0,1,2,3,4

let 和var 重新声明
var允许在同一作用域中声明同名的变量，而let不可以

  let a=1  let a=2  console.log(a)


let相对来说严格些，在同一块级作用域下不能有重复的变量名。

变量提升
let不存在变量提升，var存在变量提升

  console.log(a)  let a=1

二、const

const跟let相类似，不同的是定义的变量不可以修改，而且必须初始化。

  const a=2  a=3  console.log(a)

三、解构赋值

什么是解构赋值：声明标识符，按照某种数据模型，解析并赋值给声明的标识符

解构对象

基本赋值：

  var obj={a:10,b:'ljy'}  var {a,b}=obj  console.log(a,b)

无声明赋值

一个变量可以独立于其声明进行解构赋值。

  var obj={a:10,b:'ljy'}  var a,b;  ({a,b}=obj)  console.log(a,b)


注意：赋值语句周围的圆括号 ( … ) 在使用对象字面量无声明解构赋值时是必须的。

给新的变量名赋值

可以从一个对象中提取变量并赋值给和对象属性名不同的新的变量名。

  var obj={a:22,b:'ljy'}  var {a:age,b:name}=obj  console.log(age,name)

默认值

变量可以先赋予默认值。

  var obj={a:22,b:'ljy'}  var {a=10,b=1,c=11}=obj  console.log(a,b,c)


如果赋值的是undefined则不会覆盖默认值。

  var obj={a:undefined,b:'ljy'}  var {a=10,b=1,c=11}=obj  console.log(a,b,c)

解构数组

变量声明并赋值时的解构

  var [a,b,c]=[1,2,3]  console.log(a,b,c)

变量先声明后赋值时的解构

通过解构分离变量的声明，可以为一个变量赋值。

  var a,b,c  [a,b,c]=[1,2,3]  console.log(a,b,c)

默认值

为了防止从数组中取出一个值为undefined的对象，可以在表达式左边的数组中为任意对象预设默认值。

  var [a=5,b=0,c=3]=[1,2]  console.log(a,b,c)

交换变量

在一个解构表达式中可以交换两个变量的值。
没有解构赋值的情况下，交换两个变量需要一个临时变量

  var a=1;  var b=2;  [a,b]=[b,a];  console.log(a,b)

解析一个从函数返回的数组

从一个函数返回一个数组是十分常见的情况。解构使得处理返回值为数组时更加方便。

  function fn(){  return [1,2];  }  var a,b;  [a,b]=fn();  console.log(a,b)

忽略某些返回值

你也可以忽略你不感兴趣的返回值：

  function fn(){  return [1,2,3];  }  var a,b;  [a,,b]=fn();  console.log(a,b)

将剩余数组赋值给一个变量

当解构一个数组时，可以使用剩余模式，将数组剩余部分赋值给一个变量。

  var [a,...b]=[1,2,3,4]  console.log(a,b)

四、新增基本数据类型 symbol

Symbol (符号)是 ECMAScript 6 新增的一种基本数据类型。符号是原始值，且符号实例是唯一、不可变的。符号的用途是确保对象属性使用唯一的标识符，不会发生属性冲突的危险，符号就是用来创建唯一记号，进而用作非字符串形式的对象属性。
简单来说： 独一无二的数据，解决我们业务中使用字符串冲突的问题。比如：标识符命名不希望发生冲突的问题。

  var a=Symbol('hello')  var b=Symbol('hello')  console.log(a,b,a==b)

五、新增引用数据类型 Map和Set

JS中Map和Set的区别：

MapSet
所有元素都是键+值存在所得元素只有key没有value，value就是key
不允许键重复不允许出现键值重复
所有元素通过键进行自动排序的所有元素都会被自动排序
map的键是不能修改的，但是其键对应的值是可以修改的不能通过迭代器来改变set的值，因为set的值就是键

Map

Map是一组键值对的结构，具有极快的查找速度。
它由set方法存入数据，get方法取出数据。
跟object的区别：键名可以为任意数据，没有语法糖。
引用数据作为键名key时，取值也必须是同一个引用。
取出一个学生的成绩：

  var map1=new Map([['张三',90],['李四',80],['王五',70]])  //当需要取出张三成绩  console.log(map1.get('张三'))

当key为引用数据时:

  var arr=[1,2,3]  var map1=new Map()  map1.set(arr,200)  arr.push(100)  console.log(map1.get(arr))

如何遍历Map数据：
利用Map对象的forEach方法，仿照的数组的forEach

  var map1=new Map([[1,2],[3,4],[5,6]])  map1.forEach(function(a,b){  console.log(b,a);  })


使用for of循环出Map,key代表键名，value代表键值

  var map1=new Map([[1,2],[3,4],[5,6]])  for(var [key,value] of map1){  console.log(key+'==>'+value)  }

数组和Map之间的转换：

二维数组转Map，直接作为Map参数传入

  var arr=[[1,2],[3,4],[5,6]]  var map1=new Map(arr)  console.log(map1)

一维数组转Map，将其用[ ]，括起来传入

  var arr=[1,2]  var arr1=[3,4]  var arr2=[5,6]  var map1=new Map([arr,arr1,arr2])  console.log(map1)


Map转数组，利用数组的静态方法==>Array.from()

  var map1=new Map([[1,2],[3,4],[5,6]])  var arr=Array.from(map1)  console.log(arr)

Map的合并：利用…来合并

  var map1=new Map([[1,2],[3,4]])  var map2=new Map([[5,6]])  var map3=new Map([...map1,...map2])  console.log(map3)

Set

Set和Map类似，也是一组key的集合，但不存储value。由于key不能重复，所以，在Set中，没有重复的key。
添加元素通过add(key)方法，删除元素通过delete(key)方法。

可用于数组去重：

  var arr=[100,100,200,200,300]  var set1=new Set(arr)  arr1=Array.from(set1)  console.log(arr1)


补充： 数组去重的几个方法
方法一，利用对象的键名来实现：

  var arr=[100,100,200,200,300]  var obj={}  for(var i=0;i<arr.length;i++){  obj[arr[i]]=0;  }  var arr1=Object.keys(obj)  console.log(arr1)


方法二，for循环实现：

  var arr=[100,100,200,200,300]  var arr2=[]  for(var i=0;i<arr.length;i++){  arr2[i]=arr[i]  for(var j=i+1;j<arr.length;j++){  if(arr[i]==arr[j]){  arr2.splice(i,1)  }  }  }  arr2=arr2.filter(function(a){  //去除splice删除后的空白元素  if(a!==''){  return true  }  })  console.log(arr2)

字符串数字新出功能

includes()

includes() 方法用于判断字符串是否包含指定的子字符串。
如果找到匹配的字符串则返回 true，否则返回 false。

  var str="ljy6 66"  console.log(str.includes(" "))

startsWith()

startsWith() 方法用于检测字符串是否以指定的子字符串开始。
如果是以指定的子字符串开头返回 true，否则 false。
startsWith() 方法对大小写敏感。

  var str="ljy6 66"  console.log(str.startsWith("ljy"))

endsWith()

endsWith() 方法用来判断当前字符串是否是以指定的子字符串结尾的（区分大小写）。
如果传入的子字符串在搜索字符串的末尾则返回 true，否则将返回 false。

  var str="ljy6 66"  console.log(str.endsWith("66"))

repeat()

repeat() 方法字符串复制指定次数。

  var str="ljy666"  console.log(str.repeat(5))

padStart()

padStart() 方法用另一个字符串填充当前字符串 (如果需要的话，会重复多次)，以便产生的字符串达到给定的长度。从当前字符串的左侧开始填充。

  var str="ljy666"  console.log(str.padStart(9,'LJY'))

padEnd()

padEnd() 方法会用一个字符串填充当前字符串（如果需要的话则重复填充），返回填充后达到指定长度的字符串。从当前字符串的末尾（右侧）开始填充。

  var str="ljy666"  console.log(str.padEnd(9,'LJY'))

模板字符串(``)

模板字符串使用反引号 (` `) 来代替普通字符串中的用双引号和单引号。模板字符串可以包含特定语法（${expression}）的占位符。在模版字符串内使用反引号（`）时，需要在它前面加转义符（\）。

换行显示使用转义字符 /n

  var a=123  var str=`hello${a}\nh5`  console.log(str)

也可直接换行

  var a=123  var str=`hello${a}
h5`  console.log(str)

isNaN(x)

全局函数isNaN()用于判断是不是数字，不是数字就返回true(有隐式转换)
Number的isNaN()方法用于判断是不是NaN,如果给定值为 NaN则返回值为true；否则为false。

  var x='123456'  console.log(isNaN(x))


  var x=NaN  console.log(Number.isNaN(x))

对象数组的新功能

…扩展运算符

可将对象，数组，map成员遍历出来

合并对象：

  var x={name:'ljy',age:22}  var y={ID:1}  var z={...x,...y}  console.log(z)

Array.of()

Array.of() 方法创建一个具有可变数量参数的新数组实例，而不考虑参数的数量或类型。

  var re=Array.of(10,203,40)  console.log(re)  var re1=Array.of(5)  console.log(re1)  var re2=Array(5)  console.log(re2)

Array.from()

Array.from() 方法对一个类似数组或可迭代对象创建一个新的，浅拷贝的数组实例。

  var arr=Array.from([10,20,30],function(el){  return el*2  })  console.log(arr)

Array.find()

find() 方法返回数组中满足提供的测试函数的第一个元素的值。否则返回 undefined。

  var arr=[1,2,3,19,20]  console.log(arr.find(function(el) {  if (el > 18) {  return true  }  }))

findIndex()

findIndex()返回数组中通过测试的第一个元素的索引。

  var re=[9,20,18]  var re2=re.findIndex(function(el) {  if (el > 18) {  return true  }  })  console.log(re,re2)

fill

fill()方法用静态值填充数组中的指定元素
可以指定开始和结束填充的位置。如果未指定，则将填充所有元素。
返回值：数组，改变后的数组。
注意：fill() 会覆盖原始数组。

参数描述
value必需。用于填充数组的值
start可选。开始填充数组的索引（默认为 0）。（包括start）
end可选。停止填充数组的索引（默认为 array.length）。(不包括end)
  var arr=[10,203,30,,,,10]  var re=arr.fill("hello",2,4)  console.log(re,arr)

flat

flat() 方法会按照一个可指定的深度递归遍历数组，并将所有元素与遍历到的子数组中的元素合并为一个新数组返回。

参数：
depth 可选
指定要提取嵌套数组的结构深度，默认值为 1。

返回值
一个包含将数组与子数组中所有元素的新数组。

		var arr=[1,2,3,[[[[1]]]]]  var arr2=arr.flat(9)  console.log(arr,arr2)

箭头函数

ES6 中引入了箭头函数。
箭头函数允许我们编写更短的函数
对于箭头函数，this 关键字始终表示定义箭头函数的对象。

  var fn = () => {  return "Hello World!";  }  console.log(fn())

如果函数只有一个语句，并且该语句返回一个值，则可以去掉括号和 return 关键字：

hello = () => "Hello World!";

如果有参数，则将它们传递到括号内：
带参数的箭头函数：

hello = (val) => "Hello " + val;

如果只有一个参数，也可以略过括号：

hello = val => "Hello " + val;

类 class

类是用于创建对象的模板。
我们使用 class 关键字来创建一个类，类体在一对大括号 {} 中，我们可以在大括号 {} 中定义类成员的位置，如方法或构造函数。
每个类中包含了一个特殊的方法 constructor()，它是类的构造函数，这种方法用于创建和初始化一个由 class 创建的对象。

  class Person{  constructor(arg,arg2){  this.arg=arg  this.arg2=arg2  this.life=1  }  }  // constructor官方提供的 必须写这个单词, 可以不写这个 ,系统会默认内置一个空的constructor  var p1=new Person("100",200)  console.log(p1)

类的继承

Class 可以通过extends关键字实现继承，子类继承父类（除static定义的静态方法和属性外）的所有属性和方法。

Object.getPrototypeOf 方法可以用来从子类上获取父类。
可以使用这个方法判断，一个类是否继承了另一个类。

  class grade {  constructor() {  this.grade='19级'  }  say(){  console.log(this.name)  }  }  class student extends grade{  constructor(id,name,age) {  super();  this.id=id  this.name=name  this.age=age  super.say()  }  }  let a=new student(1,'ljy',22)  console.log(a)  a.say()  console.log(Object.getPrototypeOf(student)===grade)

static

类相当于实例的原型，所有在类中定义的方法，都会被实例继承。如果在一个方法前，加上static关键字，就表示该方法不会被实例继承，而是直接通过类来调用，这就称为“静态方法”。

  class Teacher{  constructor(name){  this.name=name  this.say2=function(){}  }  static a=20//静态属性  static say3(){}//静态方法  //对象的属性  b=100  //原型对象的方法  say(){  console.log(this.name)  }  }  var t1=new Teacher("karen")  console.log(t1)  t1.say()  console.log(Teacher.say3,Teacher.a)  console.log(typeof Teacher)

super

super作为函数调用时，代表父类的构造函数。ES6 要求，子类的构造函数必须执行一次super函数。super内部的this指向使用super的实例

super()作为对象时，在普通方法中，指向父类的原型对象；在静态方法中，指向父类。

		class grade {  constructor() {  this.grade='19级'  }  say(){  console.log(this.name)  }  }  class student extends grade{  constructor(id,name,age) {  super();  this.id=id  this.name=name  this.age=age  super.say()  }  }  let a=new student(1,'ljy',22)  console.log(a)

模块化

模块化主要是用于管理代码，解决解耦与复用问题
官方的标准模块化规范, 通过 import 和 export 导入导出模块内的成员, 未被导出的成员, 无法导入使用

1. 导出 export

(1) 单变量函数导出：
	export let name='ljy'
	export let fn=()=>{console.log(111)};
(2) 批量导出：
		let a=10;  let name='ljy';  export {a,name};
(3) 默认导出：

默认导出是在 export 关键词后面再跟上一个 default 表示导出的该变量或函数是匿名的，一个模块只能默认导出一次

	export default {  name:'ljy',  say(){  console.log(666)  }
	};

2.导入 import

大括号中的变量或函数名必须与导出时的名称一模一样：
与from关联使用，此时script标签的type必须设置为module

  import {name,fn} from "./1.js"  console.log(name,fn)

如果我们想修改导入的变量或函数的名称，可以通过 as 关键词来命名：

  import {name as a,fn as b} from "./1.js"  console.log(a,b)

如果我们要想将所有的变量或函数都导入，可以通过 * 来整体导入： as后面是用来保存所有变量或函数的对象名，可通过对象访问成员的法访问变量或函数。

  import * as a from "./1.js"  console.log(a,a.name)  a.fn()

去掉 {} ，接收的就是默认导出的变量，导出的变量是匿名的，可以随意地起个变量名用于接收：

  import obj from "./1.js"  console.log(obj)  obj.say()

全局方法

alert()

alert() 方法用于显示带有一条指定消息和一个 OK 按钮的警告框。

  var x='hello'  alert(x)

confirm()

confirm() 方法用于显示一个带有指定消息和 OK 及取消按钮的对话框

  confirm("你确定支付吗?")

setinterval()

setinterval()是定时调用的函数，可按照指定的周期（以毫秒计）来调用函数或计算表达式。setinterval()的作用是在播放动画的时，每隔一定时间就调用函数，方法或对象。setInterval() 方法会不停地调用函数，直到 clearInterval() 被调用或窗口被关闭。

  var i=0;  var re=setInterval(()=>{  console.log(i++,111111111)  },1000)  //打印了7次后关闭它  clearInterval(re)

setTimeout()

用于在指定的毫秒数后调用函数或计算表达式。设定一个指定等候时间 (单位是千分之一秒, millisecond), 时间到了, 浏览器就会执行一个指定的代码。只调用一次。

  var re=setTimeout(()=>{  console.log(666)  },1000)  console.log(re)

Promise

用于表示一个异步操作的最终完成（或失败）及其结果值。
参数：

  • resolve：异步操作执行成功后的回调函数
  • reject：异步操作执行失败后的回调函数

Promise 类有 .then() .catch() 和 .finally() 三个方法，这三个方法的参数都是一个函数，.then() 可以将参数中的函数添加到当前 Promise 的正常执行序列，也可以传入第二个函数用于接收错误数据； .catch() 则是设定 Promise 的异常处理序列，.finally() 是在 Promise 执行的最后一定会执行的序列。 .then() 传入的函数会按顺序依次执行，有任何异常都会直接跳到 catch 序列,内部产生了错误数据或者抛出(throw)了错误信息 catch方法传入的回调函数就会运行。

难点: then函数的返回值一定是一个Promise对象
then的返回看 then的传入的回调函数参数 传入的回调函数的返回值是Promise对象那么then的返回值就是它 反之就把返回值创建一个Promise对象 返回值
在链式调用的过程中只要有一个捕获 把错误处理了 就不会报错

  var p1=new Promise(function (resolve, reject) {  console.log(1111);  resolve(2222);  })  p1.then(function (value) {  console.log(value);  return 3333;  }).then(function (value) {  console.log(value);  throw "An error";  }).catch(function (err) {  console.log(err);  });
