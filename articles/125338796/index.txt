<h3><a id="Math_3"></a>什么是Math对象</h3> 
<p>Math 对象允许您执行数学任务。<br> Math 不是构造函数。Math 的所有属性/方法都可以通过使用 Math 作为对象来调用，而无需创建它：</p>

<h3><a id="round_118"></a>round对负数的四舍五入（重点）</h3> 
<p>round() 对负数比如：-11.5的这样处于小数中间值 .5 的四舍五入计算：<br> Math.round(-11.51) = -12<br> 但是Math.round(-11.5) = -11；并不是 -12</p> 
<p>Math.round()底层源码计算是：</p> 
<pre><code>public static long round(double a) {  return (long)floor(a + 0.5d);  }
</code></pre>
