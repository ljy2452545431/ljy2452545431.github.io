数组的内置功能

1.concat() 用于连接两个或多个数组

返回值：不会更改现有数组，而是返回一个新数组，其中包含已连接数组的值。

参数描述
array2, array3, …, arrayX必需。要连接的数组

语法：array.concat(array2, array3, …, arrayX)
案例：

var array1=[0];  var array2=[1];  var array3=array1.concat(array2)  console.log(array3)

2.copyWithin() 将数组元素复制到数组中的另一个位置，覆盖现有值。

返回值：数组，被改变的数组
注意:copyWithin() 方法永远不会向数组添加更多项,会覆盖原始数组。

参数描述
target必需。将元素复制到的索引位置
start可选。开始复制元素的索引位置（默认为 0）。包括start
end可选。停止从中复制元素的索引位置（默认为 array.length），不包括end

语法：array.copyWithin(target, start, end)
案例：

var array=[0,1,2,3,4,5];
var array1=array.copyWithin(1,3,5)
console.log(array,array1)

3.entries() 返回键/值对数组迭代对象。

对于原始数组中的每一项，新的迭代对象将包含一个以索引为键，以项值为值的数组
返回值：Array Iterator 对象,==> 可使用for of循环输出其值。
注意：entries() 不会更改原始数组，也没有参数
案例：

var array=['ljy','jjj','lll','yyy'];
var array1=array.entries()
console.log(array,array1)
for(var i of array1){  console.log(i);  }

4.fill() 用静态值填充数组中的指定元素

可以指定开始和结束填充的位置。如果未指定，则将填充所有元素。
返回值：数组，改变后的数组。
注意：fill() 会覆盖原始数组。

参数描述
value必需。用于填充数组的值
start可选。开始填充数组的索引（默认为 0）。（包括start）
end可选。停止填充数组的索引（默认为 array.length）。(不包括end)

案例：

var array=['ljy','jjj','lll','yyy'];
var array1=array.fill('LJY',1,2)
console.log(array,array1)

5.filter()使用数组中通过测试的每个元素创建新数组。

filter() 方法创建数组，其中填充了所有通过测试的数组元素（作为函数提供）。
注意：filter() 不会对没有值的数组元素执行该函数，不会改变原始数组。
返回值：包含所有通过测试的数组元素的数组。如果没有元素通过测试，则返回一个空数组。

案例：

var result=[90,50,60,70,40,61,80,100,74]
var result1=result.filter(function(result){return result>=60;})
console.log(result,result1)

6.every() 检查数组中的每个元素是否通过测试。

every() 方法检查数组中的所有元素是否都通过了测试（被作为函数提供）。
every() 方法对数组中存在的每个元素执行一次函数：
如果找到函数返回 false 值的数组元素，every() 返回 false（并且不检查剩余值）
如果没有出现 false，every() 返回 true

注释：every() 不对没有值的数组元素执行函数, 不改变原始数组。

返回值：布尔值。如果数组中的所有元素都通过测试，则返回 true，否则返回 false。
语法:array.every(function(currentValue, index, arr), thisValue)

 var result=[90,50,60,70,50,61,80,100,74]
 var result1=result.every(function(result){return result>=60})
 var result2=result.every(function(result){return result>=50})
 console.log(result,result1,result2)

7.find()返回数组中第一个通过测试的元素的值。

find() 方法返回数组中第一个通过测试的元素的值（作为函数提供）。
find() 方法对数组中存在的每个元素执行一次函数：
如果找到函数返回 true 值的数组元素，则 find() 返回该数组元素的值（并且不检查剩余值）
否则返回 undefined
注释：find() 不对空数组执行该函数,不会改变原始数组。
返回值：如果数组中的任何元素通过测试，则返回数组元素值，否则返回 undefined。

var result=[90,50,60,70,50,61,80,100,74]
 var result1=result.find(function(result){return result>=60})
 var result2=result.find(function(result){return result>=100})
console.log(result,result1,result2)

8.findIndex()返回数组中通过测试的第一个元素的索引。

findIndex() 方法返回数组中通过测试的第一个元素的索引（作为函数提供）。
findIndex() 方法对数组中存在的每个元素执行一次函数：
如果找到函数返回 true 值的数组元素，则 findIndex() 返回该数组元素的索引（并且不检查剩余值）
否则返回 -1
注意：findIndex() 不会为没有值的数组元素执行函数，不会改变原始数组。
返回值：如果数组中的任何元素通过测试，则返回数组元素索引，否则返回 -1。

var result=[90,50,60,70,50,61,80,98,74]
var result1=result.findIndex(function(result){return result>=95})
var result2=result.findIndex(function(result){return result>=100})
console.log(result,result1,result2)

9.forEach()为每个数组元素调用函数。

forEach() 方法按顺序为数组中的每个元素调用一次函数。
注意：对于没有值的数组元素，不执行forEach() 方法。
返回值：undefined

var result=[90,50,60,70,50,61,80,98,74]
var result1=result.findIndex(function(item, index, arr){arr[index] = item * 10;})
console.log(result,result1)

10.from()从对象创建数组。

from() 方法从具有 length 属性或可迭代对象的任何对象返回 Array 对象。

返回值：Array 对象
语法：Array.from(object, mapFunction, thisValue)

案例1：Array from a String

var arr=Array.from('ljy');
console.log(arr)


案例2：Array from a Set

var set = new Set(['ljy',window])  var arr = Array.from(set);  console.log(set,arr)


案例3：Array from a Map

var map = new Map([[1,2],[3,4],[5,6]])
var arr = Array.from(map);
console.log(map,arr)


案例4：Array from a Object

var arr1=Array.from({1:1,3:2,length:5})
console.log(arr1)


注意： 这里对象必须有length,否则返回空数组;对象的属性必须是整数数字，表示其值在数组中的下标
否则保存的是undefined；对象的length属性表示的就是数组的长度，保存的属性值长度不足length就用undefined表示

案例5：Using arrow functions and Array.from

var arr1=Array.from({length:5}, (v,i)=>i)
console.log(arr1)


这里也就是省略了map函数的写法==> var arr1=Array.from({length:5}, map((v,i)=>i))
length代表的是新数组的长度 map的两个参数随便命名 第一个代表这个数组的每个成员值 这里是为undefined，
第二个代表其下标，然后返回下标
意思就是数组中的每个成员都执行这个map函数,执行后的结果就是每个成员的下标。

11.includes()检查数组是否包含指定的元素。

includes() 方法确定数组是否包含指定的元素。
如果数组包含元素，则此方法返回 true，否则返回 false。
注意：includes() 方法区分大小写。
返回值：布尔值

var result=[90,50,60,70,50,61,80,98,74]
var result1=result.includes(98)
console.log(result,result1)

12.indexOf()在数组中搜索元素并返回其位置。

indexOf() 方法在数组中搜索指定项目，并返回其位置。
搜索将从指定位置开始，如果未指定开始位置，则从头开始，并在数组末尾结束搜索。
如果未找到该项目，则 indexOf() 返回 -1。
如果该项目出现多次，则 indexOf() 方法返回第一次出现的位置。
注释：第一项的位置为 0，第二项的位置为 1，依此类推。
提示：如果您想从尾到头搜索，请使用 lastIndexOf() 方法。
返回值：数值，表示指定项目的位置，没有则返回 -1。

var result=[90,50,60,70,50,61,80,98,74]
var result1=result.indexOf(98)
console.log(result,result1)

13.isArray()检查对象是否为数组。

isArray() 方法确定对象是否为数组。
如果对象是数组，则此函数返回 true，否则返回 false。
返回值：布尔值。如果对象是数组则返回 true，否则返回 false。
语法:Array.isArray(obj)

参数描述
obj必需。需测试的对象。
var result=[90,50,60,70,50,61,80,98,74]
var result1=Array.isArray(result)
console.log(result1)

14.join()将数组的所有元素连接成一个字符串。

join() 方法将数组作为字符串返回。
把数组中的元素先进行toString然后再按照指定的分隔符拼接，默认分隔符是逗号 (,)。
注释：join() 方法不会改变原始数组。
返回值：字符串值，表示数组值，由指定的分隔符分隔。
注意：如果数组元素是个对象则那个元素返回[object Object];
如果数组元素是数组toString后前后衔接用指定分隔符链接，中间则是用逗号 (,)分割

参数描述
separator可选。要使用的分隔符。如果省略，元素用逗号分隔。
//默认时
var result=[90,50,60,70,50,61,80,98,74]
var result1=result.join('')
console.log(result,result1)


//指定为‘’时
var result=[90,50,60,70,50,61,80,98,74]
var result1=result.join('')
console.log(result,result1)


//有数组和对象时  var arr=[10,2,3,4,44,[90,10],{name:"karen"}]  var re=arr.join("*")  console.log(re,arr)

15.keys()返回 Array Iteration 对象，包含原始数组的键.

keys() 方法返回带有数组键的 Array Iterator 对象。
注释：keys() 方法不改变原数组,它没有参数
返回值： Array Iterator 对象

var result=[90,50,60,70,50,61,80,98,74]
var result1=result.keys()
console.log(result,result1)

16.lastIndexOf()在数组中搜索元素，从末尾开始，并返回其位置。

lastIndexOf() 方法在数组中搜索指定项目，并返回其位置。
搜索将从指定位置开始，如果未指定开始位置，则从末尾开始，并在数组的开头结束搜索。
如果未找到该项目，则 lastIndexOf() 方法返回 -1。
如果要搜索的项目不止一次出现，lastIndexOf() 方法将返回最后一次出现的位置。
提示：如果要从头到尾搜索，使用 indexOf() 方法。
返回值：数值，表示指定项目的位置，否则 -1。

var result=[90,50,60,70,50,61,80,98,74]
var result1=result.lastIndexOf(50)
console.log(result,result1)

17.map()使用为每个数组元素调用函数的结果创建新数组。

map() 方法使用为每个数组元素调用函数的结果创建新数组。
map() 方法按顺序为数组中的每个元素调用一次提供的函数。
注释：map() 对没有值的数组元素不执行函数。
注释：map() 不会改变原始数组。
返回值： 数组，包含为原始数组中的每个元素调用提供的函数的结果。

var result=[90,50,60,70,50,61,80,98,74]  var result1=result.map(function(value,index,arr){  return value*2+index;  })  console.log(result,result1)

18.pop() 删除数组的最后一个元素，并返回该元素。

pop() 方法移除数组的最后一个元素，并返回该元素。
注释：pop() 方法会改变数组的长度,它没有参数。
提示：如需删除数组的第一个元素，请使用 shift() 方法。
返回值：任何类型 ，表示被删除的数组项。数组项可以是字符串、数字、数组、布尔值或数组中允许的任何其他对象类型。

var result=[90,50,60,70,50,61,80,98,74]
var result1=result.pop()
console.log(result,result1)

19.push() 将新元素添加到数组的末尾，并返回新的长度。

push() 方法向数组末尾添加新项目，并返回新长度。
提示：新的项目将被添加到数组的末尾。
注释：push() 方法会改变数组的长度。
返回值： 数值，表示数组的新长度。
提示：如需在数组的开头添加项目，请使用 unshift() 方法。

参数描述
item1, item2, …, itemX必需。要添加到数组中的项目。
var result=[90,50,60,70,50,61,80,98,74]

console.log(result,result1)

19.reduce() 将数组的值减为单个值（从左到右）。

reduce() 方法将数组缩减为单个值。
reduce() 方法为数组的每个值（从左到右）执行提供的函数。
函数的返回值存储在累加器中（结果/总计）。
返回值： 返回上次调用回调函数的累积结果。
注释：对没有值的数组元素，不执行 reduce() 方法,reduce() 方法不会改变原始数组。

语法：array.reduce(function(total, currentValue, currentIndex, arr), initialValue)

//对result求和
var result=[90,50,60,70,50,61,80,98,74]
var result1=result.reduce(function(num,value){return num+value;})
console.log(result,result1)

20.reduceRight() 将数组的值减为单个值（从右到左）。

reduceRight() 方法将数组缩减为单个值。
reduceRight() 方法为数组的每个值（从右到左）执行提供的函数。
函数的返回值存储在累加器中（结果/总计）。
注释：对没有值的数组元素，不执行 reduceRight() 方法。
返回值： 返回上次调用回调函数的累积结果。

语法：array.reduceRight(function(total, currentValue, currentIndex, arr), initialValue)

var result=[1,2,3,10]
var result1=result.reduceRight(function(num,value){return num-value;})
console.log(result,result1)

shift() 方法移除数组的第一项。

返回值： 任何类型，表示被删除的数组项目。

23.slice() 选择数组的一部分，并返回新数组。

slice() 方法以新的数组对象，返回数组中被选中的元素。
slice() 方法选择从给定的 start 参数开始的元素，并在给定的 end 参数处结束，但不包括。
注释：slice() 方法不会改变原始数组。
返回值： 新的数组，包含选定的元素。
注意：不会倒过来筛选，也就是当第二个end下标再start前面时就没有值，返回空数组

console.log(result,result1)


//为负数时
var result=[1,2,3,10]
var result1=result.slice(-2,-1)
console.log(result,result1)

24.some() 检查数组中的任何元素是否通过测试。

some() 方法检查数组中的任何元素是否通过测试（作为函数提供）。
some() 方法对数组中存在的每个元素执行一次函数：
如果找到函数返回真值的数组元素，some() 返回真（并且不检查剩余值）
否则返回 false
返回值： 布尔值。如果数组中的任何元素通过测试，则返回 true，否则返回 false。
注释：some() 对没有值的数组元素不执行函数。
注释：some() 不改变原始数组。

//检测数组中是否有大于或等于90
var result=[90,50,60,70,50,61,80,100,74]
var result1=result.some(function(result){return result>=90})
console.log(result,result1)

25.sort() 对数组的元素进行排序。

sort() 方法对数组的项目进行排序。
排序顺序可以是按字母或数字，也可以是升序（向上）或降序（向下）。
默认情况下，sort() 方法将按字母和升序将值作为字符串进行排序。
这适用于字符串（“Apple” 出现在 “Banana” 之前）。但是，如果数字按字符串排序，则 “25” 大于 “100” ，因为 “2” 大于 “1”。
正因为如此，sort() 方法在对数字进行排序时会产生不正确的结果。
您可以通过提供“比较函数”来解决此问题（请参阅下面的“参数值”）。
注释：sort() 方法会改变原始数组。
返回值： Array 对象，其中的项目已排序。

//默认是按照表码排序
var result=[90,50,60,70,50,61,80,100,74]
var result1=result.sort();
console.log(result,result1)


//按照数值大小升序
var result=[90,50,60,70,50,61,80,100,74]
var result1=result.sort(function(a,b){return a-b; })
console.log(result,result1)


//按照数值大小降序
var result=[90,50,60,70,50,61,80,100,74]
var result1=result.sort(function(a,b){return b-a; })
console.log(result,result1)

26.splice() 从数组中添加/删除元素。

splice() 方法向/从数组添加/删除项目，并返回删除的项目。
注释：splice() 方法会改变原始数组。
返回值： 新数组，包含删除的项目（如果有）。

语法：array.splice(index, howmany, item1, …, itemX)

var result=[90,50,60,70,50,61,80,100,74]
var result1=result.splice(1,7,'ljy','666')
console.log(result,result1)

27.toString() 将数组转换为字符串，并返回结果。

toString() 方法返回包含所有数组值的字符串，以逗号分隔。
注释：toString() 方法不会改变原始数组,没有参数。
返回值： 字符串，代表数组的值，用逗号隔开。

var result=[90,50,60,70,50,61,80,100,74]
var result1=result.toString()
console.log(result,result1)

28.unshift() 将新元素添加到数组的开头，并返回新的长度。

unshift() 方法将新项添加到数组的开头，并返回新的长度。
注释：unshift() 方法会改变数组的长度。
提示：如需在数组末尾添加新项，请使用 push() 方法。
返回值： 数值，表示数组的新长度。

参数描述
item1, item2, …, itemX必需。要添加到数组开头的项
  var result=[90,50,60,70,50,61,80,100,74]  var result1=result.unshift('ljy',666)  console.log(result,result1)

29.valueOf() 返回数组的原始值。

valueOf() 方法返回数组。
valueOf() 方法是数组对象的默认方法。
返回值： 数组。valueOf() 方法返回其自身。
注释：valueOf() 方法不会改变原始数组。

  var result=[90,50,60,70,50,61,80,100,74]  var result1=result.valueOf()  console.log(result,result1)

  var arr1=new Array(10)  var arr2=new Array(10,20)  var arr3=new Array('ljy')  console.log(arr1,arr2,arr3)
