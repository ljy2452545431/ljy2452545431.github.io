<h2><a id="_7"></a>一、什么是劫持?</h2> 
<p>再JS中劫持是this关键字的劫持，也就是改变this指向。<br> 再之前的this的文章中，谈到this指向的就是它的调用者。<br> 再这里this的劫持用的是call方法和apply方法来实现的。</p> 
<h2><a id="call_12"></a>二、call方法</h2> 
<p>call() 方法用来调用所有者对象作为参数的方法。<br> 通过 call()，能够使用属于另一个对象的方法。<br> call方法的第一个参数代表指定的调用者，后面的参数代表传递的实参,它是分别接受参数。<br> <strong>案例:</strong></p> 
<pre><code>		var obj={name:&quot;karen&quot;,say:function(str,arg2){console.log(this.name,str,arg2)}}  var obj2={name:&quot;jack&quot;}  var obj3={name:&quot;marry&quot;}  obj.say.call(obj2,100,200) //相当于是obj2在调用say方法  obj.say.call(obj3,80,10)
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/0eba8ca71a87c30ea2413f1f9338966d.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<h2><a id="apply_25"></a>三、apply方法</h2> 
<p>apply() 方法跟call方法一样所不同的是参数，apply()方法接受数组形式的参数。<br> 如果要使用数组而不是参数列表，则 apply() 方法非常方便。<br> <strong>案例1：</strong></p> 
<pre><code>  var obj={name:&quot;karen&quot;,say:function(arg1,arg2){console.log(this.name,arg1,arg2,arguments)}}  var obj2={name:&quot;jack&quot;}  var obj3={name:&quot;marry&quot;}  obj.say.apply(obj2,[&#x27;ljy&#x27;,100])  obj.say.apply(obj3,[&#x27;ljy&#x27;,200])  obj.say.apply(obj3,[&#x27;ljy&#x27;,300])
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/67f4322c9f1a5d6b53df6690687938d3.png" alt="在这里插入图片描述" loading="lazy" decoding="async"><br> <strong>案例2求数组中的最大值和最小值：</strong></p> 
<pre><code>  var arr=[90,50,30,80,40,70,100]  var max=Math.max.apply(arr,arr)  var min=Math.min.apply(arr,arr)  console.log(max,min)
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/319c7c431c59c88987e73d31e77b52f9.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<h2><a id="bind_46"></a>四、解决方法bind()</h2> 
<p>定义式的函数可以在设计的时候就指定this<br> 例如：fn.bind(obj)<br> 案例：</p> 
<pre><code>  var obj2={name:&quot;karen&quot;}  var obj={  name:&quot;ljy&quot;,  say:function(){  console.log(this)  }.bind(obj2)  }  obj.say()  var obj3={name:&quot;marry&quot;}  obj.say.call(obj3)  obj.say.apply(obj3,[])
</code></pre>

<h2><a id="_64"></a>五、拓展</h2> 
<p><strong>call连用的案例</strong></p> 
<pre><code>  function fn () {  console.log(1)  }  function fn2 () {  console.log(2)  }  fn.call.call(fn2)  fn.call.call.call(fn2)
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/14042e47ae743f2ade24c7eade9129c0.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<p><strong>分析：</strong><br> 1.所有的函数对象都有call方法—Function.prototype有call方法<br> 2.调用call方法是调用者运行<br> 3.也就是fn.call.call(fn2)等价于fn2.call(), call(fn2)相对于把调用它的调用者改成了fn2, 然后调用它的函数运行也就是前面那个call运行所以就等价于fn2.call() ==&gt;fn2()</p> 
<p><strong>设计call函数的代码</strong></p> 
<pre><code>  var obj={name:&quot;ljy&quot;,say:function(a,b){console.log(this.name,a,b)},age:10}  var obj2={name:&#x27;karen&#x27;,age:30}  Function.prototype.mycall=function(That,...args) { //...args代表多个参数  var name1=&quot;ljy_&quot;+new Date()  That[name1]=this  var re=That[name1](...args)//让传进来的对象去调用this函数  delete That[name1]  return re  }  obj.say.mycall(obj2,100,200)
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/f21c4d565b7936a58480ebe1f208a39c.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<p><strong>设计思路：</strong><br> 从call函数实现的两个功能入手：<br> 一、调用call方法是调用者运行==&gt;this()<br> 二、改变调用者的this对象:设置形参接受传入的设置的调用者；<br> 然后给其设置一个方法保存this，也就是保存原先调用它的函数。<br> 方法名用个绝不会重名的，比如：加个当前时间<br> 然后运行接受的调用者的这个方法，就实现了改变call调用者的this指向<br> 最后删除这个方法，用delete来删除，就不会导致传入的对象里面多了个这个方法。</p>
