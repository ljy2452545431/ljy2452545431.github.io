<h2><a id="egg_4"></a>一、egg框架介绍</h2> 
<p>简单来说：egg.js 是『约定优先于配置』的一个 Node.js web 框架，<br> 基于<a href="https://t.csdn.cn/YdhJf" target="_blank" rel="noreferrer noopener">MVC</a>设计思想设计的。<br> 它具有以下特点：</p> 
<ul><li>提供基于 Egg 定制上层框架的能力</li><li>高度可扩展的插件机制</li><li>内置多进程管理</li><li>基于 Koa 开发，性能优异</li><li>框架稳定，测试覆盖率高</li><li>渐进式开发</li></ul> 
<h2><a id="_15"></a>二、约定规则</h2> 
<p>1 app/router.js：用于配置URL路由规则；<br> 2 app/controller/** ：用于解析用户的输入，处理后返回相应的结果；<br> 3 app/service/<strong>： 用于编写业务逻辑层；<br> 4 app/public/</strong>： 用于放置静态资源；<br> 5 config/config.{env}.js： 用于编写配置文件；<br> 6 config/plugin.js 用于配置需要加载的插件；</p> 
<h2><a id="_23"></a>三、主要模块</h2> 
<h3><a id="routerjs_24"></a>路由(router.js)</h3> 
<p>定义了我们的路由规则，所有的请求都会通过这个路由规则去找对应的Controller，这样也可以做到统一管控。</p> 
<p>其业务逻辑如下图所示：<br> <img src="https://i-blog.csdnimg.cn/blog_migrate/ed5e327d049b8fe92e631dbcaf63de6e.png" alt="在这里插入图片描述" loading="lazy" decoding="async"><br> <strong>基本用法：</strong></p> 
<pre><code>router.verb(&#x27;path-match&#x27;, app.controller.action);
router.verb(&#x27;router-name&#x27;, &#x27;path-match&#x27;, app.controller.action);
router.verb(&#x27;path-match&#x27;, middleware1, ..., middlewareN, app.controller.action);
router.verb(&#x27;router-name&#x27;, &#x27;path-match&#x27;, middleware1, ..., middlewareN, app.controller.action);
</code></pre> 
<p><strong>verb</strong> 为请求方法<br> <strong>router-name</strong> 给路由设定一个别名，可以通过 Helper 提供的辅助函数 pathFor 和 urlFor 来生成 URL。(可选)<br> <strong>path-match</strong> - 路由 URL 路径。<br> <strong>middleware1</strong> - 在 Router 里面可以配置多个 Middleware。(可选)<br> <strong>controller</strong> - 指定路由映射到的具体的 controller 上，controller 可以有两种写法：<br> <strong>app.controller.user.fetch</strong> - 直接指定一个具体的 controller<br> <strong>‘user.fetch’</strong> - 可以简写为字符串形式</p> 
<h3><a id="Controllerjs_44"></a>控制器（Controller.js）</h3> 
<p>Controller负责解析用户的输入，处理后返回响应的结果。<br> 1.所有的Controller 文件都必须放在 app/controller目录下<br> 2.支持多级目录，访问时可以通过目录名级联访问。</p> 
<pre><code>//如果路由为：
router.get(&#x27;/ajax1&#x27;, controller.user.ajax1);
//则控制器对应要有一个user.js文件并且文件中有ajax1方法  async ajax1() {  const { ctx } = this;  ctx.body = [ &#x27;ljy&#x27;, 666 ];  }
</code></pre> 
<h3><a id="service_57"></a>服务(service)</h3> 
<p>主要用于操作数据库<br> 需要手动下载：</p> 
<pre><code>npm i --save egg-mysql
</code></pre> 
<p>开启插件</p> 
<pre><code>// config/plugin.js
module.exports = {  mysql: {  enable: true,  package: &quot;egg-mysql&quot;  }
};
</code></pre> 
<p>配置数据库</p> 
<pre><code>// config/config.default.js
config.mysql={  client:{  //host  host:&quot;localhost&quot;,  //端口  port:&quot;&quot;,  //用户名  user:&quot;&quot;,  //密码  password:&quot;&quot;,  //数据库名  database:&quot;&quot;  }  }
</code></pre> 
<p>使用方式：</p> 
<pre><code>  async getuserinfo(){  var mySql = await this.app.mysql.query(&quot;select *from studentinfo&quot;)  this.ctx.body=mySql  }
</code></pre>
