<h2><a id="ElementUI_4"></a>如何引入ElementUI</h2> 
<p>1.安装 <a href="https://element.faas.ele.me/#/zh-CN/component/installation" target="_blank" rel="noreferrer noopener">官方地址</a></p> 
<pre><code>npm i element-ui -S
</code></pre> 
<p>2.再main.js中引入并挂载到vm对象中</p> 
<pre><code>import Vue from &#x27;vue&#x27;;
import ElementUI
from &#x27;element-ui&#x27;;//引入组件库
import &#x27;element-ui/lib/theme-chalk/index.css&#x27;;//全局的css样式
import App from &#x27;./App.vue&#x27;;

Vue.use(ElementUI);//注册全局组件==&gt;Vue.component(&quot;xxxx&quot;,{})

new Vue({  el: &#x27;#app&#x27;,  render: h =&gt; h(App)
});
</code></pre> 
<p>但是呢这种再main.js中去挂载的写法不太利于管理和维护，代码比较混乱，<br> 还有一种是将这个插件的逻辑封装成一个对象，最后将在 install 编写业务代码暴露给 Vue 对象。这样做的好处是可以添加任意参数在这个对象上方便将 install 函数封装得更加精简，可拓展性也比较高。</p> 
<h2><a id="Vueuse_27"></a>Vue.use()</h2> 
<p>use 的基本原理就是：</p> 
<ul><li>外界 use 引入组件，触发内部 install 方法，并且传了一个Vue对象；</li><li>进入以后通过 component 注册一个全局组件（全局组件知识点）；</li><li>最后，外部就可以全局使用组件了。</li></ul> 
<p>那么外部组件挂载如何实现的呢：<br> 1.创建一份JS文件并插入：</p> 
<pre><code>//use语法
//写法一:
let obj={  install(arg){  //agr就是调用use的对象,也就是Vue对象  // install会直接运行  arg.prototype.hqyj=100
	}
 }
// Vue.use(obj)//会执行obj内部的install

//写法二：
 let install=(arg)=&gt;{  arg.prototype.hqyj2=100  arg.component(&quot;mygold&quot;,Gold1)
 }
// Vue.use(install)//会直接执行传入install

//写法三： 挂载外部组件最常用写法
import Vue from &quot;vue&quot;
import axios from &quot;axios&quot;
axios.defaults.baseURL=&quot;http://localhost:8080/serve&quot;
let myplug={}
myplug.install=(Vue)=&gt;{
	Vue.prototype.$axios=axios  //这面可以继续写其它外部组件
}
Vue.use(myplug)
</code></pre> 
<p>然后再main.js中引入：</p> 
<pre><code>import myplug from &#x27;./common/plug.js&#x27;
</code></pre>
