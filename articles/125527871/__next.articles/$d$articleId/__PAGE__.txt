<h2><a id="_7"></a>一、正则表达式是什么？</h2> 
<p>正则表达式是构成搜索模式的字符序列。<br> 当搜索文本中的数据时，可使用搜索模式来描述搜索的内容。<br> 正则表达式可以是单字符，或者更复杂的模式。<br> 正则表达式可用于执行所有类型的文本搜索和文本替换操作。<br> 例如：<br> /Ljy/i 是一个正则表达式。<br> Ljy是模式（在搜索中使用）。<br> i 是修饰符（把搜索修改为大小写不敏感）。</p> 
<h2><a id="_16"></a>二、正则表达式修饰符</h2> 
<table><thead><tr><th>修饰符</th><th>描述</th></tr></thead><tbody><tr><td>i</td><td>执行对大小写不敏感的匹配。</td></tr><tr><td>g</td><td>执行全局匹配（查找所有匹配而非在找到第一个匹配后停止）。</td></tr><tr><td>m</td><td>执行多行匹配。</td></tr></tbody></table>
<h2><a id="_23"></a>三、正则表达式模式</h2> 
<p>括号用于查找一定范围的字符串：</p> 
<table><thead><tr><th>表达式</th><th>描述</th></tr></thead><tbody><tr><td>[abc]</td><td>查找方括号之间的任何字符。</td></tr><tr><td>[0-9]</td><td>查找任何从 0 至 9 的数字。</td></tr><tr><td>(x|y)</td><td>查找由</td></tr></tbody></table>
<p>元字符是拥有特殊含义的字符：</p> 
<table><thead><tr><th>元字符</th><th>描述</th></tr></thead><tbody><tr><td>\d</td><td>查找数字。</td></tr><tr><td>\s</td><td>查找空白字符。</td></tr><tr><td>\b</td><td>匹配单词边界。</td></tr><tr><td>\uxxxx</td><td>查找以十六进制数 xxxx 规定的 Unicode 字符。</td></tr></tbody></table>
<p>Quantifiers 定义量词：</p> 
<table><thead><tr><th>量词</th><th>描述</th></tr></thead><tbody><tr><td>n+</td><td>匹配任何包含至少一个 n 的字符串。</td></tr><tr><td>n*</td><td>匹配任何包含零个或多个 n 的字符串。</td></tr><tr><td>n?</td><td>匹配任何包含零个或一个 n 的字符串。</td></tr></tbody></table>
<p><strong>锚点：</strong><br> 锚点指定个各行的模式位置。下面是两个最重要的锚点：<br> ^(插入符号)将模式固定到行首。例如，模式^1 匹配以 1 开头的任意行。<br> $(美元符)将模式固定到句尾。例如，9$匹配以 9 结尾的任意行。</p> 
<h2><a id="_52"></a>四、如何使用正则表达式？</h2> 
<h3><a id="_53"></a>字符串中的方法</h3> 
<h4><a id="search_54"></a>search()</h4> 
<p>search() 方法使用表达式来搜索匹配，然后返回匹配的位置。</p> 
<pre><code>  var str = &quot;ljy666&quot;;  console.log(str.search(/666/g))
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/b7040b5def8231db631afc985b34b9bd.png" alt="在这里插入图片描述" loading="lazy" decoding="async">z</p> 
<h4><a id="replace_61"></a>replace()</h4> 
<p>replace()方法返回模式被替换处修改后的字符串。</p> 
<pre><code>  var str = &quot;ljy666&quot;;  console.log(str.replace(/666/g,999))
</code></pre> 
<h4><a id="match_69"></a>match</h4> 
<p>match() 方法可在字符串内检索指定的值，或找到一个或多个正则表达式的匹配。<br> 返回值:存放匹配结果的数组。该数组的内容依赖于 regexp 是否具有全局标志 g。</p> 
<pre><code>  var str = &quot;ljy666j88j&quot;;  var reg=/j/g  console.log(str.match(reg))
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/98e55ae930f232123407a8a27f2073a2.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<h4><a id="split_78"></a>split</h4> 
<p>split() 方法用于把一个字符串分割成字符串数组。如果传入的正则表达式，则按照正则表达式匹配到的字符分割。</p> 
<pre><code>  var str = &quot;ljy666j88j&quot;;  var reg=/[6-8]/g  console.log(str.split(reg))
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/1a40d8c796576b81ef1cc9d49035a363.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<h3><a id="_88"></a>正则表达式的方法</h3> 
<h4><a id="test_89"></a>test()</h4> 
<p>它通过模式来搜索字符串，然后根据结果返回 true 或 false。</p> 
<pre><code>  var str = &quot;ljy666&quot;;  var reg=/j/g  console.log(reg.test(str))
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/030647a5439dbb0c1fb4a9b809c4a22c.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<h4><a id="exec_97"></a>exec()</h4> 
<p>它通过指定的模式（pattern）搜索字符串，并返回已找到的文本。<br> 如果未找到匹配，则返回 null。</p> 
<pre><code>  var str = &quot;ljy666&quot;;  var reg=/j/g  console.log(reg.exec(str))
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/d015656cbb29ae0f26f4cb9ef1a51806.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p>
