<h2><a id="AJAX_6"></a>一、回调封装AJAX</h2> 
<p>利用回调函数思想，将url和业务函数作为参数传进去；<br> 我们只需将open的网址改为url，然后响应数据后，使用业务函数去接受这个数据并调用。</p> 
<pre><code>function myAjax(url,callback){  let xhr=new XMLHttpRequest()||new ActiveXObject(&quot;Microsoft.XMLHTTP&quot;)  xhr.open(&quot;GET&quot;,url,true)  xhr.send()  xhr.onreadystatechange=function(){  if(xhr.readyState==4&amp;&amp;xhr.status==200){  callback(xhr.responseText)  }  }
}
</code></pre>

<h2><a id="promiseAJAX_33"></a>二、promise封装AJAX</h2> 
<p>主要解决异步深层嵌套(回调地狱)的问题，它提供了简洁的API使得异步操作更加容易。</p> 
<pre><code>function promiseAjax(url) {  let p1 = new Promise((resolve, reject) =&gt; {  try {  let xhr = new XMLHttpRequest() || new ActiveXObject(&quot;Microsoft.XMLHTTP&quot;)  xhr.open(&quot;GET&quot;, url, true)  xhr.send()  xhr.onreadystatechange = function () {  if (xhr.readyState == 4) {  if (xhr.status == 200) {  resolve(xhr.responseText)  } else if (xhr.status == 400) {  reject(xhr.responseText)  } else {  reject(&quot;not 404 found&quot;)  }  }  }  } catch (e) {  reject(xhr.responseText)  }  })  return p1
}
