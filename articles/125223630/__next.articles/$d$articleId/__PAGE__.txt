<h2><a id="_4"></a>一、什么是函数的自调用</h2> 
<p>可以理解为函数自己调用自己，也就是在函数内部放入调用这个函数的代码。在函数运行时执行调用代码，可以一直循环调用这个函数。<br> 例如：</p> 
<pre><code>  var a=100  function fn () {  console.log(666)  fn()  }  fn()  </code></pre> 
<p>这会无限循环打印666，会导致电脑卡死。<br> 解决方法添加条件判断语句<br> 例如：</p> 
<pre><code>  let i=10  //注意这里I不能放在函数里面，函数每次调用都会重新执行内部代码  //放在里面就会每调用都重新声明了i，解决方法：通过传参方式  function  fn () {  if(!i){  return i ;  }  else{  console.log(666)  i--;  fn()  }  }  fn()
</code></pre> 
<h2><a id="_34"></a>二、函数自调用的案例</h2> 
<p>通过函数自调用输出10的阶乘</p> 
<pre><code>  function fn (n) {  if(n&lt;=1){  return 1  }  else{  return n*fn(n-1)  }  }  var re=fn(10)  console.log(re)
</code></pre> 
<p>假设你只知道数组内部全是(数字和数组的混套),不知道嵌套了几层,打印出所有数字</p> 
<pre><code>var arr=[[1,2,3,4,[2,3,4,5],[2,3,4,5],[4,54,2,6]],[2,3,4,4,5,6]]  let myArr=function(arr){  for(let i=0;i&lt;arr.length;i++){  if(typeof(arr[i])==&#x27;number&#x27;){  console.log(arr[i])  }else{  myArr(arr[i])  }  }  }  myArr(arr);
</code></pre>
