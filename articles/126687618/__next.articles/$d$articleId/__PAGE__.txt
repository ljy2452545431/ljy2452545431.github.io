<h2><a id="_6"></a>什么是计算属性</h2> 
<p>模板内的表达式非常便利，但是设计它们的初衷是用于简单运算的。<br> 在模板中放入太多的逻辑会让模板过重且难以维护,也就是当逻辑比较复杂时，应该使用计算属性。</p>

<h3><a id="_131"></a>计算属性和方法的区别:</h3> 
<p>计算属性会把使用到的data中的属性缓存起来，防止页面发生大量重复计算，<br> 提升js 运行效率,如果计算属性中使用到的data中那部分数据变了才会重新调用计算属性<br> methods方法没有计算结果缓存起来，data任何数据发生改变，方法都会被重新调用一遍<br> 方法常常是作用的事件使用,计算属性常常是动态计算结果时使用。</p> 
<h2><a id="_136"></a>什么是属性监听器</h2> 
<p>属性监听器（watch）也是vue实例的一个属性，其主要就是用来监听元素值的变化从而来做各种相应的处理。<br> 简单来说就是：当侦听器监听的属性发生变化时,就会调用watch中对应的方法。<br> 格式要求：watch:{name(){}}中的方法名必须跟要监听的data中的属性名一样,才代表监听指定属性<br> 比如：</p> 
<pre><code>&lt;script src=&#x27;https://lf6-cdn-tos.bytecdntp.com/cdn/expire-1-M/vue/2.6.14/vue.js&#x27;&gt;&lt;/script&gt; //引入vue.js文件
&lt;div id=&quot;app&quot;&gt;  &lt;p&gt;{{name}}&lt;/p&gt;  &lt;button @click=&quot;fn&quot;&gt;点我修改name&lt;/button&gt;  //点击修改name值  &lt;/div&gt;  &lt;script&gt;  var vue = new Vue({  el: &quot;#app&quot;,  data: {  name:&#x27;LJY&#x27;  },  methods: {  fn(){  this.name=&quot;LJY666&quot;  }  },  watch:{  name(){  console.log(&quot;修改了name值&quot;)  //修改了name值后猝发这个函数  }  }  })  &lt;/script&gt;
</code></pre>
