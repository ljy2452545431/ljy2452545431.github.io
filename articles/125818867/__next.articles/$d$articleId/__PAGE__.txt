<h2><a id="DOM_4"></a>一、什么是DOM？</h2> 
<p>DOM 是document object model 它是W3C产业联盟制定的浏览器对程序员提供的对HTML文档操作的接口<br> 它把文档中的代码翻译成一个对象模型<br> 在这个模型中 所有相关的标签属性注释文本等等12种数据都翻译为一种类型的对象 统称节点对象。</p> 
<h2><a id="_8"></a>二、获取元素的方式</h2> 
<h3><a id="1_9"></a>1.系统提供的方法</h3> 
<table><thead><tr><th>方法</th><th>描述</th></tr></thead><tbody><tr><td>document.getElementById()</td><td>通过元素 id 来查找元素,输入“id名”</td></tr><tr><td>document.getElementsByClassName()</td><td>通过类名来查找元素，输入&quot;类名&quot;</td></tr><tr><td>document.getElementsByTagName()</td><td>通过标签名来查找元素,输入&quot;标签名&quot;</td></tr><tr><td>document.getElementsByName()</td><td>通过name名来查找元素，输入&quot;name名&quot;</td></tr><tr><td>document.querySelector()</td><td>查找匹配指定 CSS 选择器（id、类名、类型、属性、属性值等等）的第一个 HTML 元素；</td></tr><tr><td>document.querySelectorAll()</td><td>查找匹配指定 CSS 选择器（id、类名、类型、属性、属性值等等）的所有 HTML 元素,返回包含查找到的所有元素的数组</td></tr></tbody></table>

<p><strong>补充：</strong><br> 元素和节点的区别：<br> 元素：即html文档里面，所有的标签都可以称之为元素，比如说&lt;div&gt;、&lt;p&gt;等。<br> 节点：在 HTML DOM （文档对象模型）中，每个部分都是节点：<br> 文档本身是文档节点<br> 所有 HTML 元素是元素节点<br> 所有 HTML 属性是属性节点<br> HTML 元素内的文本是文本节点 （包括回车符也是属于文本节点）<br> 注释是注释节点。<br> 它们的关系是：元素是节点中的一种，称为元素节点，但元素节点中可以包含很多的节点。</p> 
<p>parentElement和parentNode区别::<br> 区别在于html标签的parentNode为document,parentElement则没有，返回null；</p>
