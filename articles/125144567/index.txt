<h2><a id="_6"></a>前言</h2> 
<p>JS中遍历器是什么？<br> 取出数据容器中的每一个元素的工具。<br> 那么有哪些遍历器呢？</p> 
<hr> 
<h2><a id="for_15"></a>一、for循环</h2> 
<p>for循环是遍历器中最重要的，因为兼容性好。</p> 
<pre><code>		var arr=[10,20,30,40,5]  for(var i=0;i&lt;arr.length;i++){  console.log(arr[i])  }
</code></pre>

<h2><a id="for_in_24"></a>二、for in循环</h2> 
<p>特点：能够取出对象的属性和属性值</p> 
<pre><code>  var arr=[10,20,30,40,5]  for(var i in arr){  console.log(arr[i],i)  }  var obj={name:&quot;ljy&quot;,age:22}  for(var key in obj){  console.log(key,obj[key])  }
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/dc2d90a68739375ce7ec65e2c8fbeb38.png" alt="在这里插入图片描述" loading="lazy" decoding="async"><br> 缺点：会循环出原型链的属性</p> 
<pre><code>  var obj={age:20,name:&quot;karen&quot;}  obj.__proto__.life=1  for (var key in obj) {  console.log(key)  }
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/aa67f2596cc83f840383d11142ca9f37.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<h2><a id="forEach_47"></a>三、数组的forEach方法</h2> 
<p>特点：按顺序为数组中的每个元素调用一次函数。<br> 传入的函数有三个参数分别对应的是数组每个的成员，成员的下标，调用这个方法的数组。<br> 返回值：undefined</p> 
<pre><code>  var arr=[10,20,30,40,5]  arr.forEach(function(el,index,arr){  console.log(el,index,arr)  })
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/d103514055a1b238417237646ace0b41.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<pre><code>  var arr = [10,20,30,40,5]  var re=arr.forEach(function(el,index,arr){  arr[index]=el*el  })  console.log(re,arr)
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/59cad0ca7164f05a9068c9974379b437.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<h2><a id="map_67"></a>四、数组的map方法</h2> 
<p>特点：也是跟forEach方法一样按顺序为数组中的每个元素调用一次函数，<br> 但不同的是用调用函数的结果创建新数组,不会改变原数组，它的三个参数跟forEach一样。</p> 
<pre><code>  var arr = [10,20,30,40,5]  var re=arr.map(function(el){  console.log(el)  return el*el  })  console.log(re)
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/d6a6e74948862aba0c28c6e2e2b95d09.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<pre><code>//实际业务中的map应用  var arr=[{name:&quot;karen&quot;,birth:&quot;2001-02-03&quot;},{name:&quot;jack&quot;,birth:&quot;2002-02-03&quot;}]  var arr2=arr.map(function(el){  el.age=new Date().getFullYear()-new Date(el.birth).getFullYear()  return el  })  console.log(arr2)
</code></pre>

<h2><a id="filter_90"></a>四、数组的filter方法</h2> 
<p>filter() 方法创建数组，其中保存所有通过测试的数组元素。</p> 
<pre><code>  var arr=[10,80,34,50]  var re=arr.filter(function(el,index,arr){  console.log(el)  return el&gt;40  })  console.log(re)
</code></pre>

<h2><a id="some_111"></a>五、数组的some方法</h2> 
<p>some() 方法检查数组中的任何元素是否通过测试,不会改变原数组<br> 返回值： 布尔值。如果数组中的任何元素通过测试，则返回 true，否则返回 false。</p> 
<pre><code>  var  arr=[100,200,30,40]  var re=arr.some(function(el){  console.log(el)  return el&gt;100  })  console.log(re)
</code></pre>

<h2><a id="reduce_123"></a>六、数组的reduce方法</h2> 
<p>reduce() 方法将数组缩减为单个值。<br> reduce() 方法为数组的每个值（从左到右）执行提供的函数。<br> 返回值：返回上次调用回调函数的累积结果。</p>

<h2><a id="for_of_200"></a>八、for of遍历器</h2>
