<h2><a id="_6"></a>插值表达式</h2> 
<p>1.普通插值表达式插入数据: 在标签尖括号中使用{{}}插入js表达式:变量,函数调用,三目运算等等<br> 插值表达式中的标识符 代表vue对象中的data的属性名或者methods中的方法名</p> 
<pre><code>  &lt;script src=&#x27;https://lf6-cdn-tos.bytecdntp.com/cdn/expire-1-M/vue/2.6.14/vue.js&#x27;&gt;&lt;/script&gt;
&lt;/head&gt;
&lt;body&gt;  &lt;div class=&quot;myH&quot;&gt;  //定义一个父盒子，使里面的标签都能使用vue data对象中的属性  &lt;h1 &gt;  {{fn(&quot;hello&quot;)+666}}  &lt;/h1&gt;  &lt;h2 &gt;  {{title}}  &lt;/h2&gt;  &lt;h3 &gt;  {{msg}}  &lt;/h3&gt;  &lt;h4 &gt;  {{obj.name}}  &lt;/h4&gt;  &lt;h5 &gt;  {{obj.age&gt;18?&quot;成年人&quot;:&quot;未成年&quot;}}  &lt;/h5&gt;
&lt;/div&gt;  &lt;script&gt;  let data={  title:&quot;描述&quot;,  msg:6666,  obj:{name:&quot;ljy&quot;,age:21},  fn:(el)=&gt;el  }  let op={  el:&quot;.myH&quot;,  //获取页面中的class属性  data  //外部的data对象  }  var vue=new Vue(op)  //创建一个vue对象  &lt;/script&gt;
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/51b9070e298b241039d087e3ca75f5fc.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<h2><a id="_47"></a>文本指令</h2> 
<p>v-html==&gt;相当于innerHTML<br> v-text==&gt;相当于innerText<br> v-pre==&gt;插件表达式就被识别为文本,而不是js表达式</p> 
<pre><code>  &lt;script src=&#x27;https://lf6-cdn-tos.bytecdntp.com/cdn/expire-1-M/vue/2.6.14/vue.js&#x27;&gt;&lt;/script&gt;
&lt;/head&gt;
&lt;body&gt;  &lt;div class=&quot;myH&quot;&gt;  &lt;h1 v-html=&quot;title&quot;&gt;  &lt;/h1&gt;  &lt;h2 v-text=&quot;msg&quot;&gt;  &lt;/h2&gt;  &lt;h3 v-pre&gt;  {{obj.name}}  &lt;/h3&gt;  &lt;/div&gt;  &lt;script&gt;  let data={  title:&quot;&lt;i&gt;描述&lt;i&gt;&quot;,  msg:6666,  obj:{name:&quot;ljy&quot;,age:21},  fn:(el)=&gt;el  }  let op={  el:&quot;.myH&quot;,  data  }  var vue=new Vue(op)  &lt;/script&gt;
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/9f1f7959644e8e8f1df6707b98a5ffa6.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<p>v-cloak==&gt;加上这个属性的标签相当于在构建虚拟节点的时候就会有这个属性,等data的数据生成的时候,这个标签会自动去掉这个属性,可以利用这个特性来在css中把这个元素在加载初期写样式(隐藏)</p> 
<pre><code>&lt;style&gt;  [v-clock]{  display: none;  //vue中data数据没有加载时就会隐藏  }
&lt;/style&gt;
&lt;body&gt;  &lt;div class=&quot;myH&quot;&gt;  &lt;h4 v-clock&gt;  {{obj.name}}  &lt;/h4&gt;  &lt;/div&gt;  &lt;script&gt;  let data = {  title: &quot;&lt;i&gt;描述&lt;i&gt;&quot;,  msg: 6666,  obj: {  name: &quot;ljy&quot;,  age: 21  },  fn: (el) =&gt; el  }  let op = {  el: &quot;.myH&quot;,  data  }  var vue = new Vue(op)
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/22e8d502fc95dbf095933a7f3e7f2425.png" alt="在这里插入图片描述" loading="lazy" decoding="async"><br> 补充：v-html,v-text指令操作,或者css中加[v-cloak]{display:none}解决vue第一次加载的时候 页面上使用的数据会闪烁。</p> 
<h2><a id="_115"></a>属性绑定</h2> 
<p>所有标签中属性绑定js中变量:<br> 标准写法: v-bind:src=“变量”<br> 简写形式: :src=“变量”</p> 
<pre><code>  &lt;div class=&quot;myH&quot;&gt;  &lt;a :href=&quot;src&quot;&gt;点我跳转到百度&lt;/a&gt;  &lt;img v-bind:src=&quot;myimg&quot; alt=&quot;&quot;&gt;  &lt;/div&gt;  &lt;script&gt;  let data = {  src: &quot;http://www.baidu.com&quot;,  myimg: &quot;https://img2.baidu.com/it/u=436635185,1433075744&amp;fm=253&amp;app=138&amp;size=w931&amp;n=0&amp;f=JPEG&amp;fmt=auto?sec=1661965200&amp;t=d9eb6c21e174eebcf9239ac87fe89d31&quot;,  }  let op = {  el: &quot;.myH&quot;,  data  }  var vue = new Vue(op)  &lt;/script&gt;
</code></pre>
