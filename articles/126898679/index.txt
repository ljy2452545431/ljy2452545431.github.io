<h2><a id="1setup_3"></a>1.setup</h2> 
<h3><a id="setup_5"></a>setup是什么</h3> 
<ul><li>Vue3.0中一个新的配置向，值为一个函数</li><li>setup是所有Composition API（组合API） ”表演的舞台“</li><li>组件中所有用到的:数据、方法等等，均要配置在setup中</li></ul> 
<h3><a id="setup_10"></a>setup执行的时机</h3> 
<ul><li>在beforeCreate之前执行(一次)，此时组件对象还没创建；</li><li>this是undefined，不能通过this来访问data/computed/methods/props；</li><li>其实所有的composition API相关回调函数中也都不可以；</li></ul> 
<h3><a id="setup_16"></a>setup的返回值</h3> 
<p>一般都返回一个对象：为模板提供数据，也就是模板中可以直接使用此对象中的所有属性/方法<br> 返回对象中的属性会与data函数返回对象合并成为组件对象的属性<br> 返回对象中的方法会与methods中的方法合并成功组件对象的方法</p> 
<pre><code>&lt;script&gt;  export default{  setup() {  //写JS语法  let msg=&quot;setup组合API&quot;  let obj={name:&#x27;ljy&#x27;,age:21}  let fn=()=&gt;{  console.log(666)  }  let arr=[1,2,3,4,5]  //导出对象 对象的属性作为数据  return {msg,obj,fn,arr}  }  }
&lt;/script&gt;

&lt;template&gt;
 &lt;div&gt;  &lt;h2&gt;{{msg}}&lt;/h2&gt;  &lt;span&gt;{{obj.name}}&lt;/span&gt;  &lt;span&gt;{{obj.age}}&lt;/span&gt;&lt;br&gt;  &lt;span v-for=&quot;(item, index) in arr&quot; :key=&quot;index&quot;&gt;{{item}}&lt;/span&gt;&lt;br&gt;  &lt;button @click=&quot;fn&quot;&gt;点我&lt;/button&gt;
 &lt;/div&gt;
&lt;/template&gt;
</code></pre> 
<p><img src="/images/articles/126898679/b43388567ddc6588465d54d626c2a89b.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<p>若返回一个渲染函数，则可以自定义渲染内容</p> 
<pre><code>&lt;script&gt;  import {h} from &#x27;vue&#x27;  export default{  setup() {  // 返回一个渲染函数  // h相当于document.CreateElement()  return () =&gt; { return h(&quot;h1&quot;, &quot;setup返回渲染函数&quot;) }  }  }
&lt;/script&gt;
</code></pre> 
<p><img src="/images/articles/126898679/381c00e736b77bfdd9981a66c68ba271.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<p>注意：<br> 尽量不要和Vue2.x配置混用<br> Vue2.x配置（data，methods，computed…）中可以访问setup中的属性，方法<br> 但在setup中不能访问到Vue2.x配置(data，methods，computed…)<br> 如有重名，setup优先<br> setup不能是一个async函数，因为返回值不再是return的对象，而是Promise，模板看不到return对象中的属性</p> 
<h3><a id="setup_72"></a>setup语法糖</h3> 
<p>给script标签直接添加setup属性就能使用setup了 &lt;script setup&gt;</p> 
<p>&lt;script setup&gt; 语法糖里面的代码会被编译成组件setup()函数的内容，不需要通过return暴露声明的变量、函数以及import引入的内容，即可在&lt;template/&gt;使用，并且不需要些export default{}</p> 
<pre><code>&lt;script setup&gt;  let msg = &quot;setup语法糖&quot;  let obj = { name: &#x27;ljy&#x27;, age: 21 }  let fn = () =&gt; {  console.log(666)  }  let arr = [1, 2, 3, 4, 5]
&lt;/script&gt;
&lt;template&gt;  &lt;div&gt;  &lt;h2&gt;{{msg}}&lt;/h2&gt;  &lt;span&gt;{{obj.name}}&lt;/span&gt;  &lt;span&gt;{{obj.age}}&lt;/span&gt;&lt;br&gt;  &lt;span v-for=&quot;(item, index) in arr&quot; :key=&quot;index&quot;&gt;{{item}}&lt;/span&gt;&lt;br&gt;  &lt;button @click=&quot;fn&quot;&gt;点我&lt;/button&gt;  &lt;/div&gt;
&lt;/template&gt;
</code></pre>

<p>这意味着与普通的 &lt;script&gt; 只在组件被首次引入的时候执行一次不同，&lt;script setup&gt; 中的代码会在每次组件实例被创建的时候执行</p>

<h2><a id="ref_113"></a>ref函数</h2> 
<ul><li>作用：定义一个响应式的数据</li><li>语法：const xxx = ref(“value”)  <ul><li>创建一个包含响应式的数据的引用对象(reference对象)</li><li>js中操作数据：xxx.value</li><li>模板中读取数据不需要.value,直接&lt;div&gt;{{xxx}}&lt;/div&gt;</li></ul> </li><li>注意  <ul><li>接收的数据类型可以是基本数据类型也可以是引用数据类型</li><li>基本类型的数据：响应式依然是靠Object.defineProperty()的get和set完成的</li><li>对象类型的数据：内部“求助”了Vue3.0的一个新的函数------reactive函数</li></ul> </li></ul> 
<p>ref设计原理:监听value的改变，劫持value属性的get和set<br> 因此ref一般用在基本数据,或者引用数据的嵌套层级不深的数据上<br> 嵌套层级深情况用reactive；</p> 
<p>案例：</p> 
<pre><code>&lt;script setup&gt;  //使用解构赋值引入ref  import {ref} from &quot;vue&quot;  //创建响应式的数据  let count=ref(0)  let obj = ref({name:&quot;ljy&quot;,age:&quot;21&quot;})  let arr = ref([1,2,3,4,5])  //修改基本数据  let fn=()=&gt;{  //使用响应式数据  count.value++  }  //修改对象  let fn2 = () =&gt; {  obj.value={name:&#x27;jack&#x27;,age:&#x27;30&#x27;}  }  //修改数组  let fn3 = () =&gt; {  arr.value = [6,7,8,9,10]  }
&lt;/script&gt;
&lt;template&gt;  &lt;button @click=&quot;fn&quot;&gt;点击count+1&lt;/button&gt;  &lt;button @click=&quot;fn2&quot;&gt;点击修改对象&lt;/button&gt;  &lt;button @click=&quot;fn3&quot;&gt;点击修改数组&lt;/button&gt;  &lt;h1&gt;{{count}}&lt;/h1&gt;  &lt;h1&gt;{{obj.name}}--{{obj.age}}&lt;/h1&gt;  &lt;span v-for=&quot;(item, index) in arr&quot; :key=&quot;index&quot;&gt;{{item}}&lt;/span&gt;
&lt;/template&gt;
</code></pre>

<h2><a id="reactive_162"></a>reactive函数</h2> 
<ul><li>作用：定义一个对象类型的响应式数据(基本数据类型别用它，用ref函数)</li><li>语法：const 代理一个对象 = reactive(被代理的对象) 接收一个对象（或数组），返回一个代理器对象（proxy对象）</li><li>reactive定义的响应式数据是“深层次的”</li><li>内部基于ES6的Proxy实现，通过代理对象内部的数据都是响应式的</li></ul> 
<pre><code>&lt;script setup&gt;  //使用解构赋值引入reactive  import {reactive} from &quot;vue&quot;  //使用reactive  let obj=reactive({name:&quot;ljy&quot;,age:22, family:[{relation: &#x27;father&#x27;,age:52}, { relation: &#x27;mother&#x27;, age: 55 }]})  let fn=()=&gt;{  //直接用点语法，因为reactive使用的是Proxy代理了整个对象  obj.age++  obj.family[0].age++  obj.family[1].age++  }
&lt;/script&gt;
&lt;template&gt;  &lt;button @click=&quot;fn&quot;&gt;age+1&lt;/button&gt;  &lt;h1&gt;{{obj.name}}----{{obj.age}}&lt;/h1&gt;  &lt;h2 v-for=&quot;(item, index) in obj.family&quot; :key=&quot;index&quot;&gt;{{item.relation}}----{{item.age}}&lt;/h2&gt;
&lt;/template&gt;
</code></pre>

<h2><a id="Vue3_189"></a>Vue3响应式数据的实现原理</h2> 
<p>vue2.0的响应式</p> 
<ul><li> <p>实现原理</p>  <ul><li> <p>对象类型：通过Object.definedProperty()对属性的读取、修改进行拦截（数据劫持）</p> </li><li> <p>数组类型：通过重写更新数据的一系列方法来实现拦截。（对数组的方法进行了包裹）</p> </li></ul> </li><li> <p>存在问题:</p>  <ul><li> <p>新增属性，删除属性都不会刷新界面</p> </li><li> <p>直接通过下标修改数组，界面不会自动更新</p> </li></ul> </li></ul> 
<p>vue3.0的响应式</p> 
<ul><li>实现原理  <ul><li>通过Proxy(代理)：拦截对象中任意属性的变化，包括：属性的读写，属性的添加，属性的删除等</li><li>通过Reflect(反射)：对被代理对象的属性进行操作</li></ul> </li></ul>

<h2><a id="Vue3_321"></a>Vue3中的生命周期</h2> 
<p>在Vue3.x中，新增了一个setup生命周期函数，setup执行的时机是在beforeCreate生命函数之前执行，因为在这个函数中不能通过this来获取实例的；同时为了命名的统一，将beforeDestory改名为beforeUnmount，destoryed改名为unmounted</p> 
<p>在选项式中生命周期函数有</p> 
<pre><code>beforeCreate（建议使用setup代替）created（建议使用setup代替）
setup
beforeMount  mounted
beforeUpdate  updated
beforeUnmount  unmounted
</code></pre> 
<p>再组合式中，也就是setup语法糖中有：<br> 通过在<strong>生命周期函数</strong>前加<strong>on</strong>来访问组件的生命周期<br> 注意点就是必须用import引入</p> 
<pre><code>onBeforeMount  onMounted  onBeforeUpdate  onUpdated
onBeforeUnmount  onUnmounted
onErrorCaptured
onRenderTracked
onRenderTriggered
</code></pre>
