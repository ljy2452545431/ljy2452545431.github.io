<h2><a id="root_4"></a>$root</h2> 
<p>表示当前组件树的根 Vue 实例，即new Vue({…根组件内容})。<br> 如果当前实例没有父实例，此实例将会是其自己。<br> Vue子组件可以通过$root属性访问父组件实例的属性和方法<br> 原理：再入口文件main.js中对Vue的原型设置一个属性并绑定vm对象,后面的子组件都能访问这个根节点</p> 
<pre><code>//main.js中
var vm=new Vue({  render: h =&gt; h(App),
}).$mount(&#x27;#app&#x27;)
Vue.prototype.myroot=vm
</code></pre> 
<pre><code>//box1中
&lt;template&gt;  &lt;div&gt;  &lt;button @click=&quot;fn&quot;&gt;点我&lt;/button&gt;  &lt;/div&gt;
&lt;/template&gt;
&lt;script&gt;  export default {  methods: {  fn() {  console.log(this.$root)  console.log(this.myroot)  console.log(this.myroot === this.$root)  },  },  }
&lt;/script&gt;
</code></pre>

<h2><a id="parent_38"></a>$parent</h2> 
<p>和$root 类似，$parent property 可以用来从一个子组件访问父组件的实例。它提供了一种机会，可以在后期随时触达父级组件，以替代将数据以 prop 的方式传入子组件的方式。</p> 
<h2><a id="children_41"></a>$children</h2> 
<p>子组件:$children // 数组<br> $children表示当前实例的直接子组件。需要注意$children并不保证顺序，也不是响应式的。如果正在尝试使用$children来进行数据绑定，考虑使用一个数组配合v-for来生成子组件，并且使用Array作为真正的来源</p> 
<h2><a id="ref_45"></a>$ref</h2> 
<p>尽管存在 prop 和事件，有的时候你仍可能需要在 JavaScript 里直接访问一个子组件。为了达到这个目的，你可以通过 ref 这个 attribute 为子组件赋予一个 ID 引用。例如：</p> 
<pre><code>&lt;template&gt;
&lt;div v-cloak class=&quot;App&quot;&gt;  &lt;button @click=&quot;fn&quot;&gt;点我&lt;/button&gt;  &lt;box1 ref=&quot;reference&quot;&gt;&lt;/box1&gt;
&lt;/div&gt;
&lt;/template&gt;
&lt;script&gt;  import box1 from &quot;./components/box1.vue&quot;  export default {  methods: {  fn(){  console.log(this.$refs.reference)  }  },  components: {  box1,  }  }
&lt;/script&gt;
</code></pre> 
<pre><code>&lt;script&gt;  export default {  data(){  return{  msg:&quot;box1组件&quot;  }  },  }
&lt;/script&gt;
</code></pre>
