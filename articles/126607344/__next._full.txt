<h2><a id="_6"></a>事件监听(事件绑定)</h2> 
<p>在Vue中使用v-on:监听事件,语法糖为@<br> 函数有两种写法函数名后面可写可不写(),写了小括号可以传参,不传参时两种写法效果都一样。单个参数不传参打印时为事件对象。</p> 
<p>事件触发方法时的参数传递：可以传递普通参数，也可以传递事件对象$event,设置参数不传参时</p> 
<pre><code>  &lt;script src=&quot;https://lf26-cdn-tos.bytecdntp.com/cdn/expire-1-M/vue/2.6.12/vue.js&quot;&gt;&lt;/script&gt;
&lt;/head&gt;

&lt;body&gt;  &lt;div id=&quot;app&quot;&gt;  &lt;button v-on:click=&quot;fn&quot;&gt;点我打印666&lt;/button&gt;&lt;br&gt;  &lt;button v-on:click=&quot;fn2(999)&quot;&gt;点我打印999&lt;/button&gt;&lt;br&gt;  &lt;button @click=&quot;fn2(888)&quot;&gt;点我打印888&lt;/button&gt;&lt;br&gt;  &lt;button @click=&quot;fn3&quot;&gt;点我打印msg&lt;/button&gt;&lt;br&gt;  &lt;button @click=&quot;fn2&quot;&gt;点我打印事件对象&lt;/button&gt;&lt;br&gt;  &lt;/div&gt;  &lt;script&gt;  let obj = {  el: &#x27;#app&#x27;,  data: {  msg: &quot;ljy666&quot;,  },  methods: {  fn(){  console.log(666)  },  fn2(el){  console.log(el)  },  fn3(){  console.log(this.msg)  },  },  }  var vue = new Vue(obj)  &lt;/script&gt;
</code></pre> 
<h2><a id="_44"></a>事件修饰符</h2> 
<p>Vue认为方法应只有纯粹的数据逻辑，而不是去处理 DOM 事件细节。所以引入了事件修饰符来处理DOM事件。</p> 
<ul><li>.stop 阻止冒泡，阻止从当前元素经过的所有冒泡行为</li></ul> 
<p>script代码</p> 
<pre><code>  &lt;script&gt;  let obj = {  el: &#x27;#app&#x27;,  data: {  msg: &quot;ljy666&quot;,  },  methods: {  fn(){  console.log(666)  },  fn2(el){  console.log(el)  },  fn3(){  console.log(this.msg)  },  },  }  var vue = new Vue(obj)  &lt;/script&gt;
</code></pre> 
<p>当我们没有绑定stop时，点击元素时，点击事件会从这个元素的嵌套层级一级一级往上冒泡；<br> 当绑定了stop时，就阻止了从当前元素经过的所有冒泡行为</p> 
<pre><code>  &lt;div id=&quot;app&quot;&gt;  &lt;div @click=&quot;fn&quot; id=&quot;div1&quot;&gt;&lt;p&gt;点我打印666&lt;/p&gt;  &lt;div @click=&quot;fn2(999)&quot; id=&quot;div2&quot;&gt;&lt;p&gt;点我打印999&lt;/p&gt;  &lt;div @click.stop=&quot;fn3&quot; id=&quot;div3&quot;&gt;&lt;p&gt;点我打印msg&lt;/p&gt;&lt;/div&gt;  &lt;/div&gt;  &lt;/div&gt;  &lt;/div&gt;
</code></pre> 
<p><img src="/images/articles/126607344/1d5e66d2c72783e40b4ccce66ee871f4.png" alt="在这里插入图片描述" loading="lazy" decoding="async"><br> 可以看到点击了紫色区域，只执行了当前元素的点击事件</p> 
<ul><li>.prevent 阻止默认事件<br> 有些标签会自带事件，比如a标签点击时会跳转页面，此时给事件绑定prevent就不会执行默认事件</li></ul> 
<pre><code>&lt;a href=&quot;http://www.baidu.com&quot; @click.prevent=&quot;fn&quot;&gt;点我&lt;/a&gt;
</code></pre> 
<ul><li>.capture 添加事件侦听器时让事件在捕获阶段触发<br> 补充：事件执行顺序是捕获=&gt;目标=&gt;冒泡<br> 事件默认是在冒泡阶段触发的,当在捕获阶段触发意味着我们点击它的子元素时,设置为捕获阶段触发的父元素会最先执行它的点击事件</li></ul> 
<pre><code>&lt;div id=&quot;app&quot;&gt;  &lt;div @click.capture=&quot;fn&quot; id=&quot;div1&quot;&gt;&lt;p&gt;点我打印666&lt;/p&gt;  &lt;div @click=&quot;fn2(999)&quot; id=&quot;div2&quot;&gt;&lt;p&gt;点我打印999&lt;/p&gt;  &lt;div @click=&quot;fn3&quot; id=&quot;div3&quot;&gt;&lt;p&gt;点我打印ljy666&lt;/p&gt;&lt;/div&gt;  &lt;/div&gt;  &lt;/div&gt;  &lt;/div&gt;
</code></pre> 
<p><img src="/images/articles/126607344/6c7a9cc1b1a71038967dfdc1788fb497.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<ul><li>.self 其他元素的事件触发时 事件链经过它,无论是捕获还是冒泡阶段都不会触发它的事件,<br> 只有它自己是精准对象才会触发事件, 虽然它自己不会被别人影响,<br> 但是它自己的事件触发的时候还是会生成事件链经过其他元素,并不阻止继续冒泡到其他元素</li></ul> 
<pre><code> &lt;div id=&quot;app&quot;&gt;  &lt;div @click.self=&quot;fn&quot; id=&quot;div1&quot;&gt;&lt;p&gt;点我打印666&lt;/p&gt;  &lt;div @click=&quot;fn2(999)&quot; id=&quot;div2&quot;&gt;&lt;p&gt;点我打印999&lt;/p&gt;  &lt;div @click=&quot;fn3&quot; id=&quot;div3&quot;&gt;&lt;p&gt;点我打印ljy666&lt;/p&gt;&lt;/div&gt;  &lt;/div&gt;  &lt;/div&gt;  &lt;/div&gt;
</code></pre> 
<p><img src="/images/articles/126607344/4e08a272158fd3ac67226e50abc8d068.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<ul><li>.once 事件只触发一次,触发完之后,事件就解绑</li></ul> 
<pre><code>&lt;div id=&quot;app&quot;&gt;  &lt;div @click=&quot;fn&quot; id=&quot;div1&quot;&gt;&lt;p&gt;点我打印666&lt;/p&gt;  &lt;div @click=&quot;fn2(999)&quot; id=&quot;div2&quot;&gt;&lt;p&gt;点我打印999&lt;/p&gt;  &lt;div @click.once=&quot;fn3&quot; id=&quot;div3&quot;&gt;&lt;p&gt;点我打印ljy666&lt;/p&gt;&lt;/div&gt;  &lt;/div&gt;  &lt;/div&gt;  &lt;/div&gt;
</code></pre> 
<p><img src="/images/articles/126607344/7facebee32999f5f793b143ffaf5abb8.png" alt="在这里插入图片描述" loading="lazy" decoding="async"><br> 重复点击div3时只打印了一次</p> 
<ul><li>多修饰符一起使用:连点</li></ul> 
<pre><code>  &lt;div id=&quot;app&quot;&gt;  &lt;div @click=&quot;fn&quot; id=&quot;div1&quot;&gt;&lt;p&gt;点我打印666&lt;/p&gt;  &lt;div @click.self.stop=&quot;fn2(999)&quot; id=&quot;div2&quot;&gt;&lt;p&gt;点我打印999&lt;/p&gt;  &lt;div @click=&quot;fn3&quot; id=&quot;div3&quot;&gt;&lt;p&gt;点我打印ljy666&lt;/p&gt;&lt;/div&gt;  &lt;/div&gt;  &lt;/div&gt;  &lt;/div&gt;

<h2><a id="_145"></a>按键修饰符</h2> 
<p>Vue的按键修饰符使用v-on:event.xxx，其中event为按键事件，xxx为键码或键码别名，如v-on:keydown.13或v-on:keydown.enter就表示：当按下回车键时才触发keydown方法。</p> 
<pre><code>&lt;input type=&quot;text&quot; @keydown.enter=&quot;fn()&quot;&gt;//方式一
&lt;input type=&quot;text&quot; @keydown.13=&quot;fn()&quot;&gt;//方式二
</code></pre> 
<p>Vue2.x为我们内置了一些常用的键码别名：</p> 
<pre><code> .enter：回车键
 .tab：制表键
 .delete：含delete和backspace键
 .esc：返回键
 .space: 空格键
 .up：向上键
 .down：向下键
 .left：向左键
 .right：向右键
</code></pre> 
<p>除了上面提到的按键别名，还可以用如下修饰键开启鼠标或键盘事件监听，使在按键按下时发生响应。</p> 
<pre><code>.ctrl
.alt
.shift
.meta
</code></pre> 
<p>与按键别名不同的是，修饰键和 keyup 事件一起用时，事件引发时必须按下正常的按键。<br> 换一种说法(组合键)：如果要引发 keyup.alt，必须按下 alt时释放其他的按键；单单释放 alt不会引发事件。</p>
