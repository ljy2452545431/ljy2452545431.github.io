<h2><a id="hook_4"></a>什么是hook</h2> 
<p>React Hook是React 16.8版本之后添加的新属性，用最简单的话来说，React Hook就是一些React提供的内置函数，这些函数可以让函数组件和类组件一样能够拥有组件状态（state）以及进行副作用（side effect）</p> 
<p>但是不要什么业务都使用hook,请在合适的时候使用hook,否则会造成性能问题.(能不用的时候就不能,当遇到性能不好优化的时候,自然会想到使用它)</p> 
<h2><a id="useState_9"></a>useState</h2> 
<p>它允许函数组件<strong>将自己的状态持久化到React运行时的某个地方</strong>，这样在组件每次重新渲染的时候都可以从这个地方拿到该状态，而且当该状态被更新的时候，组件也会重渲染。</p> 
<pre><code>//语法:
import {useState} from &quot;react&quot;
const [state, setState] = useState(initialState)//数组解构赋值

//useState接收一个initialState变量作为状态的初始值，返回值是一个数组。返回数组的第一个元素代表当前state的最新值，第二个元素是一个用来更新state的函数。state和setState这两个变量的命名是你自己取的
//state用于组件内部使用的数据
//setState函数用于修改state,当修改后会触发所有使用过state的地方重新取值(调用render)
//可以用多个useState
</code></pre> 
<p>案例：</p> 
<pre><code>import React, { Component,useState } from &#x27;react&#x27;
export default function Box3() {  const [first, setfirst] = useState(0)  return (  &lt;div&gt;  &lt;h1&gt;{first}&lt;/h1&gt;  &lt;button onClick={()=&gt;{setfirst(first+1)}}&gt;点击first+1&lt;/button&gt;  &lt;/div&gt;  )
}
</code></pre>

<p>可以看到数据修改了并刷新了模板</p> 
<h2><a id="useEffect_39"></a>useEffect</h2> 
<p>useEffect是用来使函数组件也可以进行副作用操作的。那么什么是副作用呢？</p> 
<p>函数的副作用就是函数除了返回值外对外界环境造成的其它影响假如我们每次执行一个函数，该函数都会操作全局的一个变量，那么对全局变量的操作就是这个函数的副作用。而在React的世界里，我们的副作用大体可以分为两类，<strong>一类是调用浏览器的API</strong>，例如使用addEventListener来添加事件监听函数等，<strong>另外一类是发起获取服务器数据的请求</strong>，例如当用户组件挂载的时候去异步获取用户的信息等。</p> 
<pre><code>import {useEffect} from &quot;react&quot;
useEffect(effect?=&gt;clean, dependencies?)  //useEffect的第一个参数effect是要执行的副作用函数，它可以是任意的用户自定义函数，用户可以在这个函数里面  操作一些浏览器的API或者和外部环境进行交互,网络请求等，这个函数会在每次组件渲染完成之后被调用
//useEffect可以有一个返回值,返回一个函数,系统在组件重新渲染之前调用它  //第二个参数dependencies来限制该副作用的执行条件  </code></pre> 
<p>案例：组件销毁时清除计算器</p> 
<pre><code>import React,{useEffect,useState} from &#x27;react&#x27;
export default function Box1(props) {  let [i,seti]=useState(0)  useEffect(()=&gt;{  console.log(i)  let timer=setInterval(() =&gt; {  seti(i+1)  },1000);  return ()=&gt;{  clearInterval(timer)  }  })  return (  &lt;div&gt;  &lt;h1&gt;{i}&lt;/h1&gt;  &lt;/div&gt;  )
}

</code></pre> 
<pre><code>//父组件

import React,{useState} from &#x27;react&#x27;
import Box1 from &#x27;./Box1&#x27;
export default function Box2() {  let [flag,setflag]=useState(true)  return (  &lt;div&gt;  &lt;button onClick={()=&gt;{setflag(!flag)}}&gt;点击销毁/创建Box1&lt;/button&gt;  {flag&amp;&amp;&lt;Box1&gt;&lt;/Box1&gt;}  &lt;/div&gt;  )
}
</code></pre> 
<h2><a id="useRef_90"></a>useRef</h2> 
<p>useRef是用来在组件不同渲染之间共用一些数据的，它的作用和我们在类组件里面为this赋值是一样的。</p> 
<p>语法</p> 
<pre><code>react
import {useRef} from &quot;react&quot;
const refObject = useRef(initialValue)
//useRef接收initialValue作为初始值，它的返回值是一个ref对象，这个对象的.current属性就是该数据的最新值。使用useRef的一个最简单的情况就是在函数组件里面获取DOM对象的引用
</code></pre> 
<p>案例：</p> 
<pre><code>import { useRef, useEffect } from &#x27;react&#x27;
import ReactDOM from &#x27;react-dom&#x27;

const AutoFocusInput = () =&gt; {  const inputRef = useRef(null)  useEffect(() =&gt; {  // 组件挂载后自动聚焦  inputRef.current.focus()  }, [])  return (  &lt;input ref={inputRef} type=&#x27;text&#x27; /&gt;  )
}

ReactDOM.render(&lt;AutoFocusInput /&gt;, document.getElementById(&#x27;root&#x27;))
//在上面代码中inputRef其实就是一个{current: input节点}对象，只不过它可以保证在组件每次渲染的时候拿到的都是同一个对象。
</code></pre> 
<h2><a id="useCallback_124"></a>useCallback</h2> 
<p>useCallback就是把我们在函数组件内部定义的函数保存起来,当组件重新渲染时还是使用之前的,就不会被重新定义一次</p> 
<p>语法：</p> 
<pre><code>import {useCallback} from &quot;react&quot;
const memoizedCallback = useCallback(callback, dependencies)  //useCallback接收两个参数，第一个参数是需要被记住的函数，第二个参数是这个函数的dependencies，只有dependencies数组里面的元素的值发生变化时useCallback才会返回新定义的函数，否则useCallback都会返回之前定义的函数。
</code></pre> 
<p>案例：</p> 
<pre><code>import React,{useCallback,useEffect,useState} from &#x27;react&#x27;

export default function Box7() {  let [arr,setarr]=useState([{id:1,name:&#x27;ljy&#x27;},{id:2,name:&#x27;jack&#x27;},{id:3,name:&#x27;marry&#x27;}])  let fn=useCallback((index)=&gt;{  console.log(index)  },[])  useEffect(()=&gt;{  console.log(&#x27;fn变化了&#x27;)  },[fn])  return (  &lt;div&gt;  &lt;&gt;{arr.map(el=&gt;&lt;p key={el.id}&gt;&lt;span&gt;{el.id}---{el.name}&lt;/span&gt;&lt;/p&gt;)}&lt;/&gt;  &lt;button onClick={()=&gt;{setarr([...arr])}}&gt;点击修改数据&lt;/button&gt;  &lt;/div&gt;  )
}
</code></pre> 
<h2><a id="useMemo_155"></a>useMemo</h2> 
<p>useMemo和useCallback的作用十分类似，只不过它允许你记住任何类型的变量（不只是函数）</p> 
<pre><code>import {useMemo} from &quot;react&quot;
const memoizedValue = useMemo(() =&gt; valueNeededToBeMemoized, dependencies)
//useMemo接收一个函数，该函数的返回值就是需要被记住的变量，当useMemo的第二个参数dependencies数组里面的元素的值没有发生变化的时候，memoizedValue使用的就是上一次的值。
</code></pre> 
<p>案例：</p> 
<pre><code>import React, { useMemo } from &#x27;react&#x27;
import ReactDOM from &#x27;react-dom&#x27;

const RenderPrimes = ({ iterations, multiplier }) =&gt; {  const primes = React.useMemo(() =&gt; calculatePrimes(iterations, multiplier), [  iterations,  multiplier  ])  return (  &lt;div&gt;  Primes! {primes}  &lt;/div&gt;  )
}

ReactDOM.render(&lt;RenderPrimes /&gt;, document.getElementById(&#x27;root&#x27;))
//例子中calculatePrimes是用来计算素数的，因此每次调用它都需要消耗大量的计算资源。
为了提高组件渲染的性能，我们可以使用useMemo来记住计算的结果，
当iterations和multiplier保持不变的时候，我们就不需要重新执行calculatePrimes函数来重新计算了，直接使用上一次的结果即可。
</code></pre> 
<h2><a id="useContext_185"></a>useContext</h2> 
<p>我们知道React中组件之间传递参数的方式是props，假如我们在父级组件中定义了某些状态，而这些状态需要在该组件深层次嵌套的子组件中被使用的话就需要将这些状态以props的形式层层传递，这就造成了props drilling的问题。为了解决这个问题，React允许我们使用Context来在父级组件和底下任意层次的子组件之间传递状态。在函数组件中我们可以使用useContext Hook来使用Context。</p> 
<p>语法：</p> 
<pre><code>const value = useContext(MyContext)
//useContext接收一个context对象为参数，该context对象是由React.createContext函数生成的。
useContext的返回值是当前context的值，这个值是由最邻近的&lt;MyContext.Provider&gt;来决定的。
一旦在某个组件里面使用了useContext这就相当于该组件订阅了这个context的变化，
当最近的&lt;MyContext.Provider&gt;的context值发生变化时，使用到该context的子组件就会被触发重渲染，且它们会拿到context的最新值。
</code></pre> 
<p>案例：</p> 
<pre><code>import React, { useContext, useState } from &#x27;react&#x27;
import ReactDOM from &#x27;react-dom&#x27;

//定义context
const NumberContext = React.createContext()

const NumberDisplay = () =&gt; {  const [currentNumber, setCurrentNumber] = useContext(NumberContext)  const handleCurrentNumberChange = () =&gt; {  setCurrentNumber(Math.floor(Math.random() * 100))  }  return (  &lt;&gt;  &lt;div&gt;Current number is: {currentNumber}&lt;/div&gt;  &lt;button onClick={handleCurrentNumberChange}&gt;Change current number&lt;/button&gt;  &lt;/&gt;  )
}

const ParentComponent = () =&gt; {  const [currentNumber, setCurrentNumber] = useState(100)  return (  &lt;NumberContext.Provider value={[currentNumber, setCurrentNumber]}&gt;  &lt;NumberDisplay /&gt;  //这里填儿子组件，后面孙子组件就可以直接使用爷爷组件传递的值  &lt;/NumberContext.Provider&gt;  )
}

ReactDOM.render(&lt;ParentComponent /&gt;, document.getElementById(&#x27;root&#x27;))
</code></pre> 
<h3><a id="_232"></a>使用时避免无用渲染</h3> 
<p>如果一个函数组件使用了useContext(SomeContext)的话它就订阅了这个SomeContext的变化，这样当SomeContext.Provider的value发生变化的时候，这个组件就会被重新渲染。</p> 
<p>这里有一个问题就是，我们可能会把很多不同的数据放在同一个context里面，而不同的子组件可能只关心这个context的某一部分数据，当context里面的任意值发生变化的时候，无论这些组件用不用到这些数据它们都会被重新渲染，这可能会造成一些性能问题.</p> 
<p>解决方法：<br> 1.拆分Context<br> 这个方法是最被推荐的做法，和useState一样，我们可以将不需要同时改变的context拆分成不同的context，让它们的职责更加分明，这样子组件只会订阅那些它们需要订阅的context从而避免无用的重渲染。</p> 
<pre><code>import React, { useContext, useState } from &#x27;react&#x27;
import ExpensiveTree from &#x27;somewhere/ExpensiveTree&#x27;
import ReactDOM from &#x27;react-dom&#x27;

const ThemeContext = React.createContext()
const ConfigurationContext = React.createContext()

const ChildrenComponent = () =&gt; {  const [themeContext] = useContext(ThemeContext)  return (  &lt;div&gt;  &lt;ExpensiveTree theme={themeContext} /&gt;  &lt;/div&gt;  )
}

const App = () =&gt; {  const [themeContext, setThemeContext] = useState({ color: &#x27;red&#x27; })  const [configurationContext, setConfigurationContext] = useState({ showTips: false })  return (  &lt;ThemeContext.Provider value={[themeContext, setThemeContext]}&gt;  &lt;ConfigurationContext.Provider value={[configurationContext, setConfigurationContext]}&gt;  &lt;ChildrenComponent /&gt;  &lt;/ConfigurationContext.Provider&gt;  &lt;/ThemeContext.Provider&gt;  )
}

ReactDOM.render(&lt;App /&gt;, document.getElementById(&#x27;root&#x27;))
</code></pre> 
<p>2.拆分组件，使用memo来优化消耗性能的组件<br> 如果出于某些原因你不能拆分context，仍然可以通过将消耗性能的组件和父组件的其他部分分离开来，并且使用memo函数来优化消耗性能的组件</p> 
<pre><code>import React, { useContext, useState } from &#x27;react&#x27;
import ExpensiveTree from &#x27;somewhere/ExpensiveTree&#x27;
import ReactDOM from &#x27;react-dom&#x27;

const AppContext = React.createContext()

const ExpensiveComponentWrapper = React.memo(({ theme }) =&gt; {  return (  &lt;ExpensiveTree theme={theme} /&gt;  )
})

const ChildrenComponent = () =&gt; {  const [appContext] = useContext(AppContext)  const theme = appContext.theme  return (  &lt;div&gt;  &lt;ExpensiveComponentWrapper theme={theme} /&gt;  &lt;/div&gt;  )
}

const App = () =&gt; {  const [appContext, setAppContext] = useState({ theme: { color: &#x27;red&#x27; }, configuration: { showTips: false }})  return (  &lt;AppContext.Provider value={[appContext, setAppContext]}&gt;  &lt;ChildrenComponent /&gt;  &lt;/AppContext.Provider&gt;  )
}

ReactDOM.render(&lt;App /&gt;, document.getElementById(&#x27;root&#x27;))
</code></pre> 
<p>3.不拆分组件，也可以使用useMemo来优化</p> 
<pre><code>import React, { useContext, useState, useMemo } from &#x27;react&#x27;
import ExpensiveTree from &#x27;somewhere/ExpensiveTree&#x27;
import ReactDOM from &#x27;react-dom&#x27;

const AppContext = React.createContext()

const ChildrenComponent = () =&gt; {  const [appContext] = useContext(AppContext)  const theme = appContext.theme  return useMemo(() =&gt; (  &lt;div&gt;  &lt;ExpensiveTree theme={theme} /&gt;  &lt;/div&gt;  ),  [theme]  )
}

const App = () =&gt; {  const [appContext, setAppContext] = useState({ theme: { color: &#x27;red&#x27; }, configuration: { showTips: false }})  return (  &lt;AppContext.Provider value={[appContext, setAppContext]}&gt;  &lt;ChildrenComponent /&gt;  &lt;/AppContext.Provider&gt;  )
}

ReactDOM.render(&lt;App /&gt;, document.getElementById(&#x27;root&#x27;))
</code></pre> 
<h2><a id="useReducer_346"></a>useReducer</h2> 
<p>.useReducer用最简单的话来说就是允许我们在函数组件里面像使用redux一样通过reducer和action来管理我们组件状态的变换<br> 语法:</p> 
<pre><code>const [state, dispatch] = useReducer(reducer, initialArg, init?)  //useReducer和useState类似，都是用来管理组件状态的，只不过和useState的setState不一样的是，useReducer返回的dispatch函数是用来触发某些改变state的action而不是直接设置state的值，至于不同的action如何产生新的state的值则在reducer里面定义。

//useReducer接收的三个参数分别是：  //reducer: 这是一个函数，它的签名是(currentState, action) =&gt; newState，从它的函数签名可以看出它会接收当前的state和当前dispatch的action为参数，然后返回下一个state,也就是说它负责状态转换的工作。  //initialArg：如果调用者没有提供第三个init参数，这个参数代表的是这个reducer的初始状态，如果init参数有被指定的话，initialArg会被作为参数传进init函数来生成初始状态。  //init: 这是一个用来生成初始状态的函数，它的函数签名是(initialArg) =&gt; initialState，从它的函数签名可以看出它会接收useReducer的第二个参数initialArg作为参数，并生成一个初始状态initialState
</code></pre> 
<p>案例：</p> 
<pre><code>import React,{useReducer} from &#x27;react&#x27;

export default function Box3() {  let redux=(initState,action)=&gt;{  if(action.type==&#x27;NAME&#x27;){  //这里进行判断type是什么，然后修改对应的值  initState.name=action.value  }  initState=JSON.parse(JSON.stringify(initState))  //这一步是状态转换,返回一个新的initState,没有这一步则修改之后不会刷新  return initState  }  let [state,dispatch]=useReducer(redux,{name:&#x27;hello&#x27;},(arg)=&gt;{  arg.name=&quot;ljy&quot;  return arg  //return返回的就是初始值  })  return (  &lt;&gt;  &lt;h1&gt;{state.name}&lt;/h1&gt;  &lt;button onClick={()=&gt;{dispatch({type:&#x27;NAME&#x27;,value:&#x27;修改了name&#x27;})}}&gt;点击修改&lt;/button&gt;  &lt;/&gt;  )
}

</code></pre>
