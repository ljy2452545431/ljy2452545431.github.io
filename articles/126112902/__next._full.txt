<h2><a id="_5"></a>一、什么是跨域?</h2> 
<p>产生跨域问题是由于浏览器的同源策略限制。<br> <strong>什么是浏览器的同源策略：</strong><br> 浏览器的一种安全策略: 指 两个网址的协议ip:port(端口) 三者一样代表同源<br> 浏览器为了用户的信息安全,网页中有一个网络请求技术:AJAX 在网络请求时;请求的网址和当前页面的网址不是同一台服务器,就会被拒绝接受服务器发送的数据。也就是ajax请求才会有这种跨域问题<br> 比如：<br> <img src="https://i-blog.csdnimg.cn/blog_migrate/b10d921e8e30db16dc6fd2433ed4eee3.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<h2><a id="_13"></a>二、解决跨域</h2> 
<h3><a id="1CORS_14"></a>1.CORS（跨域资源共享）技术</h3> 
<p>在数据包的头部配置Access-Control-Allow-Origin字段以后,数据包发送给浏览器后<br> 浏览器就会根据这里配置的白名单 “放行” 允许白名单的服务器对应的网页来用ajax跨域访问<br> 注意：跨域请求时，前端是请求了跨域的后端,只是返回的数据被浏览器拒收了,并不是跨域了就不发网络请求<br> 方法一：直接在自己服务器的js文件设置</p> 
<pre><code>res.setHeader(&quot;Access-Control-Allow-Origin&quot;,&quot;*&quot;)  //第二个参数代表都能访问这个数据，也可以设置服务器地址指定谁能访问
res.end(&#x27;{&quot;name&quot;:&quot;ljy&quot;,age:22}&#x27;)
</code></pre> 
<p>案例: 当我我要访问8080端口的数据</p> 
<pre><code>//这是在8081端口打开的html文件  &lt;button onclick=&quot;fn()&quot;&gt;点击请求百度首页&lt;/button&gt;  &lt;script&gt;  function fn(){  let xhr=new XMLHttpRequest()||new ActiveXObject(&quot;Microsoft.XMLHTTP&quot;)  xhr.open(&quot;GET&quot;,&quot;http://localhost:8080/ajax1&quot;,true)  xhr.send()  xhr.onreadystatechange=function(){  if(xhr.readyState==4){  console.log(xhr.responseText)  }  }  }
</code></pre>

<h3><a id="2JSONP_54"></a>2.JSONP</h3> 
<p>前端网页中用ajax请求跨域服务器的网址 ,会报跨域错误<br> 用script标签的src属性去请求跨域服务器的网址不会报跨域错误,但是会直接把请求过来的编码用v8引擎去运行,所以我们需要封装函数通过dom操作来把请求的数据添加到网页上。</p> 
<p>1.在后端写一个js引擎能识别的字符串发送给前端,这个字符串是这样的:’ fn({“name”:“ljy”}) ’</p> 
<p>2.前端直接通过script标签的src属性去请求这个网址,请求完毕以后 v8就会直接运行这个编码去调用fn函数,所以必须提前创建这个函数，然后将它放在要执行的业务函数中等待被调用。</p> 
<p>3.函数的名称问题: 前端可以通过querystring把函数名以参数的形式发送给后端,后端解析了以后直接拼接到数据中，然后发送给前端。</p> 
<p>4.通过dom操作创建script节点并为其设置src属性去请求这个网址，然后将script标签添加到页面上。</p> 
<p>首先在请求的服务器端设置 我使用的本机8080端口作为请求的服务器端，8081端口作为前端的服务器。</p> 
<pre><code>//8080服务器端
var http = require(&quot;http&quot;)
var url=require(&quot;url&quot;)
http.createServer((req, res) =&gt; {  var pathname=url.parse(req.url).pathname  if (pathname==&quot;/car&quot;) {  let querystr=url.parse(req.url,true).query.callback  //接受前端发送的函数名称  var obj={&quot;name&quot;:&quot;ljy&quot;,age:22}  var jsonstr=JSON.stringify(obj)  res.end(`${querystr}(${jsonstr})`)  }
}).listen(8080)
</code></pre> 
<pre><code>//8081服务器前端  &lt;button onclick=&quot;myload()&quot;&gt;点击请求8080端口&lt;/button&gt;  &lt;script&gt;  function myload(){  let myname=&quot;ljy&quot;+new Date().getTime()  window[myname]=function(data){  console.log(data)  }  let myscript=document.createElement(&quot;script&quot;)  myscript.src=`http://localhost:8080/car?callback=${myname}`  document.body.append(myscript)  }
</code></pre>

<h3><a id="3Proxy_97"></a>3.Proxy代理</h3> 
<p>在开发阶段 最常用的手段,比如Vue,React,等前端框架中常常有一个自己的开发服务器 ，如果用户访问我们的A服务器的网页,网页内部的AJAX 去请求A服务器的数据接口,是不会跨域的，然后A服务器去请求B服务器的数据,再把返回给A服务器的数据 返回给用户。在这里A服务器就是一个代理服务器</p> 
<p>这里我们后端使用的是request模块去发送请求。这是第三方模块需要手动下载</p> 
<p>1.安装request模块<br> npm i request</p> 
<p>2.使用request模块</p> 
<pre><code>var http = require(&quot;http&quot;)

</code></pre>
