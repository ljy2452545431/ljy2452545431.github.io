一、原型链是什么？

含义： 原型链是一种机制，指的是JavaScript每个对象包括原型对象都有一个内置的[[proto]]属性指向创建它的函数对象的原型对象，即prototype属性。

作用： 实现对象的继承，从而实现内存空间的复用。

二、原型链的理解

任何函数都有一个属性prototype 是一个对象 new Object()/{}
任何对象都有一个__proto__属性 是指向创建它的函数的prototype属性
任何对象都是由构造函数创建而来的

2.1 构造函数有哪些？

1.自定义构造函数,自己创建的函数 比如：function Fn(){this.name=ljy}
2.官方提供构造函数，比如：Function Object String Number Bloolean Array Date Math

为何说任何对象都是由构造函数创建而来：
首先来看看，创建对象的方法有：

方式一、object构造函数创建对象

var obj = new Object();

方式二、使用对象字面量表示法

var obj = {};  //相当于var obj = new Object();
var obj = {
	name: 'ljy';
	age : 22;
}

方式三、使用工厂模式创建对象

function createObj(name,age){
	var obj = new Object();
	obj.name = name;
	obj.age = age;
	return obj;
}
var obj = createObj('ljy', 23);

方式四、使用构造函数创建对象

function Fn(){  this.name=‘ljy’  }  var f1=new Fn()

从以上这些创建对象的方法可以看出，对象都是由函数创建而来的。

2.2 原型的分类：

隐式原型（proto）：这个原型是JavaScript中的内置属性[[prototype]]，此属性继承自object对象，在脚本中没有标准的方式访问[[prototype]]，但Firefox、Safari和Chrome在每个对象上都支持一个属性_proto_，隐式原型的作用是用来构成原型链，实现基于原型的继承
显示原型（prototype）：每一个函数在创建之后，便会拥有一个prototype属性，这个属性指向函数的原型对象，显示原型的作用是用来实现基于原型的继承与属性的共享

2.3 函数对象的原型对象（Fn.prototype）

原型对象的值是什么?
原型对象的值可以理解为是在函数创建的时候,创建了一个它的实例对象并赋值给它的prototype。
原型对象prototype里面有一个constructor属性，该属性指向原型对象所属的构造函数

2.4 __proto__属性

1. 构造函数new出来的对象__proto__指向构造函数的prototype
2. 所有函数的__proto__都是指向Function的prototype
3. Object的prototype.__proto__指向null
注意：因为系统内置的最初的原型对象 是在null指针的基本上扩展的内存 所有用type检测时 null的指针和对象的指针 前一个机器码一样 null会返回"object" 但是null被划分为基本类型

三、对象成员的操作和原型对象的操作

1. 对象取一个成员值时 会在原型链上取 就近优先 直到null都没有 系统为了程序不崩溃 就会默认返回undefined
2. 对象给一个成员存值时 无论其原型链上是否有这个成员 都会把更新或者添加这个成员在对象自己的内存中 不会操作原型对象
3. 对象的成员操作如果没有修改原型对象的属性 只是修改属性内部的数据 是可以的(因为引用数据的引用改变了系统才会判定其发生变化)
4. obj.x1.x2=100//如果x1是原型对象的属性,那么obj对象真的会修改原型对象的x1属性内部的x2属性的值
5. Fn.prototye={name:“ljy”}==>这个代码出现 意味着Fn函数创建的对象的原型对象是{name:“ljy”}

实例

function fn (name) {  this.name=name  }  fn.prototype={age:30} //后面用fn函数创建的对象的原型对象是{age:30}  var obj=new fn("karen")//{name:"karen",__proto__:{age:30}}  obj.age=20  //给一个对象存值,没有这个属性 就直接创建这个属性  obj.name="jack" //给一个对象存值,有这个属性,更新  var re=obj.age //  找到obj的age属性 为20  所以re=20  var re2=obj.x  //取一个对象的属性值 自己没有就取原型对象的  也没有就取原型的原型  直到null都没有 就取出undefined  所以返回undefined  re2=undefind  var re3=obj.name  // 找到更新后的obj的name属性为"jack" re3="jack"  console.log(re,re2,re3) //打印20,undefined,’jack‘
