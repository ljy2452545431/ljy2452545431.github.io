<h2><a id="provideinject_7"></a>provide-inject的作用</h2> 
<p>通常情况下，父组件向孙组件传递数据，可以采用父子props层层传递，也可以使用bus和Vuex直接交互。在Vue2.2.0之后，Vue还提供了provide/inject选项</p> 
<p>这对选项允许一个祖先组件向其所有子孙后代组件注入一个依赖，不论组件层次有多深，并在起上下游关系成立的时间里始终生效。</p> 
<p>也就是说，在父组件只要声明了provide，在其子组件，孙组件，曾孙组件等能形成上下游关系的组件中交互，无论多深都能通过inject来访问provider中的数据。而不是局限于只能从当前父组件的prop属性来获取。注意他只做祖先通后代的单向传递的一个办法。有人这么形容：</p> 
<p>provide就相当于加强版父组件prop，可以跨越中间组件，inject就相当于加强版子组件的props</p> 
<h2><a id="_16"></a>如何使用</h2> 
<p>使用方法<br> provide 提供变量：Object | () =&gt; Object<br> inject 注入变量： Array | { [key: string]: string | Symbol | Object }<br> provide 选项应该是一个对象或返回一个对象的函数。 该对象包含可注入其子孙的属性。在该对象中，它支持ES6中Symbol作为key，但只在原生支持等环境下可工作。</p> 
<p><strong>inject 选项可以是:</strong><br> inject用来指定一个数组或者一个对象，数组的话就放provide里字段的名称，而对象的话可以指定<br> 当前实例中的字段名<br> 对应provide里的字段名<br> 默认值或者返回默认值的函数</p> 
<pre><code>const Child = {  inject: {  foo: {  from: &#x27;msg&#x27;,  default: () =&gt; [1, 2, 3]  }  }
}
</code></pre> 
<p>注意：provide和inject绑定并不是可响应的，这是刻意为之，然而如果你传入了一个可监听的对象，那么气对象的属性还是可监听的。</p> 
<p><strong>案例：</strong></p> 
<pre><code>//App.vue中
&lt;template&gt;
&lt;div v-cloak class=&quot;App&quot;&gt;  &lt;box1 @myclick=&quot;fn&quot;&gt;&lt;/box1&gt;
&lt;/div&gt;
&lt;/template&gt;
&lt;script&gt;  import box1 from &quot;./components/box1.vue&quot;  export default {  data() {  return {  msg:&quot;父组件App传的值&quot;  }  },  methods: {  fn(arr){  this.msg=`父组件App传的值----${arr}`  }  },  // provide选项提供变量  provide:function(){  return {msg:this.msg}  },  components: {  box1,  },  }
&lt;/script&gt;
</code></pre> 
<pre><code>//bo1文件中
&lt;template&gt;
 &lt;box2&gt;&lt;/box2&gt;
&lt;/template&gt;
&lt;script&gt;  import box2 from &quot;./box2.vue&quot;  export default {  inject:[&#x27;msg&#x27;],  components:{  box2  },  provide:{data:&quot;box2传递的值&quot;}  }
&lt;/script&gt;
</code></pre> 
<pre><code>//bo2文件中
&lt;template&gt;
&lt;div&gt;  &lt;h3&gt;{{msg}}--{{data}}&lt;/h3&gt;
&lt;/div&gt;
&lt;/template&gt;
&lt;script&gt;
export default {
//在孙组件中，使用inject来注入  inject:[&quot;msg&quot;,&#x27;data&#x27;],  methods: {  fn(){  this.$emit(&quot;myclick&quot;)  }  },
}
&lt;/script&gt;
</code></pre>

<h3><a id="_108"></a>方法一、父级组件为子级组件提供的数据为对象</h3> 
<pre><code>//App.vue中
&lt;template&gt;
&lt;div v-cloak class=&quot;App&quot;&gt;  &lt;h1&gt;父组件app中----{{msg.age}}&lt;/h1&gt;  &lt;box1&gt;&lt;/box1&gt;
&lt;/div&gt;
&lt;/template&gt;
&lt;script&gt;  import box1 from &quot;./components/box1.vue&quot;  export default {  data() {  return {  msg:{name:&quot;父组件App传的值&quot;,age:22}  }  },  provide:function(){  return {msg:this.msg}  },  components: {  box1,  },  }
&lt;/script&gt;
</code></pre> 
<pre><code>//bo1文件中
&lt;template&gt;
 &lt;div&gt;  &lt;button @click=&quot;fn&quot;&gt;点击修改msg.age&lt;/button&gt;  &lt;h2&gt;子组件box1中----{{msg.age}}&lt;/h2&gt;  &lt;box2&gt;&lt;/box2&gt;

&lt;script&gt;  import box2 from &quot;./box2.vue&quot;  export default {  inject:[&#x27;msg&#x27;],  methods: {  fn(){  this.msg.age=100  }  },  components:{  box2  },  }
&lt;/script&gt;
</code></pre>

&lt;/div&gt;
&lt;/template&gt;
&lt;script&gt;
export default {  inject:[&quot;msg&quot;], 
}
&lt;/script&gt;
</code></pre>
