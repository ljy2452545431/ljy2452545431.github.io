<h2><a id="_5"></a>前言</h2> 
<p>什么是构造函数?<br> 构造函数有何作用?</p> 
<h2><a id="_9"></a>一、构造函数是什么？</h2> 
<p>在 JavaScript 中，用 new 关键字来调用的函数，称为构造函数。<br> 例如:new Fn()</p> 
<h2><a id="_12"></a>二、构造函数的特点</h2> 
<p>1.构造函数的首字母必须大写，用来区分于普通函数。这是一种语法规范，小写也不会报错。<br> 2.内部使用的this对象，来指向即将要生成的实例对象<br> 3.使用New来生成实例对象<br> 格式：var 变量名=new 构造函数名</p> 
<h2><a id="_18"></a>三、使用构造函数有哪些好处?</h2> 
<p>在使用对象字面量创建一系列同一类型的对象时，这些对象可能具有一些相似的特征(属性)和行为(方法)，此时会产生很多重复的代码，而使用构造函数就可以实现代码复用。<br> 举个例：<br> 学校录入某个班级的个人信息时,可以使用创建对象来</p> 
<pre><code>var n1 = { Student_No: 2191111, name: &#x27;zhangsan&#x27;, age: 21, gender: &#x27;男&#x27;};
var n2 = { Student_No: 2191112, name: &#x27;lisi&#x27;, age: 22, gender: &#x27;男&#x27; };
var n3 = { Student_No: 2191113, name: &#x27;wangwu&#x27;, age: 23, gender: &#x27;女&#x27; };
...
</code></pre> 
<p>但是人数多时，要创建的对象就是几十上百个，而代码就很多重复的。<br> 因此这里可以用到构造函数，来实现代码复用</p> 
<pre><code>function Class(Student_No,name,age,gender){  this.Student_No=Student_No;  this.name=name;  this.age=age;  this.gender=gender;
}
</code></pre> 
<pre><code>var n1=new Class(2191111, &#x27;zhangsan&#x27;,21,&#x27;男&#x27;)
var n2=new Class(2191112, &#x27;lisi&#x27;,22,&#x27;男&#x27;)
var n3=new Class(2191113, &#x27;wangwu&#x27;,23,&#x27;女&#x27;)
</code></pre> 
<p>可以发现创建对象过程变得简单了，没有那些重复的代码了。</p> 
<h2><a id="_45"></a>四、构造函数的返回值</h2> 
<p>首先看构造函数是否手动添加return<br> 如果添加了return 再看return后面是不是引用数据<br> 如果是那么就返回这个return的值<br> 不是就返回这个构造函数运行完毕之后创建的那个对象<br> 没有手动添加return时返回这个构造函数运行完毕之后创建的那个对象</p> 
<p><strong>补充：</strong> 这里的引用数据也就是对象类型Object type，比如：Object 、Array 、Function 、Data等。</p>
