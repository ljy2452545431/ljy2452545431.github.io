<h2><a id="this_13"></a>一、this的定义</h2> 
<p>this代表的是 执行这个this代码的环境对象<br> this基本上就代表的是对象 在及其少的时候 this不是对象=&gt;call apply bind</p> 
<h2><a id="this_17"></a>二、this具体代表什么？</h2> 
<p>简单来说:this代表离它最近的嵌套级别的function的调用者,如果没有就是window</p> 
<pre><code>		// console.log(this)//this是window  // obj.xx()==&gt;this是obj  // obj.x1.x2()==&gt;this是obj.x1属性引用的对象  // obj.x1[2]()==&gt;this是obj.x1属性引用的数组  // fn().x()==&gt;fn()的返回值  // obj.fn(this)==&gt;fn函数内部的this是obj 小括号中的this看这个单词所在的函数 是谁调用的 特别注意它跟fn函数没关系  // 其他情况下 一般this都是代表window  // 匿名函数自调用  (function(){ this})() ==&gt;  this代表window  // 普通函数调用  fn() ==&gt; fn内部的this代表window
</code></pre> 
<h2><a id="this_30"></a>三、this实例</h2> 
<p>实例1</p> 
<pre><code>function a(xx){  this.x = xx;  return this;  };
var x = a(5);
var y = a(6);
console.log(x.x);
console.log(y.x);
</code></pre> 
<p><strong>分析：</strong> function a(xx){}这里有个隐式操作 var xx = 具体传入的实参<br> 由 var x = a(5); 可得出 this.x = xx 这里this的调用者是window。<br> 并且传入了实参5 ，得出var xx = 5, 因此 window.x = 5 ,这里的x属性就相对于var x = 5<br> 然后看下面return返回值这里的this跟上面一样为window,可得window.x=window 覆盖掉之前的var x = 5<br> 通过 var y = a(6) 可得出window.x = 6 覆盖掉之前的var x = window ;var y = window<br> 所以console.log(x.x) 这里的x.x就等于6.x 是包装函数,所以打印的是undefind<br> console.log(y.x)这里的y.x就等于window.x，打印的就是6</p>
