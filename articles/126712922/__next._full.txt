<h2><a id="_5"></a>组件是什么</h2> 
<p>组件是可复用的 Vue 实例,主要用于开发中 具有相同特征不同数据的模块 把它集成为一个组件 供重复利用</p> 
<h2><a id="_8"></a>全局组件</h2> 
<p><strong>规则：</strong></p> 
<ul><li>组件的属性不能用大写字母</li><li>组件的名字可以用驼峰命名法,但是使用的时候必须用连字符</li><li>全局注册的组件使用时不能使用单标签(不会报错,但是只能使用一次 多次使用只显示第一个)</li><li>注册的组件不要跟系统标签同名</li></ul> 
<p><strong>创建全局组件语法：</strong></p> 
<pre><code>  //注册全局组件  Vue.component(&quot;box&quot;, {  //标签名  template: &quot;&lt;div&gt;&lt;h1&gt;box组件&lt;/h1&gt;&lt;/div&gt;&quot; //标签内容  //template里面内容只能用一个唯一的div包裹住，如果template的儿子元素中有两个元素，那么就会报错。局部组件也是  })
</code></pre> 
<p>全局组件完成后相对于局部组件来说不用注册在任何vue管辖的html中(也就是vue的el元素下)都可以调用。</p> 
<h2><a id="_24"></a>局部组件</h2> 
<p>一个vm实例可以有多个局部组件,但是只能供当前vm实例使用</p> 
<p><strong>创建局部组件语法：</strong></p> 
<pre><code>		&lt;div id=&quot;app&quot;&gt;  &lt;box&gt;&lt;/box&gt;  &lt;/div&gt;  &lt;script&gt;  new Vue({  el: &#x27;#app&#x27;,  data:{  name:&quot;ljy&quot;  },  components:{  box:{  template:`&lt;div&gt;&lt;h1&gt;{{name}}{{fn()}}&lt;/h1&gt;&lt;/div&gt;`,  //下面的组件只能在box里面使用  data(){  return {  name:&quot;LJY&quot;,  age:21  }  },  methods:{  fn(){  if(this.age&gt;=18){  return &quot;成年人&quot;  }else{  return &quot;未成年&quot;  }  }  }  }  }  })
</code></pre> 
<h2><a id="_61"></a>单文件组件</h2> 
<p>vue中的单文件组件是以.vue扩展名结尾的文件，在这个文件中封装了html、js、css的代码，它自身是一个独立 的组件，所以成为单文件组件；</p> 
<p>引入:1官方脚手架 2挂载vm对象 3组件引入并渲染到vm中</p> 
<p>环境配置命令：</p> 
<pre><code>1.  npm install  @vue/cli -g //下载官方脚手架
2.  vue create app  //项目名称 
3. 接下来让你选择一些默认要生成的工具,不管直接回车
4. 进入项目文件夹: cd app //进入项目文件夹,也可以直接在项目文件夹中打开终端
5. 启动:
npm run serve  //生成的打包文件在内存中不会写入磁盘用于开发阶段
或者  npm run build //生成的打包文件在dist中 用于项目上线
</code></pre> 
<p>单文件组件也有全局组件和局部组件<br> 只是把一个组件单独写在一个.vue文件中,供别的组件引入然后注册<br> 引入文件时:一般使用相对路径 上一下用…/ 同级使用./ 下级使用/ @ 代表src文件夹</p> 
<p><strong>vue文件结构：</strong></p> 
<p>由于.vue封装了html、js、css的代码，所以它由以下几部分组成；</p> 
<pre><code>template -&gt; 组件的模板结构
script -&gt; 组件的 JavaScript 行为
style -&gt; 组件的样式
</code></pre> 
<p><strong>基于webpack的单文件组件项目基本结构</strong></p> 
<p>index.html 基本页面<br> App.vue vue根组件<br> main.js 入口文件<br> package.json 项目配置文件<br> webpack.config.js webpack配置文件<br> .babelrc babel配置文件，babel可以将es6转成es5</p>

<h2><a id="Props_171"></a>组件的属性Props</h2> 
<p>Vue组件通过props属性来声明一个自己的属性，然后父组件就可以往里面传递数据。<br> 同样传递父组件里面的变量时，使用v-bind绑定。</p> 
<p>属性有两种写法:简单声明和详细描述:</p> 
<p>简单声明<br> props:[“prop1”,“prop2”]</p> 
<p>对属性做详细的描述</p> 
<pre><code>props: {
	propA: Number,		// 基础的类型检查 (`null` 匹配任何类型)
	propB: [String, Number],	// 多个可能的类型
	propC: {	type: String,  required: true	// 必填的字符串  },
	propD: {	type: Number,  default: 100	// 带有默认值的数字  },
	propE: {	type: Object,	// 带有默认值的对象或者数组填Array  default: function () {	// 不建议直接填对象(因为对象直接量会一直占用内存),一般使用工厂函数,调用时才创建对象节省资源(面试)  return { message: &#x27;hello&#x27; }  }  },
	propF: {  validator: function (value) {// 自定义验证函数返回为true就代表数据符合我们规定  return [&#x27;success&#x27;, &#x27;warning&#x27;, &#x27;danger&#x27;].indexOf(value) !== -1  }  }  }
</code></pre> 
<h2><a id="Props__204"></a>通过属性Props 传值</h2> 
<p>父组件通过属性给子组件传值: 子组件的props接受数据<br> 在页面模板中 使用变量名:属性 data 计算属性<br> 注意：属性传值是单向的</p> 
<p><strong>案例：</strong></p> 
<pre><code>//再父组件App.vue文件中

&lt;template&gt;  &lt;div v-cloak&gt;  &lt;h1&gt;App组件中&lt;/h1&gt;  &lt;box :pro=&quot;msg&quot;&gt;&lt;/box&gt;  //属性名不能取官方定义  &lt;/div&gt;
&lt;/template&gt;
&lt;script&gt;
import box from &quot;@/components/user.vue&quot;
export default {  data() {  return {  msg: &quot;父组件传递的值&quot;,  }  },  components:{  box  }
}
&lt;/script&gt;
&lt;style&gt;
&lt;/style&gt;
</code></pre> 
<pre><code>&lt;template&gt;
&lt;h1&gt;{{msg}}{{pro}}&lt;/h1&gt;
&lt;/template&gt;
&lt;script&gt;
export default {  props:[&#x27;pro&#x27;],  //接受这个属性  data() {  return {  msg:&quot;Box组件中&quot;  }  },
}
&lt;/script&gt;
&lt;style&gt;
&lt;/style&gt;
</code></pre>

<h2><a id="CSSscoped_253"></a>CSS相关技术[scoped]</h2> 
<p><strong>全局样式的写法:</strong><br> 在.vue文件中的style中写的样式 打包后就是全局样式<br> 写一个css文件 在项目中导入就是全局样式<br> 如果全局样式出现了相同的选择器. 就看是哪个最后打包引入项目 哪个的优先级就最高</p> 
<pre><code>//父组件App.vue
&lt;template&gt;  &lt;div v-cloak&gt;  &lt;h1&gt;App组件中&lt;/h1&gt;  &lt;box :pro=&quot;msg&quot;&gt;&lt;/box&gt;  &lt;user :pro2=&quot;msg2&quot;&gt;&lt;/user&gt;  &lt;/div&gt;
&lt;/template&gt;

&lt;script&gt;
import box from &quot;@/components/box.vue&quot;  import user from &quot;@/components/user.vue&quot;  //由于user后引入，css同样式优先级高
export default {  data() {  return {  msg: &quot;父组件传递给box的值&quot;,  msg2: &quot;父组件传递给user的值&quot;,  }  },  components:{  box,  user  }
}
&lt;/script&gt;
&lt;style&gt;
&lt;/style&gt;
</code></pre>

&lt;/template&gt;

&lt;/script&gt;
&lt;style&gt;  h1 {  color: red;  }
&lt;/style&gt;

<p><strong>全局样式会出先组件样式污染，那么如何解决？</strong><br> 使用局部样式scoped；</p> 
<p><strong>局部样式/CSS作用域的实现和原理</strong><br> 在style标签中添加一个scoped<br> 原理就是vue的插件webpack打包时会:<br> 把当前组件模板中的每一个元素添加一个相同的哈希值命名的属性名<br> 并且为添加了scoped的style中的样式选择器上添加一个属性选择器</p> 
<pre><code>//修改box.vue中的style
&lt;style scoped=&quot;scoped&quot;&gt;  h1 {  color: red;  }
&lt;/style&gt;

//修改user.vue中的style
&lt;style scoped=&quot;scoped&quot;&gt;  h1{  color: aqua;  }
&lt;/style&gt;
</code></pre>
