<h2><a id="1_4"></a>1.什么是动态组件</h2> 
<p>当我们希望页面中的某个地方，在不同组件之间进行动态切换，这时候除了条件渲染，还可以使用动态组件。</p> 
<h2><a id="2_6"></a>2.如何实现动态组件渲染？</h2> 
<p>vue提供了一个内置的组件，专门用来实现动态组件的渲染：通过 is 属性动态指定要渲染的组件</p> 
<p>因为要渲染的组件是不确定的，所以要通过data申明一个变量用来接收组件的名称，用 :is 动态绑定这个变量到组件中，通过按钮添加事件改变变量的值来切换相应组件<br> 案例：</p> 
<pre><code>//父组件App中
&lt;template&gt;  &lt;div v-cloak class=&quot;App&quot;&gt;  &lt;button v-for=&quot;(item, index) in arr&quot; :key=&quot;index&quot; @click=&quot;()=&gt;msg=item&quot;&gt;点击切换box{{index+1}}组件&lt;/button&gt;  &lt;component :is=&quot;msg&quot;&gt;&lt;/component&gt;  &lt;/div&gt;
&lt;/template&gt;
&lt;script&gt;  import box1 from &quot;./components/box1.vue&quot;  import box2 from &quot;./components/box2.vue&quot;  import box3 from &quot;./components/box3.vue&quot;  export default {  data() {  return {  msg: &#x27;box1&#x27;,  arr:[&#x27;box1&#x27;, &#x27;box2&#x27;, &#x27;box3&#x27;]  }  },  components: {  box1,  box2,  box3  },  }

</code></pre> 
<pre><code>//子组件box1中
&lt;template&gt;  &lt;div&gt;  &lt;h1&gt;box1组件中&lt;/h1&gt;  &lt;/div&gt;
&lt;/template&gt;

//子组件box2中
&lt;template&gt;
&lt;div&gt;  &lt;h1&gt;box2组件中&lt;/h1&gt;
&lt;/div&gt;
&lt;/template&gt;

//子组件box3中
&lt;template&gt;  &lt;div&gt;  &lt;h1&gt;box3组件中&lt;/h1&gt;  &lt;/div&gt;
&lt;/template&gt;
</code></pre>

<h2><a id="3_61"></a>3.如何实现缓存组件？</h2> 
<p>动态组件的切换，切换后是不会缓存之前被切换掉的组件的，每次切换新组件的时候，Vue 都创建了一个新的组件对象。<br> 有时候我们希望在A组件时用户做了一些操作，切换B组件时做了一些操作，当切回A组件时希望记住A的操作，不要重新创建A组件，keep-alive可以缓存动态切换的组件,代码如下：</p> 
<pre><code>//默认全部组件缓存
&lt;keep-alive&gt;  &lt;components :is=&quot;msg&quot;&gt;&lt;/components&gt;
 &lt;/keep-alive&gt;
</code></pre> 
<p><strong>keep-alive提供了三种匹配组件的方法:</strong></p> 
<ul><li>1.include 用来指定：只有名称匹配的组件会被缓存。多个组件名之间使用英文的逗号分隔； 可以写组件名字符串 也可以写正则</li></ul> 
<pre><code>&lt;keep-alive :include=&quot;/box2|box3/&quot;&gt;  //匹配bo2和box3组件缓存  &lt;component :is=&quot;msg&quot;&gt;&lt;/component&gt;  &lt;/keep-alive&gt;
</code></pre> 
<ul><li>2.exclude 只有名称匹配的组件不会被缓存。多个组件名之间使用英文的逗号分隔；</li></ul> 
<pre><code>  &lt;keep-alive exclude=&quot;box2&quot;&gt;  &lt;component :is=&quot;msg&quot;&gt;&lt;/component&gt;  &lt;/keep-alive&gt;
</code></pre> 
<ul><li>3.max 填数字，表示缓存最近被渲染过的几个组件</li></ul> 
<pre><code>  &lt;keep-alive :max=&quot;2&quot;&gt;  &lt;component :is=&quot;msg&quot;&gt;&lt;/component&gt;  &lt;/keep-alive&gt;
</code></pre> 
<p><strong>keep-alive对应的生命周期函数：</strong></p> 
<p>当组件被缓存时，会自动触发组件的 deactivated 生命周期函数。<br> 当组件被激活时，会自动触发组件的 activated 生命周期函数。</p> 
<h2><a id="4_95"></a>4.异步组件</h2> 
<p>vue开发过程中，我们会做出特别多特别多的组件，包括login,header,footer,main等等。这样使整个网站看起来就十分的庞大，当我们在打开网页的时候，突然一下子把这些所有的组件加载上来，这么多的请求全部同时开始请求，势必会造成网页打开很慢，使客户得到的是非常差劲的体验。</p> 
<p>在单页应用（SPA）中，如果没有用懒加载，运用webpack打包后的文件将会异常的大，造成进入首页时，需要加载的内容过多，延时过长，不利于用户体验，而运用懒加载则可以将页面进行划分，需要的时候加载页面，可以有效的分担首页所承担的加载压力，减少首页加载用时。</p> 
<p>此时我们需要运用到异步加载并缓存组件</p> 
<p><strong>什么是异步加载并缓存组件？</strong></p> 
<p>1、 异步加载组件：用不到的组件不会加载，因此网页打开速度会很快，当你用到这个组件的时候，才会通过异步请求进行加载；</p> 
<p>官方解释：<strong>Vue允许将组件定义为一个异步解析（加载）组件定义的工厂函数，即Vue只在实际需要渲染组件时，才会触发调用工厂函数，并且将结果缓存起来，用于将来再次渲染</strong>。</p> 
<p>2、 组件缓存起来：通过异步加载的组件会缓存起来，当你下一次再用到这个组件时，丝毫不会有任何的疑迟，组件很快会从缓存中加载出来。</p> 
<p><strong>如何使用：</strong><br> 方法一：通过webpack2.0的按需加载</p> 
<pre><code>//1 全局：
 Vue.component(&#x27;component-name&#x27;,function(resolve){
 //require 语法告诉 webpack自动将编译后的代码分割成不同的块
 //这些块将通过 Ajax 请求自动下载  require([&#x27;./my-async-componnet&#x27;],resolve)
 })
 //注册全局组件名，但只有一个名字，没有实体，相当于空的
//当需要这个组件时，调用上面的工厂函数，触发webpack的异步加载模块方法
//然后异步请求一个模块，请求成功后，这个模块内容即为组件实体部分，并对应地方渲染，加载内容也缓存下来。

//2 局部
 new Vue({  components: {  &#x27;component-name&#x27;:function(resolve) {  require([&#x27;./my-async-component&#x27;], resolve)  }  }
 })
</code></pre> 
<p>方法二：通过webpack2+es2015返回一个promise(主流 )</p> 
<pre><code>//1 全局：
Vue.component(&#x27;component-name&#x27;,
 （）=&gt; import(&#x27;./my-async-componnet&#x27;)//这个 `import` 函数会返回一个 `Promise` 对象,不要问我为什么,人家webpack这样设计的。
 )
//2 局部：
 new Vue({  components: {  &#x27;component-name&#x27;: () =&gt;  import(&#x27;./my-async-componnet&#x27;)//这个 `import` 函数会返回一个 `Promise` 对象。  }
 })
</code></pre> 
<p>方法三：高级异步组件（可以处理加载状态）<br> 常常用在路由中使用，vue 2.3.0+ 新增终极解决方案,要求路由2.4.0+</p> 
<pre><code>//工厂对象可以返回一个如下对象，对象里面的一些配置参数
const AsyncComponent = () =&gt; ({  // 需要加载的组件 (这个 `import` 函数会返回一个 `Promise` 对象。)  component: import(&#x27;./MyComponent.vue&#x27;),  // 异步组件加载时使用的组件  loading: LoadingComponent,  // 加载失败时使用的组件  error: ErrorComponent,  // 展示加载时组件的延时时间。默认值是 200 (毫秒)  delay: 200,  // 如果提供了超时时间且组件加载也超时了，  // 则使用加载失败时使用的组件。默认值是：`Infinity`  timeout: 3000
})
</code></pre>
