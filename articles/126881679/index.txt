<h2><a id="CSS_3"></a>什么是CSS样式穿透</h2> 
<p>所谓的穿透，官方叫做深度选择器。<br> 如果引入了其它组件，然后通过dom节点上的选择器来改变这个组件的一些样式，但是修改了不会生效<br> 原因是&lt;style scoped&gt;中的scoped所致,当 &lt;style&gt; 标签有 scoped 属性时，它的 CSS 只作用于当前组件中的元素。</p> 
<pre><code>&lt;template&gt;  &lt;div id=&quot;app&quot;&gt;  &lt;box1&gt;&lt;/box1&gt;  &lt;box2&gt;&lt;/box2&gt;  &lt;/div&gt;
&lt;/template&gt;
&lt;script&gt;  export default {  components:{  box1:()=&gt;import(&quot;@/views/login/views/box1.vue&quot;),  box2: () =&gt; import(&quot;@/views/login/views/box2.vue&quot;),  }  };
&lt;/script&gt;
&lt;style scoped&gt;  #app .box1{  color: black;  }  #app .box2{  color: green;  }
&lt;/style&gt;
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/083e7ecd9a85e0f00556ad30e2abc958.png" alt="在这里插入图片描述" loading="lazy" decoding="async"><br> 发现颜色并没有修改</p> 
<p>此时需要样式穿透，需要用到深度选择器。</p> 
<pre><code>&lt;style scoped&gt;  #app &gt;&gt;&gt; .box1{  color: black;  }  #app &gt;&gt;&gt; .box2{  color: green;  }
&lt;/style&gt;

</code></pre>

<p>再不同的预处理器中样式穿透也不一样</p> 
<p>css可以使用&gt;&gt;&gt;，/deep/，::v-deep<br> less和node-sass可以使用/deep/，::v-deep<br> dart-sass可以使用::v-deep<br> 所有的都能使用:deep()</p>
