<h2><a id="Object_8"></a>一、Object静态方法</h2> 
<p>静态方法就是直接使用类名调用的方法<br> <strong>object中静态方法有哪些？</strong></p> 
<h3><a id="1getPrototypeOf_11"></a>1.getPrototypeOf()</h3> 
<p>Object.getPrototypeOf()获取对象的原型，相当于obj._<em>proto</em>_</p> 
<pre><code>  function fn () {  }  fn.prototype=[&quot;ljy&quot;,22]  var obj=new fn()  var re=Object.getPrototypeOf(obj)//==&gt;obj.__prto__  console.log(re)
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/ca8e82543198fb36e93e5b96e9bfc9eb.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<h3><a id="2getOwnPropertyNames_23"></a>2.getOwnPropertyNames()</h3> 
<p>Object.getOwnPropertyNames()将obj的可枚举和不可枚举的属性的名称组成一个数组返回</p> 
<pre><code>  var obj=[10,203,4]  var re=Object.getOwnPropertyNames(obj)  console.log(obj,re)
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/95fd767b828e9a3586f180fbe4b144ee.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<h3><a id="3keys_31"></a>3.keys()</h3> 
<p>Object.keys()返回一个由一个给定对象的自身可枚举属性组成的数组，数组中属性名的排列顺序和正常循环遍历该对象时返回的顺序一致 。</p> 
<pre><code>  var obj={name:&#x27;akren&#x27;,age:20}  var re=Object.keys(obj)  console.log(re)
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/d384569b8600a805e18059145d395dce.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<h3><a id="4values_39"></a>4.values()</h3> 
<p>Object.values() 方法返回一个给定对象自身的所有可枚举属性值的数组，值的顺序与使用 for…in 循环的顺序相同 ( 区别在于 for-in 循环枚举原型链中的属性 )。</p> 
<pre><code>  var obj={name:&#x27;ljy&#x27;,age:22}  var re=Object.values(obj)  console.log(re)
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/52de86607fb1e6996ec8143268300961.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<h3><a id="5defineProperty_47"></a>5.defineProperty()</h3> 
<p>Object.defineProperty() 方法会直接在一个对象上定义一个新属性，或者修改一个对象的现有属性，并返回此对象。<br> 可以一次性定义多个值。</p> 
<table><thead><tr><th>描述符</th><th>作用</th></tr></thead><tbody><tr><td>configurable</td><td>当且仅当该属性的 configurable 键值为 true 时，该属性的描述符才能够被改变，同时该属性也能从对应的对象上被删除。默认为 false。</td></tr><tr><td>enumerable</td><td>当且仅当该属性的 enumerable 键值为 true 时，该属性才会出现在对象的枚举属性中。默认为 false。</td></tr><tr><td>value</td><td>该属性对应的值。可以是任何有效的 JavaScript 值（数值，对象，函数等）。默认为 undefined。</td></tr><tr><td>writable</td><td>当且仅当该属性的 writable 键值为 true 时，属性的值，也就是上面的 value，才能被赋值运算符改变。默认为 false。</td></tr><tr><td>get</td><td>属性的 getter 函数，如果没有 getter，则为 undefined。当访问该属性时，会调用此函数。执行时不传入任何参数，但是会传入 this 对象（由于继承关系，这里的this并不一定是定义该属性的对象）。该函数的返回值会被用作属性的值。默认为 undefined。</td></tr><tr><td>set</td><td>属性的 setter 函数，如果没有 setter，则为 undefined。当属性值被修改时，会调用此函数。该方法接受一个参数（也就是被赋予的新值），会传入赋值时的 this 对象。默认为 undefined。</td></tr></tbody></table>
<p><strong>案例1：</strong></p> 
<pre><code>  var obj={}  var temp;  Object.defineProperty(obj,&quot;ljy&quot;,{  set(arg){  //设置存入的数据  temp=arg;  console.log(&quot;您存入了&quot;+arg)  //当我们给这个属性存入时就打印(&quot;您存入了&quot;+arg)  },  get(){  //获得存入数据  return temp+&#x27;岁&#x27;  //当我们获取这个属性的数据时返回temp+&#x27;岁&#x27;  }  })  obj.ljy=22  console.log(obj[&#x27;ljy&#x27;])
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/f5b27b66e8573d622b978629a457e0b2.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<p><strong>案例2：</strong></p> 
<pre><code>  var obj={}  Object.defineProperty(obj,&quot;ljy&quot;,{  enumerable:true,  value:666,  writable:false,  //value不会被赋值运算符改变  })  obj.ljy=22  console.log(obj[&#x27;ljy&#x27;])
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/c0d39a982553ed4c78eac5d45102e919.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<h3><a id="6create_89"></a>6.create()</h3> 
<p>Object.create() 方法创建一个新对象，使用现有的对象来提供新创建的对象的原型。也称为工厂函数。</p> 
<pre><code>  var obj = Object.create([10,20,30],{&#x27;ljy&#x27;:{  //第一个参数表示原型，第二个参数表示对象属性和属性值描述跟defineProperty()一样。  value:22,  writable:false  }});  console.log(obj)  //打印的Array代表原型是数组
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/0cff9caa381b9ef59ba7818065bb8feb.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<h3><a id="7getOwnPropertyDescriptorobjpropName_99"></a>7.getOwnPropertyDescriptor(obj,propName)</h3> 
<p>Object.getOwnPropertyDescriptor() 方法返回指定对象上一个自有属性(propName)对应的属性描述符。（自有属性指的是直接赋予该对象的属性，不需要从原型链上进行查找的属性）</p> 
<pre><code>  var obj={name:&quot;karen&quot;}  var f1=Object.create(obj,{life:{  value:&#x27;ljy&#x27;  }})  console.log(f1)  var re=Object.getOwnPropertyDescriptor(f1,&quot;life&quot;)  console.log(re)
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/6b9fdb7a81b407d0fe15034dcbb9d2d9.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<h3><a id="8preventExtensionsobj_111"></a>8.preventExtensions(obj)</h3> 
<p>Object.preventExtensions() 方法让一个对象变的不可扩展，也就是永远不能再添加新的属性。</p> 
<pre><code>  var obj={ljy:22}  Object.preventExtensions(obj)  obj.age=200  console.log(obj,obj.age)
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/b388e3743c2bc1150d5235a1acae6143.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<h3><a id="9seal_120"></a>9.seal()</h3> 
<p>Object.seal() 方法封闭一个对象，阻止添加新属性并将所有现有属性标记为不可配置。<br> 当前属性的值只要原来是可写的就可以改变。</p> 
<pre><code>  var obj={ljy:22}  var re=Object.seal(obj)  obj.age=22  delete obj.ljy  console.log(obj)
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/3759685c2728de79c08e7964ca696beb.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<h3><a id="10freezeobj_131"></a>10.freeze(obj)</h3> 
<p>可以禁止对obj的所有操作，它相对与preventExtensible方法而言，将属性的configurable属性和writable属性都设置为了false。</p> 
<pre><code>  var obj={ljy:22}  var re=Object.freeze(obj)  delete obj.ljy  obj.ljy=100  obj.age=20  console.log(obj)
</code></pre> 
<p><img src="https://i-blog.csdnimg.cn/blog_migrate/8c97700ff3e9628eacdf2bc3c94058ab.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<h3><a id="11_142"></a>11.判断是否设置了某方法</h3> 
<p>Object.isExtensible(obj)、Object.isSealed(obj)、Object.isFrozen(obj) 分别对应了上述三个方法是否对obj进行了设置</p>
