<h3><a id="_2"></a>什么是多层传值</h3>
<p>可以理解为多级组件嵌套传值，比如父组件向孙组件传值<br>
Vue 2.4版本开始，新增了$attrs 和 $listeners方法用于隔代传值</p>
<ul><li>
<p>$attrs: 用于传递属性  inheritAttrs: false,(这个属性可以让传递的属性不显示在标签上)</p>
</li><li>
<p>$listeners: 用于传递方法</p>
</li></ul>
<h4><a id="_10"></a>案例:</h4>
<pre><code>//父组件App中
&lt;template&gt;
&lt;div v-cloak class=&quot;App&quot;&gt;  &lt;!-- 属性传值给box1,并给box1绑定自定义事件 --&gt;  &lt;box1 :pro=&quot;msg&quot; @myclick=&quot;fn&quot;&gt;&lt;/box1&gt;
&lt;/div&gt;
&lt;/template&gt;
&lt;script&gt;  import box1 from &quot;./components/box1.vue&quot;  export default {  data() {  return {  msg:&quot;父组件App传递的值&quot;,  }  },  methods: {  fn(newmsg) {  this.msg=newmsg  }  },  components: {  box1,  }  }
&lt;/script&gt;
</code></pre>
<pre><code>//子组件box1中
&lt;template&gt;
&lt;div&gt;  &lt;!-- 使用 v-bind=&quot;$attrs&quot; 传递属性  v-on=&quot;$listeners&quot; 传递方法给box2--&gt;  &lt;h1&gt;box1--{{$attrs.pro}}&lt;/h1&gt;  &lt;box2 v-bind=&quot;$attrs&quot; v-on=&quot;$listeners&quot;&gt;&lt;/box2&gt;
&lt;/div&gt;  &lt;/template&gt;
&lt;script&gt;  import box2 from &quot;./box2.vue&quot;  export default {  components:{  box2  },  }
&lt;/script&gt;
</code></pre>
<pre><code>//子组件box2中
‘&lt;template&gt;
&lt;div&gt;  &lt;button @click=&quot;fn&quot;&gt;点击修改msg&lt;/button&gt;  &lt;h3&gt;box2--{{pro}}&lt;/h3&gt;
&lt;/div&gt;
&lt;/template&gt;
&lt;script&gt;
export default {  props:[&#x27;pro&#x27;],  //接受传递的值  methods: {  fn(){  this.$emit(&#x27;myclick&#x27;,&quot;box2修改了数据&quot;) //触发父组件绑定的事件  }  },
}
&lt;/script&gt;
</code></pre>
