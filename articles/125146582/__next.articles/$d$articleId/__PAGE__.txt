<h2><a id="forEach_5"></a>一、设计数组方法forEach</h2> 
<p>forEach() 方法按顺序为数组中的每个元素调用一次函数。<br> 注意：对于没有值的数组元素，不执行forEach() 方法。<br> 返回值：undefined</p>

</code></pre>

<h2><a id="some_23"></a>二、设计数组方法some</h2> 
<p>some() 方法检查数组中的任何元素是否通过测试（作为函数提供）。<br> some() 方法对数组中存在的每个元素执行一次函数：<br> 如果找到函数返回真值的数组元素，some() 返回真（并且不检查剩余值）<br> 否则返回 false<br> 返回值： 布尔值。如果数组中的任何元素通过测试，则返回 true，否则返回 false。</p> 
<pre><code>	Array.prototype.mysome=function(callback) {  for(var i=0;i&lt;this.length;i++){  if(callback(this[i],i,this)){return true}  }  return false  }  var  arr=[10,200,500,400]
	var re=arr.mysome(function(el){  console.log(el)  return el&gt;100
	})
	console.log(re)
</code></pre>
