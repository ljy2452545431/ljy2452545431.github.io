<h2><a id="_5"></a>本地引入</h2> 
<h3><a id="CDN_7"></a>CDN引入</h3> 
<pre><code>&lt;script src=&quot;https://lf26-cdn-tos.bytecdntp.com/cdn/expire-1-M/vue/2.6.12/vue.js&quot;&gt;&lt;/script&gt;
</code></pre> 
<p>CDN引入的好处是，随用随引，不需要的包在页面上就不加载。并且通过外链访问比打包压缩访问的速度更快。</p> 
<h3><a id="vuejs_13"></a>引入vue.js文件</h3> 
<p>vue框架本质是一个javascript库，简单来说就是大一点的js文件，里面封装了各种方法供我们使用。<br> 所以也可以通过本地引入vue.js文件</p> 
<pre><code>&lt;script src=&quot;./src/vue2.6.14.js&quot;&gt;&lt;/script&gt;
</code></pre> 
<h3><a id="webpack_19"></a>webpack打包</h3> 
<p>可通过webpack打包的形式将入口文件设置为vue的项目文件以main.js为例子：</p> 
<pre><code>//main.js文件
import Vue from &#x27;./vue.js&#x27;  //将下载到本地的vue.js文件引入
new Vue({  el: &quot;#app&quot;,  //css选择器名  data: {  msg: &quot;内容&quot;,  }
})
</code></pre> 
<p>webpack的入口配置为:</p> 
<pre><code>entry: __dirname + &quot;/src/main.js&quot; //本地入口文件路径
</code></pre> 
<p>注意点是：打包后的bundle挂载到模板html的位置:‘body’</p>

<p>HbuilderX=&gt;创建项目=&gt;选择=&gt;vue项目普通模式<br> <img src="https://i-blog.csdnimg.cn/blog_migrate/bc337ae01e2d395165cdc74bfad764ff.png" alt="在这里插入图片描述" loading="lazy" decoding="async"></p> 
<h2><a id="_40"></a>加载器转码引入到网页</h2> 
<p>就是直接把vue的代码环境集成了 然后开始在vue的代码环境中写项目,最终才经过webpack打包生成第一类方式</p> 
<h3><a id="vue_42"></a>手动构建vue的脚手架</h3> 
<p>再项目文件夹中使用npm init -y 生成webpack的项目配置文件<br> 再下载依赖文件：<br> npm i webpack@5.74.0 webpack-cli@4.10.0 vue-loader@17.0.0 @vue/compiler-sfc@3.2.37 webpack-dev-server@4.10.0 html-webpack-plugin@5.5.0 -D<br> 最后下载vue：npm i vue -S</p> 
<pre><code>//webpack.config.js配置:

const path = require(&#x27;path&#x27;);
const {
	VueLoaderPlugin
} = require(&#x27;vue-loader&#x27;);
const HtmlWebpackPlugin = require(&#x27;html-webpack-plugin&#x27;);
module.exports = {
	mode: &#x27;production&#x27;,
	watch: true,
	entry: &#x27;./src/main.js&#x27;,
	output: {  filename: &#x27;[name].js&#x27;,  path: path.resolve(__dirname, &#x27;dist&#x27;),
	},
	module: {  rules: [{  test: /\.vue$/,  loader: &#x27;vue-loader&#x27;,  }, ]
	},
	plugins: [  new HtmlWebpackPlugin({  template: path.join(__dirname, &#x27;src/index.html&#x27;),  filename: &#x27;index.html&#x27;  }),  new VueLoaderPlugin(),
	],
	devServer: {  open: true,  port: 8080,  hot: true,  host: &#x27;localhost&#x27;,  compress: true,
	},
}
</code></pre> 
<p>在项目配置文件中设置启动方式</p> 
<pre><code>scripts:{
&quot;dev&quot;: &quot;webpack serve --config webpack.config.js&quot;
}
</code></pre> 
<p>main.js文件配置：</p> 
<pre><code>import { createApp } from &#x27;vue&#x27;
import App from &#x27;./App.vue&#x27;
createApp(App).mount(&#x27;#app&#x27;)
</code></pre> 
<p>App.vue文件配置</p> 
<pre><code>&lt;template&gt;
&lt;div id=&quot;app&quot;&gt;
	{{msg}}
&lt;/div&gt;
&lt;/template&gt;

&lt;script&gt;
	export default {  data(){  return {msg:&quot;hello&quot;}  }
	}
&lt;/script&gt;
</code></pre>

<p>敲回车后会来到自定义配置项界面<br> <img src="https://i-blog.csdnimg.cn/blog_migrate/52db77fafa5c557cb0f7eb6e9eca48df.png" alt="在这里插入图片描述" loading="lazy" decoding="async"><br> 这里按空格为选择，有星号的代表选择起了,回车则是确认,键盘a和i都是全选或全不选<br> 自定义配置项解释<br> ( ) Choose Vue version //选择vue脚手架的版本<br> ( ) Babel //转码器，可以将ES6代码转为ES5代码，从而在现有环境执行。<br> ( ) TypeScript// TypeScript是一个JavaScript（后缀.js）的超集（后缀.ts）包含并扩展了<br> JavaScript 的语法，需要被编译输出为 JavaScript在浏览器运行<br> ( ) Progressive Web App (PWA) Support// 渐进式Web应用程序<br> ( ) Router // vue-router（vue路由）<br> ( ) Vuex // vuex（vue的状态管理模式）<br> ( ) CSS Pre-processors // CSS 预处理器（如：less、sass）<br> ( ) Linter / Formatter // 代码风格检查和格式化（如：ESlint）<br> ( ) Unit Testing // 单元测试（unit tests）<br> ( ) E2E Testing // e2e（end to end） 测试</p>
