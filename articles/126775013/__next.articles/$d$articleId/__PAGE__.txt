<h2><a id="bus_5"></a>什么是中央事件总线（bus）</h2> 
<p>通过创建一个新的vm对象,专门统一注册事件,供所有组件共同操作,达到所有组件随意隔代传值的效果<br> 也就是：各个组件内部要传输的数据或者要执行的命令信息，靠bus来通信。</p> 
<p>我们知道子组件向父组件传值可以通过将自定义事件的方法来进行，那么如果我们把事件绑定在所有组件都能访问的地方，然后想要给某个组件通信，直接触发这个事件。</p> 
<p><strong>如何实现：</strong><br> 主要使用了组件事件的三个方法：</p> 
<pre><code>  //1.触发x组件的a事件: x.$emit(&quot;a事件&quot;,参数...)  //2.给x组件绑定a事件  x.$on(&quot;a事件&quot;,监听器函数)  //3.给x组件解绑a事件  x.$off(&quot;a事件&quot;,监听器函数)
</code></pre> 
<pre><code>//在父组件App中
&lt;template&gt;  &lt;div v-cloak class=&quot;App&quot;&gt;  &lt;box2&gt;&lt;/box2&gt;  &lt;box3&gt;&lt;/box3&gt;  &lt;/div&gt;
&lt;/template&gt;
&lt;script&gt;  import box2 from &quot;./components/box2.vue&quot;  import box3 from &quot;./components/box3.vue&quot;  export default {  components: {  box2,  box3  },  }
&lt;/script&gt;
</code></pre> 
<pre><code>//子组件box2中
&lt;template&gt;
&lt;div&gt;  &lt;button @click=&quot;fn&quot;&gt;点我向box3传值&lt;/button&gt;
&lt;/div&gt;
&lt;/template&gt;
&lt;script&gt;
export default {  data() {  return {  msg:&quot;box2传递的数据&quot;  }  },  methods: {  fn(){  //触发根组件的mybox3事件，并将msg变量传进去  this.$root.$emit(&quot;mybox3&quot;,this.msg)  }  },
}
&lt;/script&gt;
</code></pre> 
<pre><code>//子组件box3中
&lt;template&gt;  &lt;div&gt;  &lt;h1&gt;box2中&lt;/h1&gt;  &lt;h2&gt;{{msg}}&lt;/h2&gt;  &lt;/div&gt;
&lt;/template&gt;
&lt;script&gt;  export default {  data() {  return {  msg:null  }  },  mounted() {  //给根组件绑定mybox3事件  this.$root.$on(&quot;mybox3&quot;,(data)=&gt;{  this.msg= data  })  },  }
&lt;/script&gt;
</code></pre>

<h2><a id="_88"></a>创建中央事件总线</h2> 
<p>方法一 全局事件总线</p> 
<pre><code>1.在main.js文件中定义
Vue.prototype.$bus=new Vue({
	data:{  arr:[]  //用来保存事件名
	},
	methods:{
	//绑定事件  on(eventname,callback){  //判断事件名是否重复  if(this.arr.includes(eventname)){  throw &quot;eventname events already regist!!&quot;  }else{  this.arr.push(eventname)  this.$on(eventname,callback)  }  },  //触发事件，传递数据  emit(eventname,...arg){  this.$emit(eventname,...arg)  },  解绑  off(eventname,callback){  this.$off(eventname,callback)  }
	}
})
2.使用方法
this.$bus.emit(&#x27;定义名称&#x27;,值) //触发事件 
this.$bus.on(&#x27;定义名称&#x27; val=&gt;{}) //绑定事件 
this.$bus.off(&#x27;定义名称&#x27;) //解绑
</code></pre> 
<p>方法二、单独创建bus.js文件</p> 
<p>1.在main.js的同级建一个bus.js,<br> 2.在main.js引入<br> import bus from “./bus.js”<br> 绑定到原型上 Vue.prototype.$bus = bus;</p>
